## 1. 原文

In everyday conversation, speed and velocity are often used as if they mean the same thing. In physics, they have definite

and distinct meanings. Speed refers to how fast an object is moving, or how far the object will travel in a specific time.

The speed of an object tells nothing about the direction an object is moving. For example, if the information is supplied that an airplane leaves New York City and travels 8 hours at a speed of 150 mph, this information tells nothing about the direction in which the airplane is moving. At the end of 8 hours, it might be in Kansas City, or if it traveled in a circular route, it could be back in New York City.

Velocity is that quantity in physics which denotes both the speed of an object and the direction in which the object moves. Velocity can be defined as the rate of motion in a particular direction. Velocity is also described as being a vector quantity, a vector being a line of specific length, having an arrow on one end or the other. The length of the line indicates the number value and the arrow indicates the direction in which that number is acting.

Two velocity vectors, such as one representing the velocity of an airplane and one representing the velocity of the wind, can be added together in what is called vector analysis. Figure 5-25 demonstrates this, with vectors “A” and “B” representing the velocity of the airplane and the wind, and vector “C” being the resultant. With no wind, the speed and direction of the airplane would be that shown by vector “A.” When accounting for the wind direction and speed, the airplane ends up flying at the speed and direction shown by vector “C.”

Imagine that an airplane is flying in a circular pattern at a constant speed. The airplane is constantly changing direction because of the circular pattern, which means the airplane is constantly changing velocity. The reason for this is the fact that velocity includes direction.

To calculate the speed of an object, the distance it travels is divided by the elapsed time. If the distance is measured in miles and the time in hours, the units of speed will be miles per hour (mph). If the distance is measured in feet and the time in seconds, the units of speed will be feet per second (fps). To convert mph to fps, divide by 1.467. Velocity is calculated the same way, the only difference being it must be recalculated every time the direction changes.

## 2. 中文翻译

在日常会话中，speed（速率）和 velocity（速度）常被当作同一个意思来使用。在物理学中，二者有明确的

、互不相同的含义。速率指物体运动的快慢，即物体在特定时间内能走多远。

物体的速率并不能说明物体运动的方向。例如，若给出的信息是：一架飞机离开纽约市，以 150 mph 的速率飞行 8 小时，这个信息并不能说明飞机正在朝哪个方向飞。8 小时结束时，它可能到了堪萨斯城；如果它沿圆形航线飞行，也可能又回到纽约市。

速度是物理学中既表示物体运动快慢、又表示运动方向的那个量。速度可定义为特定方向上的运动率。速度也被描述为矢量：矢量是一条具有特定长度的线，其一端带箭头。线的长度表示数值大小，箭头表示该数值作用的方向。

两个速度矢量，例如一个表示飞机的速度、另一个表示风的速度，可以相加，这种做法称为矢量分析。图 5-25 演示了这一点：矢量 “A” 和 “B” 分别表示飞机和风的速度，矢量 “C” 为合矢量。无风时，飞机的速率和方向就是矢量 “A” 所示。计入风向和风速后，飞机最终以矢量 “C” 所示的速率和方向飞行。

设想一架飞机以恒定速率做圆周飞行。由于做圆周运动，飞机不断改变方向，这意味着飞机不断改变速度。原因就在于速度包含方向。

要计算物体的速率，用其行进的距离除以所经过的时间。如果距离以英里计、时间以小时计，速率的单位就是英里每小时（mph）。如果距离以英尺计、时间以秒计，速率的单位就是英尺每秒（fps）。要把 mph 换算成 fps，除以 1.467。速度的计算方法相同，唯一区别是每当方向改变时必须重新计算。

## 4. 语法解析

### ① as if they mean the same thing（as if 引导方式状语从句）

**原句**：In everyday conversation, speed and velocity are often used as if they mean the same thing.

**拆解**：主句 speed and velocity are often used 为被动；as if 引导方式状语从句，从句用一般现在时 mean，主语 they 指 speed and velocity。

**要点**：as if 后可用陈述语气（说话人认为可能为真）或虚拟语气（与事实相反）。此处用 mean，表示「仿佛二者意思相同」；下一句用 in physics 转折，指出实际不同。

### ② a vector being a line of specific length（独立主格结构）

**原句**：Velocity is also described as being a vector quantity, a vector being a line of specific length, having an arrow on one end or the other.

**拆解**：主句 is described as being …；a vector being a line of specific length 为独立主格结构（逻辑主语 a vector + 现在分词 being），对 vector quantity 作补充说明；having an arrow … 为现在分词短语修饰 line。

**要点**：独立主格 = 名词 + 分词，前面没有介词、后面没有连词，起补充说明或状语作用。describe A as B 中 as 后可接名词或动名词，故用 being。one end or the other 意为「两端中的一端」。

### ③ the direction in which the object moves（介词 + which 定语从句）

**原句**：Velocity is that quantity in physics which denotes both the speed of an object and the direction in which the object moves.

**拆解**：主句 Velocity is that quantity；which denotes … 为限制性定语从句修饰 quantity；the direction in which the object moves 中 in which = in the direction，作 moves 的状语。

**要点**：介词 + which 不能用 that 替换。in which 表方向时相当于 in the direction that / where。both A and B 为并列宾语，A = the speed of an object，B = the direction …。

### ④ the fact that velocity includes direction（同位语从句）

**原句**：The reason for this is the fact that velocity includes direction.

**拆解**：主语 The reason for this，系动词 is，表语 the fact，that 引导同位语从句说明 fact 的具体内容。

**要点**：the fact that 是同位语从句的典型标志；that 在从句中不作任何成分，只起连接作用，不能换成 which。该句可简化为 The reason is that velocity includes direction。

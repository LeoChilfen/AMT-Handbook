# Using Fire Extinguishers

> 通用 Ch 01 · Using Fire Extinguishers · 原文 PDF 第 30 页

## 1. 原文

When using a fire extinguisher, ensure the correct type is used for the fire. Most extinguishers have a pin to pull that allows the handle to activate the agent. Stand back 8 feet and aim at the base of the fire or flames. Squeeze the lever and sweep side to side until the fire is extinguished.

## 2. 中文翻译

使用灭火器时，要确保所用类型与火灾类型相符。大多数灭火器都有一个需要拔出的保险销，拔出后手柄才能释放灭火剂。站到 8 英尺以外，瞄准火焰或火源的根部。握紧压把，左右扫射，直到火被扑灭。

## 4. 语法解析

### ① When + 现在分词作状语，主句祈使

**原句**：When using a fire extinguisher, ensure the correct type is used for the fire.

**拆解**：When using a fire extinguisher 是时间状语，省略了主语和 be（完整为 When you are using …）；主句 ensure the correct type is used for the fire 是祈使句，ensure 后接省略 that 的宾语从句，从句为被动 is used。

**要点**：when/while + 现在分词时，分词的逻辑主语必须与主句主语一致，否则就成了悬垂分词。ensure (that) 从句中用被动，是因为重点在「灭火器类型被使用」，而不是谁去使用；for the fire 表示「针对这种火」。

### ② 不定式作后置定语 + that 定语从句

**原句**：Most extinguishers have a pin to pull that allows the handle to activate the agent.

**拆解**：主干 Most extinguishers have a pin；to pull 是不定式作后置定语修饰 pin（「要拔的销子」）；that allows the handle to activate the agent 是定语从句，that 指代 pin，在从句中作主语；allows the handle to activate 是 allow sb/sth to do 结构。

**要点**：have sth to do 表示「有……要做/可做」，to do 与前面的名词构成动宾关系（pull a pin）。to pull 不是目的状语，不能译成「为了拔销子」；that 从句紧跟 pin，说明这个销子的作用。

### ③ 并列祈使句 + until 时间状语从句

**原句**：Squeeze the lever and sweep side to side until the fire is extinguished.

**拆解**：Squeeze the lever 与 sweep side to side 是两个并列的祈使句，由 and 连接；until the fire is extinguished 是时间状语从句，用一般现在时表示将来。

**要点**：until 从句中不用 will，用一般现在时表将来；is extinguished 是被动，强调火「被扑灭」的结果。side to side 是固定说法，意为「从一侧到另一侧、左右」，与 from side to side 同义但更简洁。

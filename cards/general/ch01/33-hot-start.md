# Hot Start

> 通用 Ch 01 · Hot Start · 原文 PDF 第 39 页

## 1. 原文

A hot start occurs when the engine starts, but the exhaust gas temperature exceeds specified limits. This is usually caused by an excessively rich air-fuel mixture entering the combustion chamber. This condition can be caused by either too much fuel or not enough airflow. The fuel to the engine must be shut off immediately.

## 2. 中文翻译

当发动机已经起动、但排气温度超过规定限值时，就发生热起动。这通常是由于过富的空气-燃油混合气进入燃烧室所致。这种状况可能由供油过多或进气量不足引起。必须立即切断通往发动机的燃油。

## 4. 语法解析

### ① when 引导的状语从句内含 but 并列谓语

**原句**：A hot start occurs when the engine starts, but the exhaust gas temperature exceeds specified limits.

**拆解**：主句 A hot start occurs；when 引导时间状语从句；从句内部由 but 连接两个并列谓语 starts 与 exceeds，后者的主语是 the exhaust gas temperature。

**要点**：but 连接的是两个并列分句，第二个分句只是省了引导词，译作「发动机虽已起动，但排气温度超限」。读这类句子要分清 but 前后各自的主语，别把 exceeds 的主语误认成 the engine。

### ② be caused by + 分词后置定语

**原句**：This is usually caused by an excessively rich air-fuel mixture entering the combustion chamber.

**拆解**：主语 This，谓语 is caused by（被动）；by 的宾语是 an excessively rich air-fuel mixture，entering the combustion chamber 是现在分词短语作后置定语，不是谓语。

**要点**：分词紧跟名词时先判断它是定语还是谓语——此处 entering 前没有 be 动词，只能是定语，译作「进入燃烧室的（混合气）」。若改成 which enters，意思相同但句子更重。

### ③ either…or… 并列两个成因

**原句**：This condition can be caused by either too much fuel or not enough airflow.

**拆解**：can be caused by 为「情态动词 + 被动」；either…or… 并列两个名词短语 too much fuel 与 not enough airflow。

**要点**：either A or B 表示「A 或 B（二者之一）」，对应中文「或……或……」。too much 修饰不可数名词 fuel，not enough 直接修饰不可数名词 airflow，都不加 -s；技术文本常用这种并列列出多个可能成因。

# Classification of Fires

> 通用 Ch 01 · Classification of Fires · 原文 PDF 第 27 页

## 1. 原文

For commercial purposes, the National Fire Protection Association (NFPA) has classified fires into three basic types:

Class A, Class B, and Class C.

1. Class A fires involve ordinary combustible materials, such as wood, cloth, paper, upholstery materials, and so forth.

2. Class B fires involve flammable petroleum products or other flammable or combustible liquids, greases, solvents, paints, and so forth.

3. Class C fires involve energized electrical wiring and equipment.

A fourth class of fire, the Class D fire, involves flammable metal. Class D fires are not commercially considered by the NFPA to be a basic type of fire since they are caused by a Class A, B, or C fire. Usually Class D fires involve magnesium in the shop, or in aircraft wheels and brakes, or are the result of improper welding operations.

Any one of these fires can occur during maintenance on or around, or operations involving aircraft. There is a particular type of extinguisher that is most effective for each type of fire.

## 2. 中文翻译

出于商业目的，美国国家消防协会（NFPA）已将火灾分为三种基本类型：

A 类、B 类和 C 类。

1. A 类火涉及普通可燃材料，如木材、布料、纸张、座椅内饰材料等。

2. B 类火涉及易燃石油产品，或其他易燃或可燃液体、油脂、溶剂、油漆等。

3. C 类火涉及带电的电气线路与设备。

第四类火是 D 类火，涉及可燃金属。NFPA 从商业角度不把 D 类火视为基本类型，因为它们是由 A、B 或 C 类火引起的。D 类火通常涉及车间中的镁，或航空器机轮与刹车中的镁，也可能是焊接操作不当的结果。

上述任何一种火都可能在航空器维修期间、在航空器上或周围发生，也可能发生在涉及航空器的作业中。每一类火都有一种最有效的专用灭火器。

## 4. 语法解析

### ① 现在完成时 + classify … into

**原句**：the National Fire Protection Association (NFPA) has classified fires into three basic types

**拆解**：主语 the National Fire Protection Association (NFPA)，谓语 has classified（现在完成时），宾语 fires，into three basic types 是介词短语表示分类结果。

**要点**：classify A into B 是「把 A 分为 B」的固定搭配，into 不能换成 in 或 to。用现在完成时是因为这套分类是业已确立、沿用至今的成果；介绍标准、规范时常用现在完成时交代「已经作出」的规定。

### ② 被动语态 + since 原因状语从句

**原句**：Class D fires are not commercially considered by the NFPA to be a basic type of fire since they are caused by a Class A, B, or C fire.

**拆解**：主句为被动结构 are not considered … to be a basic type of fire，by the NFPA 引出动作执行者，commercially 作状语修饰 considered（从商业角度而言）；since 引导原因状语从句，从句本身又是被动 are caused by。

**要点**：consider A (to be) B 变为被动即 A is considered (to be) B，to be 常保留。since 在此表原因（「因为」），不是「自从」；判断依据是从句用现在时、主句讲的是分类理由。注意 commercially 放在助动词与过去分词之间，是副词常见位置。

### ③ There be 存在句 + 定语从句

**原句**：There is a particular type of extinguisher that is most effective for each type of fire.

**拆解**：There is 引出存在的主体 a particular type of extinguisher；that is most effective for each type of fire 是定语从句，that 指代 extinguisher，在从句中作主语。

**要点**：there be 句型后接定语从句时，从句谓语要与先行词一致（a type 为单数，用 is）。be effective for / on 表示「对……有效」，for 后接对象类别，on 后多接具体事物，本节两者皆可出现。

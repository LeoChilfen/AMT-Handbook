# Classification of Fires

> 通用 Ch 01 · Classification of Fires · 原文 PDF 第 27 页

## 1. 原文

For commercial purposes, the National Fire Protection Association (NFPA) has classified fires into three basic types: Class A, Class B, and Class C.

1. Class A fires involve ordinary combustible materials, such as wood, cloth, paper, upholstery materials, and so forth.

2. Class B fires involve flammable petroleum products or other flammable or combustible liquids, greases, solvents, paints, and so forth.

3. Class C fires involve energized electrical wiring and equipment.

A fourth class of fire, the Class D fire, involves flammable metal. Class D fires are not commercially considered by the NFPA to be a basic type of fire since they are caused by a Class A, B, or C fire. Usually Class D fires involve magnesium in the shop, or in aircraft wheels and brakes, or are the result of improper welding operations.

Any one of these fires can occur during maintenance on or around, or operations involving aircraft. There is a particular type of extinguisher that is most effective for each type of fire.

## 2. 中文翻译

出于商业（保险）用途，美国国家消防协会（NFPA）把火灾划分为三个基本类别：A 类、B 类和 C 类。

1. A 类火灾涉及普通可燃材料，如木材、布料、纸张、内饰包覆材料等。

2. B 类火灾涉及易燃石油产品，或其他易燃、可燃液体，以及润滑脂、溶剂、油漆等。

3. C 类火灾涉及带电的电气线路与设备。

第四类是 D 类火灾，涉及可燃金属。NFPA 在商业用途上并不把 D 类当作基本火灾类型，因为它们是由 A、B 或 C 类火灾引起的。D 类火灾通常涉及车间里的镁，或飞机机轮和刹车中的镁，也可能是焊接操作不当的结果。

上述任何一种火灾，都可能在飞机上或其周围进行维修时、或在涉及飞机的运行中发生。每一种火灾都有一种最有效的灭火器类型。

## 4. 语法解析

### ① 现在完成时 + classify into
**原句**：For commercial purposes, the National Fire Protection Association (NFPA) has classified fires into three basic types: Class A, Class B, and Class C.
**拆解**：状语 For commercial purposes 前置；主语 NFPA；谓语 has classified（现在完成时）；宾语 fires + into three basic types 表分类结果；冒号后为列举。
**要点**：classify A into B 是固定搭配（把 A 分为 B）；现在完成时表示分类结果至今有效，不是一次性动作。

### ② such as 引出的同位列举
**原句**：Class A fires involve ordinary combustible materials, such as wood, cloth, paper, upholstery materials, and so forth.
**拆解**：主语 Class A fires + 谓语 involve + 宾语 ordinary combustible materials；such as… 为举例，与被列举名词同位。
**要点**：such as 后接名词或名词短语，不能接句子；与 for example 不同（后者可独立成句、用逗号隔开）；and so forth 收尾表示“等等”。

### ③ 逗号隔开的同位语 + 主谓一致
**原句**：A fourth class of fire, the Class D fire, involves flammable metal.
**拆解**：主语 A fourth class of fire + 同位语 the Class D fire（逗号隔开）+ 谓语 involves + 宾语 flammable metal。
**要点**：同位语插在主语和谓语之间时，谓语单复数仍与主语中心词一致（class → involves）；这种结构在定义类文本中用来先给类别、再给名称。

### ④ since 引导的原因状语从句 + 被动
**原句**：Class D fires are not commercially considered by the NFPA to be a basic type of fire since they are caused by a Class A, B, or C fire.
**拆解**：主句为被动 are not considered… to be…（consider sth to be sth 的被动式）；since 引导原因状语从句，从句再用被动 are caused by。
**要点**：consider… to be 变被动后 to be 不能省；since 表原因时比 because 更书面，且多置于主句之后。

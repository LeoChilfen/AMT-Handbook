# Hot Start

> 通用 Ch 01 · Hot Start · 原文 PDF 第 39 页

## 1. 原文

A hot start occurs when the engine starts, but the exhaust gas temperature exceeds specified limits. This is usually caused by an excessively rich air-fuel mixture entering the combustion chamber. This condition can be caused by either too much fuel or not enough airflow. The fuel to the engine must be shut off immediately.

## 2. 中文翻译

热起动（hot start）是指发动机确实起动了，但排气温度超过规定限制。这通常是由于进入燃烧室的混合气过富（油气比过大）造成的。造成这种情况的原因，可能是供油过多，也可能是空气流量不足。发现热起动，必须立即切断向发动机的供油。

## 4. 语法解析

### ① when 从句内含转折并列

**原句**：A hot start occurs when the engine starts, but the exhaust gas temperature exceeds specified limits.

**拆解**：主句 A hot start occurs；when 引导时间状语从句，从句内部是 the engine starts 与 the exhaust gas temperature exceeds specified limits 两个分句用 but 并列，形成对比（起动了，但温度超限）；specified limits 是过去分词作定语。

**要点**：when 从句可以容纳一个完整的并列句，此时 when 相当于「当……时（情形是：……）」。翻译时把 but 的对比译出来（「虽然……但……」），否则会丢掉 hot start 的定义要点：起动成功不等于正常。

### ② by + 动名词复合结构（主动的 -ing）

**原句**：This is usually caused by an excessively rich air-fuel mixture entering the combustion chamber.

**拆解**：This is usually caused 是被动语态；by an excessively rich air-fuel mixture entering the combustion chamber 是原因状语，by 的宾语是动名词复合结构「名词 + entering」，混合气与进入是主动关系，故用 entering。

**要点**：对比上一类 being + 过去分词（被动），这里混合气自己「进入」，所以用 -ing 而非 being entered。判断用 doing 还是 being done，只看名词与动作是主动还是被动关系，与句子主被动无关。

### ③ either…or 连接两个名词短语作介词宾语

**原句**：This condition can be caused by either too much fuel or not enough airflow.

**拆解**：主语 This condition，谓语 can be caused 是情态被动；by either too much fuel or not enough airflow 是原因状语，either…or 连接两个名词短语（too much fuel / not enough airflow），两者都是 by 的宾语。

**要点**：either…or 在此连接的是「量」的两种偏差（油太多、气太少），翻译要保住对称：既可能……又可能……。注意 not enough 是形容词短语作定语，不能写成 no enough。

### ④ must be + 过去分词（立即执行的强制要求）

**原句**：The fuel to the engine must be shut off immediately.

**拆解**：主语 The fuel，to the engine 是后置定语（限定「供到发动机的」燃油）；谓语 must be shut off 是情态动词 + 被动，shut off 是「动词 + 副词」型短语动词；immediately 是时间状语。

**要点**：短语动词变被动时副词不能丢（be shut off，不是 be shut）；must be + 过去分词在处置类条文里表示「必须立即被……」，配合 immediately 强化紧迫性。to the engine 不可省，因为机上还有别的燃油通路。

# Engine Fails to Start

> 通用 Ch 01 · Engine Fails to Start · 原文 PDF 第 39 页

## 1. 原文

The engine failing to start within the prescribed time limit can be caused by lack of fuel to the engine, insufficient or no electrical power to the exciter in the ignition system, or incorrect fuel mixture. If the engine fails to start within the prescribed time, shut it down.

In all cases of unsatisfactory starts, the fuel and ignition must be turned off. Continue rotating the compressor for approximately 15 seconds to remove accumulated fuel from the engine. If unable to motor (rotate) the engine, allow a 30-second fuel draining period before attempting another start.

## 2. 中文翻译

发动机未能在规定的时间限制内起动，可能的原因是发动机供油不足、点火系统激励器供电不足或无供电，或燃油混合比不正确。若发动机在规定时间内未能起动，应将其关车。

在所有起动不理想的情况下，都必须关闭燃油和点火。继续带转压气机约 15 秒，以排出发动机内积聚的燃油。若无法带转（转动）发动机，应等待 30 秒的放油时间后再尝试下一次起动。

## 4. 语法解析

### ① 情态动词 can 的被动式 + 三项并列原因
**原句**：The engine failing to start within the prescribed time limit can be caused by lack of fuel to the engine, insufficient or no electrical power to the exciter in the ignition system, or incorrect fuel mixture.
**拆解**：主语 The engine failing to start within the prescribed time limit（名词 + 动名词构成复合主语）+ 谓语 can be caused（情态动词 + 被动语态）+ by 引出三个并列原因：lack of fuel、insufficient or no electrical power、incorrect fuel mixture。
**要点**：can be caused by 是故障分析的典型句式，表示“可能由……造成”，比 is caused by 留有余地。主语把“发动机未能起动”整件事名词化，比写成 The engine fails to start 更紧凑，也便于挂上时间状语。

### ② 条件从句 + 祈使句
**原句**：If the engine fails to start within the prescribed time, shut it down.
**拆解**：If 引导条件状语从句，用一般现在时表将来；主句为祈使句 shut it down；it 指代 the engine。
**要点**：手册步骤普遍采用“条件从句 + 祈使句”，主句不加 will。shut down 是“动词 + 副词”短语，宾语为代词时必须放在中间：shut it down，不能说 shut down it。

### ③ 省略形式的条件从句 + 介词 + 动名词
**原句**：If unable to motor (rotate) the engine, allow a 30-second fuel draining period before attempting another start.
**拆解**：If unable to motor… 是 If it is unable to… 的省略式；主句 allow a 30-second fuel draining period 为 allow + 宾语；before attempting 为介词 + 动名词作时间状语。
**要点**：条件从句主语与主句一致、谓语含 be 时可省略成“if + 形容词/介词短语”。before doing 表示“在做……之前”，比 before you attempt 更书面；注意 before 后不接不定式，不能写成 before to attempt。

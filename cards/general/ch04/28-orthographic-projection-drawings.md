# Orthographic Projection Drawings

## 1. 原文

To show the exact size and shape of all the parts of complex objects, several views are necessary. This is the system used in orthographic projection.

In orthographic projection, there are six possible views of an object, because all objects have six sides—front, top, bottom, rear, right side, and left side. Figure 4-11A shows an object placed in a transparent box, hinged at the edges.

The projections on the sides of the box are the views as seen looking straight at the object through each side. If the outlines of the object are drawn on each surface of the box, and the box is then opened [Figure 4-11B] to lay flat [Figure 4-11C], the result is a six-view orthographic projection.

It is seldom necessary to show all six views to portray an object clearly; therefore, only those views necessary to illustrate the required characteristics of the object are drawn.

One-, two-, and three-view drawings are the most common.

Regardless of the number of views used, the arrangement is generally as shown in Figure 4-11, with the front view as principal view. If the right-side view is shown, it will be to the right of the front view. If the left-side view is shown, it will be to the left of the front view. The top and bottom views, if included, will be shown in their respective positions relative to the front view.

## 2. 中文翻译

要表示复杂物体所有各部分的准确尺寸与形状，就必须采用若干个视图。正投影所用的正是这一方法。

在正投影中，一个物体可以有六个视图，因为所有物体都有六个面——前、顶、底、后、右侧和左侧。图 4-11A 示出一个被放入透明方箱中的物体，方箱沿各棱边设有铰链。

方箱各面上的投影，就是沿各个面直视物体时所看到的视图。如果把物体的轮廓画在方箱的每一个面上，再把方箱打开（图 4-11B）摊平（图 4-11C），所得结果就是一个六视图正投影。

要把一个物体表达清楚，很少需要画出全部六个视图；因此，只画那些足以表示物体所需特征的视图。

最常用的是单视图、双视图和三视图。

无论采用几个视图，布局一般如图 4-11 所示，以主视图（front view）为主体视图。若画出右视图，它位于主视图的右侧；若画出左视图，它位于主视图的左侧。顶视图和底视图若画出，则按各自相对于主视图的位置摆放。

局部视图　局部视图只表示物体的某一部分，但比主体视图更详细、比例更大。凡在图样他处另作局部表示的部位，通常在主体视图上用粗线加圈标出。

主体视图表示整个物体，而局部视图则是物体某一部分的放大图。

## 4. 语法解析

### ① It is seldom necessary to show all six views … ; therefore, only those views necessary to … are drawn（形式主语 + 形容词短语后置 + 被动）

**原句**：It is seldom necessary to show all six views to portray an object clearly; therefore, only those views necessary to illustrate the required characteristics of the object are drawn.

**拆解**：It 是形式主语，真正主语为不定式 to show all six views to portray an object clearly；seldom 是否定副词；分号后 therefore 引出结果，主语是 only those views，necessary to illustrate … 是形容词短语后置修饰 views，谓语 are drawn 为被动。

**要点**：it is + 形容词 + to do 是技术文本陈述「有无必要」的常用句型。those views necessary to do 等于 those views that are necessary to do，形容词短语后置时不能加逗号。被动 are drawn 隐去执行者（绘图者），与全节客观陈述的语气一致。

### ② Regardless of the number of views used, the arrangement is generally as shown in Figure 4-11, with the front view as principal view（让步介词短语 + with 复合结构）

**原句**：Regardless of the number of views used, the arrangement is generally as shown in Figure 4-11, with the front view as principal view.

**拆解**：Regardless of + 名词短语构成让步状语；主句主语 the arrangement，系动词 is + as shown in Figure 4-11（as 引导的方式／比较结构，shown 后省略了 it is）；with the front view as principal view 是 with 复合结构，as 引出身份。

**要点**：regardless of 后接名词或名词短语，若要接从句须写成 regardless of the fact that。with A as B 表示「以 A 作为 B」，译「以主视图为主体视图」比「和主视图作为……」通顺。number of views used 中 used 是过去分词后置定语。

### ③ If the outlines … are drawn …, and the box is then opened … to lay flat …, the result is a six-view orthographic projection（条件从句中的并列被动 + 目的不定式）

**原句**：If the outlines of the object are drawn on each surface of the box, and the box is then opened [Figure 4-11B] to lay flat [Figure 4-11C], the result is a six-view orthographic projection.

**拆解**：If 引导条件从句，从句内由 and 连接两个并列被动分句（are drawn / is opened）；to lay flat 是目的（结果）不定式；主句 the result is a six-view orthographic projection 为主系表结构。

**要点**：两个并列分句共用同一个 if，翻译时不必重复「如果」。open 在此是及物动词「打开、展开」，其被动 is opened；lay flat 中 flat 作主语补足语（the box lays flat）。six-view 这类「数词 + 名词」构成的复合形容词用连字符，名词不加 -s。

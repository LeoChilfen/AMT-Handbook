# Installation Drawing

> 通用 Ch 04 · Installation Drawing · 原文 PDF 第 126 页

## 1. 原文

An installation drawing is one that includes all necessary information for a part or an assembly in the final installed position in the aircraft. It shows the dimensions necessary for the location of specific parts with relation to the other parts and reference dimensions that are helpful in later work in the shop. [Figure 4-5]

## 2. 中文翻译

安装图是包含某个零件或组件在航空器上最终安装位置所需的全部信息的图纸。它给出确定特定零件相对于其他零件之位置所需的尺寸，以及有助于后续车间作业的参考尺寸。[图 4-5]

## 4. 语法解析

### ① one that includes all necessary information …（one 作代词 + that 定语从句）

**原句**：An installation drawing is one that includes all necessary information for a part or an assembly in the final installed position in the aircraft.

**拆解**：表语 one 是代词，指「一种图纸」；that includes … 是定语从句修饰 one；for a part or an assembly 说明信息所针对的对象；in the final installed position 与 in the aircraft 两个介词短语层层限定位置。

**要点**：one that … 是定义类句型的常用骨架（A is one that …），比重复 drawing 更简洁。installed 是过去分词作定语，final installed position 不能写成 final install position。

### ② dimensions necessary for …（形容词短语后置定语）

**原句**：It shows the dimensions necessary for the location of specific parts with relation to the other parts and reference dimensions that are helpful in later work in the shop.

**拆解**：谓语 shows 带两个并列宾语：the dimensions … 与 reference dimensions …；necessary for the location of specific parts 是形容词短语后置修饰 dimensions；with relation to the other parts 进一步限定 location；that are helpful in later work 是定语从句修饰 reference dimensions。

**要点**：necessary、available、essential 等形容词短语修饰名词时必须后置（dimensions necessary for …），译成汉语则前置。第二个宾语带 that 从句，读句时要在 and reference dimensions 处切开，避免把从句误挂到前一个宾语上。

### ③ helpful in later work（形容词 + in + 名词表「在某方面」）

**原句**：reference dimensions that are helpful in later work in the shop

**拆解**：be helpful in … 表示「在……方面有帮助」，in later work 是方面状语，in the shop 是地点定语修饰 work。

**要点**：helpful 后接 in 或 for 均可，in 更强调「在……过程中」。later work 应译「后续作业」而非「更晚的工作」。两个 in 短语连用是正常嵌套，翻译时由内向外展开：「后续车间作业中有帮助的」。

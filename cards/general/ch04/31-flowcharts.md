Logic Flowchart Another type of flowchart, developed specifically for analysis of digitally-controlled components and systems, is the logic flowchart. [Figure 4-23] A logic flowchart uses standardized symbols to indicate specific types of logic gates and their relationship to other digital devices in a system. Since digital systems make use of binary mathematics consisting of 1s and 0s, voltage or no voltage, a light pulse or no light pulse, and so forth, logic flowcharts consist of individual components that take an input and provide an output that is either the same as the input or opposite. By analyzing the input or multiple inputs, it is possible to determine the digital output or outputs.

## 4. 语法解析

### ① Another type of flowchart, developed specifically for …, is the logic flowchart（插入式过去分词定语 + 主谓一致）

**原句**：Another type of flowchart, developed specifically for analysis of digitally-controlled components and systems, is the logic flowchart.

**拆解**：主语中心词 Another type（单数），of flowchart 为后置定语；developed specifically for analysis of … 是过去分词短语，用两个逗号插入，后置修饰 flowchart；谓语 is，表语 the logic flowchart。

**要点**：主谓一致看中心词 type，故用 is，不受插入的复数 components 影响。过去分词短语插入主语与谓语之间属非限制性定语，可还原为 which was developed …；digitally-controlled 是「副词 + 过去分词」构成的复合形容词，必须带连字符。

### ② Since digital systems make use of …, logic flowcharts consist of components that … and provide an output that …（since 原因从句 + 并列定语从句）

**原句**：Since digital systems make use of binary mathematics consisting of 1s and 0s, voltage or no voltage, a light pulse or no light pulse, and so forth, logic flowcharts consist of individual components that take an input and provide an output that is either the same as the input or opposite.

**拆解**：Since 引导原因状语从句；consisting of … 是现在分词短语修饰 binary mathematics；主句主语 logic flowcharts，谓语 consist of；that take an input and provide an output 是定语从句修饰 components，其后 that is either the same as … or opposite 是第二个定语从句修饰 an output。

**要点**：since 在此表原因（「由于」），不表「自从」，判断依据是从句与主句是因果关系。consist of 不用被动，不能说 is consisted of。either A or B 连接两个表语；the same as 后接比较对象。

### ③ By analyzing the input or multiple inputs, it is possible to determine the digital output or outputs（by doing 方式状语 + it 形式主语）

**原句**：By analyzing the input or multiple inputs, it is possible to determine the digital output or outputs.

**拆解**：By + 动名词短语 analyzing the input or multiple inputs 作方式状语，置于句首；主句 it 为形式主语，真正主语是 to determine the digital output or outputs；possible 作表语。

**要点**：by doing 表手段，译「通过……」。it is possible to do 是技术文本的高频句型，比 you can 更客观。output or outputs 这种「单数 or 复数」写法表示「一个或多个」，与 input or multiple inputs 同理，翻译时不必逐字对译成「输出或输出们」。

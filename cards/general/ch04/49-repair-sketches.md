# Repair Sketches

> 通用 Ch 04 · Repair Sketches · 原文 PDF 第 146 页

## 1. 原文

A sketch is frequently drawn for repairs or for use in manufacturing a replacement part. Such a sketch must provide all necessary information to those who must make the repair or manufacture the part.

The degree that a sketch is complete depends on its intended use. Obviously, a sketch used only to represent an object pictorially need not be dimensioned. If a part is to be manufactured from the sketch, it should show all the necessary construction details.

## 2. 中文翻译

草图常用于修理，也用于制造替换件。这类草图必须向必须实施修理或制造该零件的人提供全部必要信息。

草图的完整程度取决于其预期用途。显然，仅用于立体地表现某物体的草图不必标注尺寸；而若要照草图制造零件，草图就应给出全部必要的结构细节。

## 4. 语法解析

### ① to those who must make the repair or manufacture the part（定语从句 + 情态动词）

**原句**：Such a sketch must provide all necessary information to those who must make the repair or manufacture the part.

**拆解**：主句 Such a sketch must provide all necessary information to those；who 引导定语从句修饰 those，从句内 must make 与 (must) manufacture 并列，共用情态动词和宾语 the repair / the part。

**要点**：those who … 是「那些……的人」的固定结构，手册常用来代替具体人称，既概括又不指明岗位。并列谓语共用情态动词时，第二个 must 可省，但宾语必须各自清楚：make the repair 与 manufacture the part 是两件事。

### ② The degree that a sketch is complete depends on its intended use（that 从句 + depend on）

**原句**：The degree that a sketch is complete depends on its intended use.

**拆解**：主语 The degree 后接 that 从句说明是「哪一方面的程度」，可视为同位语从句；谓语 depends on（取决于）用第三人称单数，与中心词 degree 一致；宾语 its intended use 中的 its 指 sketch。

**要点**：depend on 的主语常是抽象名词（degree、result、success），后接名词而非从句。注意主语是 The degree 而不是 a sketch，所以谓语用 depends 而非 depend——中间插入了从句，容易被误判。

### ③ is to be manufactured … it should show（be to be done 表规定 + should 表应然）

**原句**：If a part is to be manufactured from the sketch, it should show all the necessary construction details.

**拆解**：If 引导条件状语从句，从句用 is to be manufactured（be to + be + 过去分词），表示「按计划、按要求要被制造」；主句 it should show … 中 should 表「应当」。

**要点**：be to be done 在技术文件中表示「将要／按规定被……」，比 will be done 多一层「按要求」的意味。条件句用现在时表将来是常规，不要写成 will be manufactured。注意 from the sketch 是「照图」，不是「从图里」。

### ④ used only to represent an object pictorially（过去分词短语作后置定语）

**原句**：Obviously, a sketch used only to represent an object pictorially need not be dimensioned.

**拆解**：主语 a sketch 后接过去分词短语 used only to represent an object pictorially 作后置定语（相当于 which is used only to …）；谓语 need not be dimensioned 为情态动词否定 + 被动。

**要点**：单个分词作定语前置（a used car），带状语的分词短语必须后置。need not be done 表示「不必被……」，与 must not be done（禁止）意思相反，这一对在维修文件中极易混淆：need not 是「可以不」，must not 是「不许」。

# Removed Section

> 通用 Ch 04 · Removed Section · 原文 PDF 第 127 页

## 1. 原文

A removed section illustrates parts of an object. It is drawn like revolved sections, except it is placed at one side and often drawn to a larger scale than the view indicated to bring out pertinent details.

Figure 4-9 is an illustration of removed sections. Section A-A shows the cross-sectional shape of the object at cutting plane line A-A. Section B-B shows the cross-sectional shape at cutting plane line B-B. These sectional views are drawn to the same scale as the principal view.

## 2. 中文翻译

移出剖视图（removed section）用以表示物体的局部。它的画法与被旋转剖视图（revolved section）相同，区别在于：它被画在视图的一侧，并且常按比所指示视图更大的比例尺绘制，以便把相关细节表达清楚。

图 4-9 是移出剖视图的示例。剖视图 A-A 表示物体在剖切面线 A-A 处的横截面形状；剖视图 B-B 表示物体在剖切面线 B-B 处的横截面形状。这些剖视图按与主视图相同的比例尺绘制。

## 4. 语法解析

### ① It is drawn like revolved sections, except it is placed at one side（被动语态 + except 引导从句）

**原句**：It is drawn like revolved sections, except it is placed at one side and often drawn to a larger scale than the view indicated to bring out pertinent details.

**拆解**：主句 It is drawn 为一般现在时被动；like revolved sections 是方式状语；except 后接并列的两个被动谓语 is placed 与 (is) often drawn，第二个 are 被省略；a larger scale than the view indicated 是比较结构，indicated 为过去分词后置定语；to bring out … 是目的状语。

**要点**：except 在此是连词，后面必须接完整从句；若只接名词短语则要用 except for。be drawn to a scale 是「按……比例尺绘制」的固定说法，用 to 不用 at。the view indicated 意为「（剖切面线上）所指明的那个视图」，单个过去分词后置即可代替定语从句。

### ② These sectional views are drawn to the same scale as the principal view（the same … as 同级比较）

**原句**：These sectional views are drawn to the same scale as the principal view.

**拆解**：主语 These sectional views，被动谓语 are drawn；to the same scale 是方式状语；as the principal view 引出比较对象，构成 the same + 名词 + as 结构。

**要点**：表示「与……相同」用 the same … as，不能写成 the same … with。注意它与 as … as 的分工：前者比较名词所代表的事物（同一个比例尺），后者比较形容词或副词的程度（as large as）。手册中 the same scale as、the same number as 都是高频搭配。

### ③ Section A-A shows the cross-sectional shape of the object at cutting plane line A-A（图表说明句的时态与介词）

**原句**：Section A-A shows the cross-sectional shape of the object at cutting plane line A-A.

**拆解**：主语 Section A-A，谓语 shows（第三人称单数一般现在时）；宾语 the cross-sectional shape；of the object 与 at cutting plane line A-A 两个介词短语均作后置修饰，分别交代「谁的截面」与「在何处剖切」。

**要点**：说明图上内容一律用一般现在时、主动语态（shows／illustrates／indicates），不用过去时。at cutting plane line A-A 的 at 表「在……位置处」，不要用 on。A-A 这种同一字母重复标注是剖切面线的行业写法，读作「A 至 A」。

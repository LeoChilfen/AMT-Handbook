# Power of Zero

> 通用 Ch 03 · Power of Zero · 原文 PDF 第 108 页

## 1. 原文

Any non-zero number raised to the zero power always equals 1.

70 = 1 1810 = 1 (–24)0 = 1

Negative Powers A number with a negative power equals its reciprocal with the same power made positive.

Example: The number 2 -3 is read as “2 to the negative 3rd power,” and is calculated by:

2-3 = 1 23 = 1 2 × 2 × 2 = 1 8 When using a calculator to raise a negative number to a power, always place parentheses around the negative number (before raising it to a power) so that the entire number gets raised to the power.

## 2. 中文翻译

任何非零数的零次幂恒等于 1。

70 = 1 1810 = 1 (–24)0 = 1

负指数 带负指数的数，等于把同一个幂次改成正值后所得的倒数。

例：数 2 -3 读作“2 的负 3 次方”，按下列方式计算：

2-3 = 1 23 = 1 2 × 2 × 2 = 1 8 用计算器把一个负数提升到某次幂时，务必先给这个负数加上括号（再求幂），这样整个数才会被提升到该幂次。

## 4. 语法解析

### ① 过去分词短语作后置定语

**原句**：Any non-zero number raised to the zero power always equals 1.

**拆解**：主语中心词 Any non-zero number，raised to the zero power 为过去分词短语作后置定语（= that is raised to the zero power）；谓语 equals，always 为状语，宾语 1。

**要点**：带介词短语的分词定语必须后置，不能写成 any non-zero raised-to-the-zero-power number。这里用过去分词是因为数是「被提升」的，不是自己提升。同结构：a number multiplied by itself、the value expressed in inches。

### ② with 复合结构（with + 宾语 + 过去分词）

**原句**：A number with a negative power equals its reciprocal with the same power made positive.

**拆解**：主语 A number，with a negative power 为介词短语作后置定语；谓语 equals；宾语 its reciprocal，with the same power made positive 是 with 复合结构 —— with + 名词 the same power + 过去分词 made positive，作后置定语说明该倒数的构成。

**要点**：with 复合结构可表伴随、方式或状态：with + 宾语 + 过去分词（被动关系）、with + 宾语 + 现在分词（主动、进行）。此处 the same power 与 make 是被动关系（幂被改为正），故用 made positive。译成中文常处理为「……，且该幂次取正值」。

### ③ When + 动名词短语作状语 + 祈使句 + so that 目的从句

**原句**：When using a calculator to raise a negative number to a power, always place parentheses around the negative number (before raising it to a power) so that the entire number gets raised to the power.

**拆解**：When using a calculator … 为「When + 动名词短语」作时间状语，其逻辑主语与主句祈使句隐含的 you 一致；主句 place parentheses around the negative number 是无主语祈使句；so that 引导目的状语从句 the entire number gets raised to the power。

**要点**：When + 动名词相当于 When you use a calculator，状语从句省略了与主句相同的主语和 be 动词，这种省略在技术说明里极常见。so that 表目的，从句常用情态动词或 get + 过去分词；get raised 比 be raised 更口语、更强调「结果变成」。

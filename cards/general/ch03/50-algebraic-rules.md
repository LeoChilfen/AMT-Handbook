# Algebraic Rules

> 通用 Ch 03 · Algebraic Rules · 原文 PDF 第 112 页

## 1. 原文

When solving for a variable in an equation, you can add, subtract, multiply, or divide the terms in the equation (you do the same to both sides of the equals sign) to get the variable onto one side of the equals sign.

Examples: Solve the following equations for the value N.

3N = 21 To solve for N, divide both sides by 3.

3N ÷ 3 = 21 ÷ 3 N = 7 N + 17 = 59 To solve for N, subtract 17 from both sides.

N + 17 – 17 = 59 – 17 N = 42 N – 22 = 100 To solve for N, add 22 to both sides.

N – 22 + 22 = 100 + 22 N = 122 N 5 = 50 To solve for N, multiply both sides by 5.

N × 5 = 50 × 5 N = 250

## 2. 中文翻译

在方程中求解某个变量时，你可以对方程中的各项进行加、减、乘、除运算（对等号两边做同样的运算），从而把该变量移到等号的一侧。

例：求解下列方程中的 N 值。

3N = 21　要求出 N，两边同除以 3。

3N ÷ 3 = 21 ÷ 3　N = 7　N + 17 = 59　要求出 N，两边同减去 17。

N + 17 – 17 = 59 – 17　N = 42　N – 22 = 100　要求出 N，两边同加上 22。

N – 22 + 22 = 100 + 22　N = 122　N 5 = 50　要求出 N，两边同乘以 5。

N × 5 = 50 × 5　N = 250

## 4. 语法解析

### ① when + 动名词作时间状语

**原句**：When solving for a variable in an equation, you can add, subtract, multiply, or divide the terms in the equation (you do the same to both sides of the equals sign) to get the variable onto one side of the equals sign.

**拆解**：When solving for a variable … 是「连词 + 现在分词」的时间状语，省略了主语 you 与 be 动词；主句 you can add, subtract, multiply, or divide the terms …；括号内补充「两边做同样运算」这一原则；to get the variable onto one side … 是不定式作目的状语。

**要点**：when / while + 动名词要求逻辑主语与主句一致（此处都是 you）；括号内是完整的独立分句，起解释作用，翻译时可保留括号。solve for a variable 是固定搭配，意为「对某个变量求解」。

### ② 祈使句 + 目的状语 + divide A by B

**原句**：To solve for N, divide both sides by 3.

**拆解**：To solve for N 是不定式作目的状语；主句 divide both sides by 3 为无主语祈使句；divide A by B 中 by 引出除数。

**要点**：解题步骤类文本统一用祈使句，不带主语；四则运算的介词各不相同：divide / multiply both sides by 3、subtract 17 from both sides、add 22 to both sides，记搭配比记规则更有效。

### ③ 括号插入的独立分句

**原句**：(you do the same to both sides of the equals sign)

**拆解**：括号内是一个完整分句：主语 you，谓语 do，宾语 the same，to both sides of the equals sign 是介词短语作状语，与前面的 add, subtract, multiply, or divide 相呼应。

**要点**：do the same to sth 意为「对……做同样的事」，介词用 to；the same 在此是代词性用法，后接 to 短语而不是 as 从句——用 the same as 就变成比较了。手册用括号插入解释性分句，不打断主干。

## 4. 语法解析

### ① 目的不定式 + first 标记步骤：To express a fraction as a percentage, first change…

**原句**：To express a fraction as a percentage, first change the fraction to a decimal number

**拆解**：To express a fraction as a percentage 是目的状语；主句为祈使句，谓语 change，宾语 the fraction，to a decimal number 作宾语补足语（由分数变为小数）；first 是顺序副词，预示后面还有 then 等步骤。

**要点**：步骤说明常以「目的不定式 + 祈使句 + 顺序副词」构成，first / next / then / finally 把操作串成流程，读时要按这串副词把握先后。change A to B 与 convert A to B 同义，都是「把 A 换成 B」，介词用 to；注意此处的 percentage 指带 % 的结果，不是泛指「百分比的概念」。

### ② by + 动名词表方式：by dividing the numerator by…

**原句**：by dividing the numerator by

**拆解**：by 后接动名词 dividing，构成方式状语（＝通过除法），说明「把分数换成小数」的具体做法；dividing 的宾语是 the numerator，by 再引出除数（原文此处被版面截断，按算式应为分母 denominator）。

**要点**：by + -ing 是手册说明「靠什么手段完成动作」的常用结构，译作「用／通过……」。注意 by 后必须跟动名词，不能跟不定式（by divide 是错的）。本句里 by 出现两次、身份不同：前一个 by 是介词（引出手段），后一个 by 与 divide 搭配（除以），读时要把两个 by 分开看，不要当成同一个结构。

### ③ 标题式不定式：To solve for N:

**原句**：To solve for N:

**拆解**：不定式短语 To solve for N 单独成句并加冒号，充当解题步骤的标题，后面的算式是它的「正文」；solve for 是固定搭配，for 引出待求的未知量。

**要点**：数学与工程文本常把 To solve for X / To find Y / To convert … 这类不定式短语当小标题用，后面直接用冒号接算式，不再补主谓。solve for 与 solve 不同：solve an equation 是「解方程」，solve for X 是「求出 X」。译文可照用「求 N：」，不必补成完整句子。

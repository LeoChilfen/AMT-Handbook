# The Binary Number System

> 通用 Ch 03 · The Binary Number System · 原文 PDF 第 123 页

## 1. 原文

The binary number system has only two digits: 0 and 1. The prefix in the word “binary” is a Latin root for the word “two” and its use was first published in the late 1700s. The use of the binary number system is based on the fact that switches or valves have two states: open or closed (on/off).

Currently, one of the primary uses of the binary number system is in computer applications. Information is stored as a series of 0s and 1s, forming strings of binary numbers. An early electronic computer, ENIAC ( Electronic Numerical Integrator and Calculator), was built in 1946 at the University of Pennsylvania and contained 17,000 vacuum tubes, along with 70,000 resistors, 10,000 capacitors, 1,500 relays, 6,000 manual switches and 5 million soldered joints. Computers obviously have changed a great deal since then, but are still based on the same binary number system. The binary number system is also useful when working with digital electronics because the two basic conditions of electricity, on and off, can be represented by the two digits of the binary number system. When the system is on, it is represented by the digit 1, and when it is off, it is represented by the digit 0.

## 2. 中文翻译

二进制数制只有两个数字：0 和 1。「binary」（二进制）一词中的词头是拉丁语中表示「二」的词根，该词的这种用法最早于 18 世纪后期发表。二进制数制的应用基于这样一个事实：开关或活门只有两种状态——断开或闭合（开／关）。

目前，二进制数制的主要用途之一是在计算机应用中。信息以一串 0 和 1 的形式存储，构成二进制数串。早期电子计算机 ENIAC（Electronic Numerical Integrator and Calculator，电子数字积分计算机）于 1946 年在宾夕法尼亚大学建成，装有 17,000 只真空管，以及 70,000 个电阻、10,000 个电容、1,500 个继电器、6,000 个手动开关和 500 万个焊接接头。此后计算机显然发生了巨大变化，但仍基于同一套二进制数制。在处理数字电子设备时二进制数制同样有用，因为电的两种基本状态——通与断——可以用二进制数制的两个数字来表示。系统处于接通状态时用数字 1 表示，处于断开状态时用数字 0 表示。

## 4. 语法解析

### ① be based on the fact that：同位语从句

**原句**：The use of the binary number system is based on the fact that switches or valves have two states: open or closed (on/off).

**拆解**：主干为 The use of the binary number system is based on the fact；that switches or valves have two states 是同位语从句，说明 fact 的具体内容；冒号后的 open or closed (on/off) 是对 two states 的列举解释。

**要点**：be based on the fact that … 是引出论据的固定框架；fact 后的 that 从句是同位语从句，不能用 which 引导（which 在此会变成定语从句，含义走偏）。on/off 是「通／断」的口语写法，机务文件里也写作 ON/OFF。

### ② 同位语 + 并列谓语 + along with 不改变主谓一致

**原句**：An early electronic computer, ENIAC ( Electronic Numerical Integrator and Calculator), was built in 1946 at the University of Pennsylvania and contained 17,000 vacuum tubes, along with 70,000 resistors, 10,000 capacitors, 1,500 relays, 6,000 manual switches and 5 million soldered joints.

**拆解**：主语 An early electronic computer，ENIAC (…) 是同位语；谓语为并列的 was built … and contained …；along with … 引出附加成分，不参与主谓一致。

**要点**：along with / together with / as well as 引出的成分不改变主语的单复数，谓语仍与前一个主语一致（此处主语是 computer，故用 was built）。同位语两侧用逗号隔开，可还原为 which was called ENIAC。

### ③ since then + 现在完成时与并列谓语的省略

**原句**：Computers obviously have changed a great deal since then, but are still based on the same binary number system.

**拆解**：obviously 是句子副词；have changed 为现在完成时，since then 表示「从那时起」；but 连接并列谓语 are still based on …，其后省略了主语 Computers。

**要点**：since + 时间点、since then 是现在完成时的典型标志，强调「直到现在」的变化。but 后只保留 are，属并列谓语的省略，阅读时要自行补回主语；这类省略在技术文本里很常见，不能误认为是另一个新主语。

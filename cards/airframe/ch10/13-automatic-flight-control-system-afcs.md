# Automatic Flight Control System (AFCS)

> 机体 Ch 10 · Automatic Flight Control System (AFCS) · 原文 PDF 第 582 页

## 1. 原文

An aircraft autopilot with many features and various autopilot related systems integrated into a single system is called an automatic flight control system (AFCS). These were formerly found only on high-performance aircraft. Currently, due to advances in digital technology for aircraft, modern aircraft of any size may have AFCS.

AFCS capabilities vary from system to system. Some of the advances beyond ordinary autopilot systems are the extent of programmability, the level of integration of navigational aids, the integration of flight director and autothrottle systems, and combining of the command elements of these various systems into a single integrated flight control human interface.

It is at the AFCS level of integration that an autothrottle system is integrated into the flight director and autopilot systems with glide scope modes so that auto landings are possible. Small general aviation aircraft being produced with AFCS may lack the throttle-dependent features.

Modern general aviation AFCS are fully integrated with digital attitude heading and reference systems (AHRS) and navigational aids including glideslope. They also contain modern computer architecture for the autopilot (and flight director systems) that is slightly different than described above for analog autopilot systems. Functionality is distributed across a number of interrelated computers and includes the use of intelligent servos that handle some of the error correction calculations. The servos communicate with dedicated avionics computers and display unit computers through a control panel, while no central autopilot computer exists.

## 2. 中文翻译

把具有多种功能、并将各种与自动驾驶仪相关的系统集成于单一系统的飞机自动驾驶仪，称为自动飞行控制系统（AFCS）。这类系统过去只出现在高性能飞机上。如今，由于飞机数字技术的进步，任何尺寸的现代飞机都可能装备 AFCS。

AFCS 的能力因系统而异。相比普通自动驾驶仪系统，其进步之处包括可编程的程度、导航设备的集成水平、飞行指引仪与自动油门系统的集成，以及把上述各种系统的指令元件合并为单一的综合飞行控制人机接口。

正是在 AFCS 这一集成层面上，自动油门系统才与带下滑道模式的飞行指引仪和自动驾驶仪系统集成在一起，从而使自动着陆成为可能。而装有 AFCS 的小型通用航空飞机，可能不具备这些依赖油门的自动着陆功能。

现代通用航空 AFCS 与数字式姿态航向参考系统（AHRS）以及包括下滑道在内的导航设备完全集成。它们还采用面向自动驾驶仪（及飞行指引仪系统）的现代计算机架构，与上文所述的模拟式自动驾驶仪系统略有不同。其功能分布在若干相互关联的计算机上，并采用智能舵机来承担部分误差修正计算。舵机通过控制面板与专用航空电子计算机和显示组件计算机通信，而系统中并不存在中央自动驾驶仪计算机。

## 4. 语法解析

### ① with 复合结构作后置定语 + 被动语态
**原句**：An aircraft autopilot with many features and various autopilot related systems integrated into a single system is called an automatic flight control system (AFCS).
**拆解**：主语中心词 An aircraft autopilot，后接 with 复合结构（with + 宾语 many features and various autopilot related systems + 过去分词 integrated into a single system）作后置定语；谓语 is called 为被动语态，an automatic flight control system 为主语补足语。
**要点**：with 复合结构里宾语与补足语是被动关系，故用过去分词 integrated。主语中心词与谓语之间隔了 14 个词，读句时先抓 autopilot ... is called 这条骨架，再回头补 with 短语。

### ② 四项并列作表语
**原句**：Some of the advances beyond ordinary autopilot systems are the extent of programmability, the level of integration of navigational aids, the integration of flight director and autothrottle systems, and combining of the command elements of these various systems into a single integrated flight control human interface.
**拆解**：主语 Some of the advances beyond ordinary autopilot systems；系动词 are；后面四个名词性短语并列作表语——the extent of…、the level of integration of…、the integration of…、and combining of…，前三项是名词，末项是动名词，靠 and 收尾。
**要点**：四项并列都挂在 are 后面，中间用逗号分隔，最后一项前才有 and；漏看 and 会把末项误读成新分句。combining 用动名词是为了与前面几个抽象名词保持同构。

### ③ 强调句 It is ... that + so that 目的从句
**原句**：It is at the AFCS level of integration that an autothrottle system is integrated into the flight director and autopilot systems with glide scope modes so that auto landings are possible.
**拆解**：It is + 被强调的地点状语 at the AFCS level of integration + that 引出其余部分；从句主语 an autothrottle system，谓语 is integrated into 为被动语态；so that auto landings are possible 为目的状语从句。
**要点**：去掉 It is ... that 后句子仍成立，可据此与 it 作形式主语区分。被强调的是状语而非主语，所以 that 不能换成 which；so that 在此表目的（“以便”），不是结果。

### ④ 并列谓语 + that 定语从句
**原句**：Functionality is distributed across a number of interrelated computers and includes the use of intelligent servos that handle some of the error correction calculations.
**拆解**：主语 Functionality 带两个并列谓语：is distributed（被动）和 includes；that handle some of the error correction calculations 是定语从句，修饰 servos，关系词 that 在从句中作主语。
**要点**：第二个谓语 includes 与 is distributed 共用一个主语，不是新的分句。定语从句谓语用复数 handle，是因为先行词 servos 为复数——主谓一致要看先行词，不看主句主语。

### ⑤ while 引导对比并列
**原句**：The servos communicate with dedicated avionics computers and display unit computers through a control panel, while no central autopilot computer exists.
**拆解**：前一分句主语 The servos，谓语 communicate with，宾语两台计算机，through a control panel 为方式状语；while 引出对比分句，说明“却没有中央计算机”。
**要点**：while 在此不是“当……时候”，而是对比连词，相当于“而”。后半句是 there be 句型的变体（no central autopilot computer exists），中文宜译成“而系统中并不存在……”，不要译成时间关系。

# Ch 08 · Cleaning & Corrosion Control（清洁与腐蚀控制）

> 依据：FAA《AMT Handbook》General 分册第 8 章（PDF 第 326–354 页，正文页码 8-1 至 8-29）。深入资料指向 AC 43-4《Corrosion Control for Aircraft》、AC 43.13-1《Acceptable Methods, Techniques, and Practices—Aircraft Inspection and Repair》。

## 1. 一句话

讲飞机金属腐蚀的成因与各种形式、识别与去除工艺，以及清洁、表面处理和涂层一整套防腐维护手段。

## 2. 本章要点

1. **腐蚀是"金属被化学或电化学作用变回金属化合物"**，可在表面也可在内部发生；它不只是表面变丑，蚀坑会成为裂纹源，有些腐蚀在涂层下蔓延直至零件失效。
2. **电化学腐蚀要四个条件同时成立**：① 受腐蚀的金属（anode）；② 腐蚀倾向更小的异种导体（cathode）；③ 连续的导电液通路（electrolyte）；④ 阴阳极之间的电接触（铆钉、螺栓、金属对金属）。**去掉任意一条，腐蚀即停止**——这就是"洗干净 + 涂层完好"能防腐的全部道理。
3. **直接化学腐蚀与电化学腐蚀的区别在于阴阳极反应发生的位置**：直接化学腐蚀（溅出的电瓶酸、残留钎焊熔剂、滞留的碱性清洗液）的氧化与还原在**同一点同时**发生；电化学腐蚀的两处变化相隔一段可测距离。
4. **铝合金有三种特别严重的攻击形式**：穿透铝管壁的点蚀（penetrating pit-type）、持续应力下的应力腐蚀开裂、以及热处理不当合金的晶间腐蚀。
5. **环境严重度决定维护频次**：mild 区每 90 天、moderate 区每 45 天、severe 区每 15 天做清洁、检查、润滑、防腐。
6. **清洁是检查的前置条件**：所有腐蚀检查都先彻底清洁，再目视（手电、反光镜、5–10X 放大镜）找可疑区，最后对可疑区做详细检查；涂层会掩盖初期腐蚀，只能靠鼓包、起皮、掉漆、结块这些"不平整"发现。
7. **机械去除有严格的金属隔离纪律**：钢丝刷、钢丝棉、钢质工具绝不可用于铝、镁、钛；非织造研磨垫（nonwoven abrasive pad）不得跨金属混用，嵌进去的钢铁颗粒造成的腐蚀比原来的腐蚀更麻烦。
8. **化学处理必须当天上漆**：铬酸类抑制剂处理后，最迟须在同一日恢复涂层；舱内使用可燃溶剂时，距使用点 5 ft 处可燃蒸气达爆炸下限 25% 即须中止作业。

## 3. 术语对照（英文 | 中文 | 一句话解释）

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| corrosion | 腐蚀 | 金属受化学或电化学作用而劣化 |
| direct chemical attack | 直接化学腐蚀 | 裸表面直接接触强碱液或腐蚀性气体，阴阳极反应同点同时发生 |
| electrochemical attack | 电化学腐蚀 | 阳极区与阴极区经电解液构成回路，是机上结构腐蚀的主要形式 |
| anode / anodic area | 阳极 / 阳极区 | 失去电子、被氧化腐蚀的一方 |
| cathode / cathodic area | 阴极 / 阴极区 | 腐蚀倾向较小、接受电子的一方 |
| electrolyte | 电解液 | 能导电的连续液膜，通常是含盐的水 |
| galvanic corrosion | 电偶腐蚀 | 两种异种金属在电解液中电接触发生的腐蚀 |
| dissimilar metal corrosion | 异种金属腐蚀 | 异种金属接触处绝缘破损后发生的电偶作用，常藏在看不见的接合面 |
| concentration cell corrosion | 浓差电池腐蚀 | 同一金属因溶液浓度差形成的电池，又名缝隙腐蚀 |
| metal ion concentration cell | 金属离子浓差电池 | 搭接面下溶液滞留、离子浓度高，缝外低浓度处为阳极 |
| oxygen concentration cell | 氧浓差电池 | 垫片、木、橡胶下缺氧处为阳极；不锈钢尤易发生 |
| active-passive cell | 活化-钝化电池 | 钝化膜被污物压破，小面积活化金属对大面积钝化膜，快速点蚀 |
| pitting corrosion | 点蚀 | 表面白/灰粉状沉积，去掉后见小孔，可深达结构件内部 |
| intergranular corrosion | 晶间腐蚀 | 沿晶界发生的腐蚀，源于合金组织不均匀，可无表面迹象 |
| exfoliation corrosion | 剥蚀（层状剥落） | 晶间腐蚀的高级形态，腐蚀产物撑起表层晶粒；挤压型材多见 |
| stress-corrosion cracking | 应力腐蚀开裂 | 恒定或循环应力 + 腐蚀环境共同作用；SCC |
| fretting corrosion | 微动腐蚀 | 两贴合面间微小相对滑动造成的局部磨损腐蚀，又名 false brinelling |
| fatigue corrosion | 疲劳腐蚀 | 循环应力 + 腐蚀环境，使失效应力降到远低于未腐蚀件的疲劳极限 |
| filiform corrosion | 丝状腐蚀 | 有机涂层下虫迹状腐蚀产物，聚氨酯漆面尤易发生 |
| Alclad | 包铝 | 在铝合金表面覆一层纯铝以提高耐蚀性 |
| anodizing | 阳极氧化 | 铝件作阳极在电解槽中生成氧化铝膜，增厚增密天然氧化膜 |
| alodizing | 阿洛丁处理（化学氧化） | 用 Bonderite 等化学转化膜处理铝件，因简便正快速取代阳极氧化 |
| chromic acid inhibitor | 铬酸抑制剂 | 10% 铬酸加少量硫酸，用于恢复铝、镁表面氧化膜 |
| zinc chromate primer | 锌铬酸盐底漆 | 异种金属接触面的隔离底漆，常与环氧底漆并用 |
| nonwoven abrasive pad | 非织造研磨垫 | 替代钢丝棉的清洁/除锈材料，不得跨金属混用 |
| faying surface | 搭接面（贴合面） | 两层结构件相贴的界面，缝隙腐蚀与滞留液的高发处 |
| smoking rivet | 发烟铆钉 | 铆钉周围一圈黑环，微动腐蚀的典型外观 |
| SDS | 安全数据表 | 使用任何化学品前须查阅的处理与危害信息 |
| VOC | 挥发性有机化合物 | 受环保法规限制的溶剂排放物，推动水性清洗剂与水性漆 |
| DER | 委任工程代表 | 厂家损伤限制不足时，由 DER 评估损伤 |

## 4. 关键数字与公式

| 项目 | 数值 / 规定 |
|---|---|
| 环境分区维护间隔 | mild 每 90 天、moderate 每 45 天、severe 每 15 天（清洁、检查、润滑、防腐一并做） |
| 丝状腐蚀发生条件 | 相对湿度 78–90%，且表面略显酸性 |
| 丝状腐蚀预防储存条件 | 相对湿度低于 70% |
| 铝天然氧化膜厚度 | 0.001"–0.0025"（光滑氧化层，不视为有害腐蚀） |
| 目视检查工具 | 手电、检查镜、5–10X 放大镜 |
| 脱漆剂涂敷厚度 | 1/32"–1/16" |
| 脱漆剂停留时间 | 10 分钟至数小时（视温度、湿度、漆层状况） |
| 铝表面铬酸处理停留 | 至少 5 分钟，然后冲水或湿布擦除 |
| 铝（未涂漆面）二铬酸钠+三氧化铬处理停留 | 5–20 分钟 |
| 镁件铬酸（加硫酸）处理停留 | 5–20 分钟，余液不可留在表面自然干燥 |
| 坑形修整比例 | 长:深 = 20:1；清理区宽度 ≥10 倍深度、长度 ≥20 倍深度；密集多坑时相邻坑间按 5D MIN、10D MIN 过渡 |
| 凹坑轴向 | 机翼与平尾顺翼展、机身顺纵向、垂尾顺垂直方向作椭圆形 |
| 异种金属隔离（不含镁） | 至少 2 层锌铬酸盐或（优先）环氧底漆，层间空气干燥 6 小时 |
| 异种金属隔离（含镁） | 每面至少 2 层底漆 + 0.003" 厚压敏乙烯胶带；胶带影响装配、有相对运动或使用温度 >250 °F 时改用至少 3 层底漆 |
| 钛的有色氧化 | 700 °F（370 °C）以上出现有色表面氧化物；低温下无可视腐蚀产物 |
| 溶剂闪点要求 | 一般清洁溶剂闪点不低于 105 °F；Stoddard 溶剂 100–140 °F（略高于 105 °F） |
| 禁用低闪点溶剂 | Class I（闪点低于 100 °F）：丙酮、AVGAS、MEK、石脑油、甲苯不得用于飞机清洁/翻新 |
| 脂族石脑油闪点 | 约 80 °F（用于喷漆前擦洗，也可用于亚克力和橡胶） |
| MEK 闪点 | 约 24 °F，吸入有毒 |
| 舱内通风限值 | 距使用点 5 ft 处可燃蒸气不超过爆炸下限的 25%，超限须紧急更改作业 |
| 灭火器配置 | 舱门口至少 20-B 手提灭火器；或以 4-A 以上 A 类 / 20-B 以上 B 类替代；有铝腐蚀顾虑时不得使用 ABC 干粉 |
| 非离子洗涤剂配比 | 干洗溶剂中 3–5% 溶液，用于软化去除厚重防腐涂层 |
| 阿洛丁冲洗时间 | 加压淡水冲 10–15 秒；Bonderite 后清水冲 15–30 秒；再入 Deoxylyte 槽冲 10–15 秒 |
| 铬酸抑制剂配比 | 10%（重量）铬酸，加少量硫酸活化 |
| 研磨纸 | 氧化铝 300 目或更细；P-C-451 Type I Class 2 有 1 1/2" 与 2" 宽 |
| 镁铸件浸海水 | 发动机机匣浸海水一夜即可被完全穿透 |
| 适用规范 | AC 43-4、AC 43.13-1、MIL-DTL-5541F / AMS-C-5541A、MIL-C-5541、MIL-C-22543A、MIL-C-5410 Type I/II、P-D-680、P-C-451 |

## 5. 结构 / 系统 / 部件

**腐蚀分类树（本章的组织骨架）**

- 两大类
  - Direct chemical attack（直接化学腐蚀）— 电瓶酸/酸雾、未清干净的钎焊熔剂、滞留的碱性清洗液
    - 熔剂残留吸湿 → 严重点蚀；浓碱液须密封存放并远离飞机
  - Electrochemical attack（电化学腐蚀）— 占机上结构件腐蚀的绝大多数
    - 局部电池：同一合金内不同成分电位不同，活性高者为阳极
- 常见形式
  - Surface / uniform etch（均匀表面腐蚀）
  - Filiform（丝状，有机涂层下）
  - Pitting（点蚀，最破坏性、最剧烈之一）
  - Dissimilar metal / Galvanic（异种金属 / 电偶）
  - Concentration cell（浓差电池）＝ crevice corrosion：metal ion cell、oxygen cell、active-passive cell
  - Intergranular（晶间）→ Exfoliation（剥蚀，其可见形态）
  - Stress-corrosion cracking（应力腐蚀开裂）
  - Fretting（微动，又名 false brinelling）
  - Fatigue corrosion（疲劳腐蚀，两阶段：先腐蚀+循环应力造成点蚀与裂纹，再裂纹扩展）

**电化学腐蚀单元（Figure 8-5）**

- 阳极（受蚀金属）— 电解液连续通路 — 阴极（异种导体）— 外部电子通路（金属接触）
- 任一环节断开即无腐蚀；涂一层完整有机膜即可断开电解液与电极的接触

**电偶序（Figure 8-6，由易腐蚀到耐腐蚀，节选）**

- 镁 → 镁合金 → 锌 → 铝 1100 → 镉 → 铝 2024-T4 → 钢/铁 → 铸铁 → 铬铁(活性) → 304/316 不锈钢(活性) → 铅锡焊料 → 铅 → 锡 → 镍(活性) → Inconel(活性) → Hastelloy C(活性) → 黄铜 → 铜 → 青铜 → 铜镍合金 → Monel → 银焊料 → 镍(钝化) → Inconel(钝化) → 铬铁(钝化) → 304/316(钝化) → Hastelloy C(钝化) → 银 → 钛 → 石墨 → 金 → 铂

**防护体系的层次**

- 基体：耐蚀合金（加入合金元素）
- 化学转化膜：anodizing（阳极氧化，MIL-DTL-5541F/AMS-C-5541A）、alodizing（Bonderite + Deoxylyte）、铬酸抑制剂、二铬酸钠溶液、MIL-C-5541 商用活化铬酸盐混合物
- 底漆：锌铬酸盐底漆或环氧底漆（异种金属接触面加倍层数）
- 面漆：催化聚氨酯磁漆、水性聚氨酯磁漆、双组分环氧漆；织物蒙皮用硝酸酯/丁酸酯 dope；另有前缘防雨蚀涂层、机匣与机轮的烘烤磁漆
- 临时保护：防腐剂、滑油、防水蜡、保护罩、硬膜防腐涂层

**清洁剂体系**

- 轻负荷：soaps、synthetic detergents（皂类与合成洗涤剂，无毒不燃者优先）
- 重负荷：solvents、emulsion cleaners（溶剂、乳化型清洗剂）
- 外表面三种清洁法：wet wash、dry wash、polishing（分手抛与机械抛光）
- 专用：氧气系统用无水乙醇或异丙醇；塑料件只用肥皂水

**腐蚀易发部位清单**

- 排气尾迹区、电瓶舱与电瓶通气口、舱底（bilge）、厕所/配餐间/厨房、轮舱与起落架、积水区与低点排水孔、发动机前部与冷却空气道、襟翼/扰流板凹槽、外蒙皮（镁蒙皮边缘、紧固件周围；钢琴铰链；点焊接缝）、电子电气舱、直升机旋翼头与减速器、操纵钢索

## 6. 检查与维修要点

**检查流程**

1. 先彻底清洁待检区（否则看不出来）。
2. 一般目视：手电、检查镜、5–10X 放大镜，找明显缺陷与可疑区；可用低入射角观察，也可用触摸发现隐蔽的成熟腐蚀。
3. 详细检查可疑区；通道不足时拆口盖与相邻设备、清除松动或开裂的密封胶与漆层，借助反光镜、borescope、光纤。
4. 补充 NDI：液体渗透、磁粉、涡流、X 射线、超声、声发射；**必须由有资格认证的 NDI 人员执行**，涡流/ X 射线/超声每次使用前须校准且有比对标准件。
5. 水陆两栖/水上飞机须每日检查并清洁处理关键区。

**判据与处理原则**

- 腐蚀即损伤：按四类损伤归档——negligible（可忽略）、可补片修理、可嵌入修理、须更换。negligible 不等于不处理，仍须清洁、处理、涂漆。
- 腐蚀超出厂家损伤限制且无法修理 → 更换部件；厂家限制不足时请 DER 评估。
- 修理一律先除净所有腐蚀产物；未进展到需结构修理的，按"清洁除漆 → 除腐蚀产物 → 中和残液 → 恢复保护膜 → 涂临时/永久涂层"流程。
- 结构钢件除锈后须尽快检查并评估损伤；高强度钢件表面任何腐蚀都潜在危险，禁止使用化学除锈剂（除非有工程批准），因高强度钢易氢脆。
- 高强度钢打磨时不得过热，除锈后立即补漆。

**各金属的施工要点**

- **铝（未涂漆 Alclad）**：中性 pH 清洁剂 → 细研磨/金属抛光 → 抑制性擦拭或二铬酸钠+三氧化铬 5–20 分钟 → 防水蜡罩面。切勿过度磨掉包铝层。
- **铝（待涂漆）**：清洁除油脂 → 剥漆 → 10% 铬酸+硫酸刷涂并保持湿润刷洗、至少 5 分钟 → 冲净干燥 → 当日恢复涂层。
- **阳极氧化面**：只可部分恢复，务必少破坏原膜；禁钢丝棉、钢丝刷、强研磨；可用铝棉、氧化铝浸渍尼龙布、细非织造垫、纤维刷；铬酸可恢复氧化膜。
- **晶间腐蚀**：必须机械去除全部腐蚀产物与可见分层金属，测剩余强度；已有腐蚀深度与去除限制的按厂家数据执行。
- **镁**：最活泼最难保护；腐蚀产物体积数倍于原金属，初期表现为漆膜鼓起与白点，迅速发展成雪堆状或"白须"。用硬猪鬃刷或非织造垫，禁用钢丝刷、碳化硅磨料、钢质刀具；铬酸+硫酸刷入坑缝，5–20 分钟，湿布擦去余液，干后立即补原漆。铸件多孔、更易穿透，尽量分开贴合面处理。
- **钛**：难发现；禁钢丝棉、铁刮刀、钢丝刷；可用铝抛光膏或细研磨（仅纤维刷），随后用二铬酸钠溶液处理，干布擦净余液，**不可水冲**。
- **异种金属接触**：按 Figure 8-30 查需加隔离层的金属组合；隔离物可用金属底漆、铝箔胶带、垫圈、润滑脂、密封胶；不含镁至少 2 层底漆，含镁每面 2 层底漆 + 0.003" 乙烯胶带（或 3 层底漆）。
- **钢索**：每次检查期用浸溶剂的布随机擦洗短段查外腐蚀；有外腐蚀则松张力查内腐蚀，内腐蚀一律更换；轻外腐蚀用蘸油非织造垫或钢丝刷去除后重新涂防腐剂。
- **点焊蒙皮**：腐蚀从层间进入，表现为缝隙处出现腐蚀产物，进而蒙皮鼓曲、焊点断裂；顺焊缝瞄视或用直尺可早期发现鼓曲；唯一预防办法是把进水点（缝、断焊点孔）用密封胶或防腐膏填实。
- **钢琴铰链**：钢销与铝铰链异种金属接触，且是脏物、盐、水分的天然收集处；须润滑并往复作动数次确保渗入，使用排水型润滑剂。
- **螺旋桨**：淡水、肥皂、批准的清洁溶剂；除蚀刻工艺外不得用碱性物质；禁刮刀、电动抛光轮、钢丝刷；清洗后立即涂清洁滑油；钢桨叶每次飞行后擦油既防腐又便于发现裂纹。
- **氧气系统**：只用无水乙醇或异丙醇清洁可接近件（面罩、管路），不得倒入储罐或调节器；不得用会留油膜的任何清洗剂。
- **塑料件/风挡**：先用淡水冲盐与尘，再用肥皂水手洗，麂皮或专用合成擦拭布擦干；不得干布擦（划伤且起静电吸尘）；禁丙酮、苯、四氯化碳、硝基漆稀释剂、玻璃清洁喷雾、汽油、灭火剂、除冰液（会软化并龟裂）。
- **轮胎**：温和肥皂水洗去油、液压油、油脂、燃油；洗后对怀疑进水/稀释的润滑点补润滑。
- **座舱内部**：金属屑、断线头等杂物 + 潮气 + 异种金属接触 = 电解腐蚀；结构作业时铺落料布，用吸尘器清理；优先用不燃清洗剂。

**脱漆与整形**

- 大面积化学脱漆尽量在室外背阴处，室内须充分通风；保护橡胶件、轮胎、织物、亚克力；注意气密/水密缝密封胶会被脱漆剂软化破坏；堵住所有通内腔的开口。
- 防护：橡胶手套、耐酸围裙、护目镜；残渣按环保法规处置。
- 凹坑整形：先除净腐蚀与毛边，做成椭圆碟形，长深比 20:1；关键高应力区所有残坑必须打磨过渡以防应力集中；非关键区经喷砂除锈后的残坑不必强行磨平（会多去金属）。
- 铝件打磨前须拆掉钢螺母板与钢紧固件，嵌入的钢/铜颗粒会成为新腐蚀源。

**清洁作业**

- 外表面：湿洗（碱性或乳化清洗剂，喷雾/拖布施涂后高压水冲）、干洗（去机场灰尘薄膜，不适合厚重碳、油、脂，尤其排气区）、抛光（恢复光泽并去氧化与腐蚀）。
- 尽可能在背阴处洗，热金属上施药会留条纹；遮盖所有开口，尤其 pitot-static 接头与静压孔。
- 平光漆区域（雷达罩、驾驶舱前区）不得过度清洗，禁硬刷与粗布，只用软海绵或纱布轻擦；油污/排气烟痕先用煤油等石油溶剂去除再立即冲洗。
- 洗后对可能进水或油脂被稀释的注脂点、铰链补润滑。
- 发动机清洗：尽量打开/拆下整流罩，自上而下用细雾煤油或溶剂冲洗，可辅以硬毛刷；洗后所有操纵臂、摇臂、运动件按手册润滑。
- 舱内可燃/易燃清洗剂使用：充分通风（开舱门或机械通风）、停用明火与打火设备、手携电气设备须为 NEC Class I Group D 认证、作业中不得操作舱内照明与电气开关、舱门张贴警示牌、尽量在机库外作业、配 20-B 灭火器与可调水雾消防软管、机库内则须有自动灭火系统。

## 7. 高频考点（TECC / 口试风格）

问：电化学腐蚀必须同时具备哪四个条件？
答：受蚀金属（阳极）、腐蚀倾向更小的异种导体（阴极）、连续导电液通路（电解液）、阴阳极间电接触；消除任一条件腐蚀即停。

问：直接化学腐蚀与电化学腐蚀怎么区分？
答：直接化学腐蚀的氧化与还原在同一点同时发生；电化学腐蚀的阳极与阴极变化相隔一段可测距离。

问：哪两种腐蚀形式是"同一种攻击的不同阶段"？
答：晶间腐蚀与剥蚀（exfoliation）——剥蚀是晶间腐蚀的高级形态，腐蚀产物把表层晶粒顶起。

问：丝状腐蚀在什么条件下发生，钢和铝上的痕迹有何不同？
答：相对湿度 78–90% 且表面微酸；钢上痕迹不交叉，铝上会互相穿越，故铝的损伤更深更重。

问：微动腐蚀（fretting）的典型例子和外观？
答：发动机整流罩与机翼蒙皮上的"发烟铆钉"，铆钉周围一圈黑环；贴合面微动产生大量细碎磨屑并被封闭在局部。

问：电偶腐蚀的严重程度受什么影响？
答：两种金属活动性差别越大腐蚀越快；且受面积比影响——受蚀金属面积小于耐蚀金属时腐蚀快而严重，反之慢而轻微。

问：为什么不能用钢丝刷或钢丝棉清理铝、镁、钛？
答：会把钢颗粒嵌入或被覆在金属表面，形成异种金属电偶，造成比原腐蚀更严重的后果；同理非织造研磨垫不得跨金属混用。

问：高强度钢件为什么禁止用化学除锈剂？
答：高强度钢对氢脆敏感，化学除锈可能导致脆断；须经工程批准，通常只用细研磨纸、绒布抛光轮等机械方法，且不得过热。

问：腐蚀损伤分哪四类？
答：可忽略（negligible）、可补片修理、可嵌入修理、须更换零件；前两类按结构修理手册修，超出限制则更换。

问：舱内使用可燃清洗剂时，通风到什么程度必须停止作业？
答：距使用点 5 ft 处可燃蒸气浓度达到该蒸气爆炸下限的 25% 时，须紧急更改作业。

## 8. 易混点

1. **浓差电池腐蚀 vs 电偶腐蚀**：两者都靠电位差，但浓差电池发生在**同一种金属**上（靠溶液离子浓度或溶解氧浓度差，如搭接面下、垫片下），电偶腐蚀发生在**两种不同金属**接触处。
2. **金属离子浓差电池 vs 氧浓差电池**：前者阳极在**低**金属离子浓度处（缝外），后者阳极在**低**氧浓度处（缝内、覆盖物下）；两者阳极位置正好相反，不要背混。
3. **丝状腐蚀 vs 点蚀**：丝状腐蚀限于有机涂层下的浅层"虫迹"，由氧浓差电池引起、与湿度 78–90% 相关；点蚀是向金属内部深钻的小孔，外表可能只有一个白灰粉点，危害与表面面积完全不成比例。
4. **阳极氧化（anodizing）vs 阿洛丁（alodizing）**：阳极氧化是电解过程、需专用设施（MIL-DTL-5541F/AMS-C-5541A），膜硬而脆、损伤后只能部分恢复且不导电（接地处须磨掉）；阿洛丁是纯化学转化膜，因工艺简单正快速取代阳极氧化。
5. **非酚型 vs 酚型溶剂乳化剂**：非酚型不软化底漆、可安全用于漆面（但反复使用会软化亚克力硝基漆）；酚型重负荷能力更强但会软化漆层，橡胶、塑料附近须慎用，操作要戴橡胶手套与护目镜。
6. **高闪点溶剂 vs 低闪点溶剂**：高闪点（100 °F 以上，Stoddard 类 100–140 °F）可用于清洁；Class I 低闪点（低于 100 °F，如丙酮、MEK、AVGAS、石脑油、甲苯）禁止用于飞机清洁与翻新。

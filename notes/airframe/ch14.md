# Ch 14 · Aircraft Fuel Systems（飞机燃油系统）

## 1. 一句话

讲飞机燃油从油箱到发动机的全链路：油品种类与特性、油箱、油泵、阀门、油管、滤、油量/流量/压力指示，以及污染控制、加油放油、渗漏修理与防火安全。

## 2. 本章要点

- 燃油系统由 storage tanks、pumps、filters、valves、fuel lines、metering devices、monitoring devices 组成，按 14 CFR part 23/25/27/29/31 认证；part 33 管发动机，part 34 管涡轮机排气通风（EPA）。
- 燃油只有两大类且**不得混用**：往复机用 aviation gasoline（AVGAS），涡轮机用 jet fuel（煤油型）。加错油是最严重的污染，发现者必须让飞机停飞（ground the aircraft）。
- 油箱分 rigid removable、bladder（fuel cell）、integral（wet wing）三类；integral 用耐油双组分密封胶密封机体结构，容积最大、重量最轻，是结构的一部分。
- 喷气运输机燃油系统分 5 个子系统：storage、vent、distribution、feed、indicating；通气的核心是 surge tank + check valve，保证任意姿态、任意油量都能通气。
- 油泵按用途分：boost pump（离心式为主，箱内正压、防 vapor lock）、engine-driven pump（vane 式为主，constant displacement）、ejector pump（引射，保证泵进口有正压头）、wobble pump / hand primer（起动注油，已基本淘汰）。
- 阀门必须能随时**确切判明阀位**：手动阀靠 detents + 指示手柄 + 标牌，电动/电磁阀另有 annunciator lights；gate valve 因无需电源即可断油而专作 fire control valve。
- 燃油必须清洁、明亮（clean, bright）：水最常见、surfactant 让水与颗粒悬浮、微生物在油水界面生长并造成电解腐蚀；每日排放 strainer 与 sump 是最基本的防线。
- 静电与点火源是燃油作业的头号风险：所有部件必须 electrical bonding/grounding，加油必须在室外、先接搭接线再开油箱盖，灭火器用 CO2 或干粉，**不得用水型灭火器**。

## 4. 关键数字与公式

- 油箱容量：至少 **30 分钟**最大连续功率/推力用油。
- 燃油密度（B777 容量图取值）：**6.7 lb/US gal**。
- B777 可用油量（level attitude）：左主箱 9,560 gal / 64,000 lb；右主箱 9,560 gal / 64,000 lb；中央箱 26,100 gal / 174,900 lb；合计 **45,200 gal / 302,900 lb**。
- AVGAS 蒸气压：**5.5–7.0 psi @ 100 °F**（最大 7 psi）；Jet A **0.125 psi**；Jet B **2–3 psi**。
- 闪点：Jet A / Jet A-1 **110–150 °F**。
- 冰点：Jet A **–40 °F**；Jet A-1 **–52.6 °F**；Jet B 约 **–58 °F**。
- 100LL 含 TEL **2 mL/加仑**。
- 涡轮机油水兼容性判据：燃油在 **80 °F** 被水饱和，每加仑加 **0.75 cm³** 游离水，再冷却到最严酷结冰条件仍能持续工作。
- 化油器结冰最常见环境温度 **30–40 °F**（潮湿天更高温亦可发生）。
- 喷气机高空燃油温度可达 **–50 °F**。
- 整体油箱挡板单向阀（737，图 14-32）：WBL 157.0 处 **5 个**、WBL 227.0 处 **6 个**、WBL 557.0 处 **1 个**；boost pumps 装在 WBL 157 内侧。
- 刚性油管支撑间隔（图 14-37，管外径→间距）：3/16 in→**9 in**、5/16 in→**12 in**、1/2 in→**16 in**、3/4 in→**22 in**、1 1/4 in→**30 in**、2 in→**40 in**；支撑管至少离穿孔边 **1/4 in**。
- 颗粒尺寸：**1 micron = 1/1,000 mm**；micronic filter 捕捉 **10–25 microns**；可更换 cellulose 滤芯拦 **10–200 microns** 并吸水。
- 燃油水含量判据：通用测试包 **>30 ppm** 变色报警；涡轮燃油另有 **15 ppm** 测试；超过即视为不可接受、不适航。
- 金属箱检漏压力：**1/2–3.5 psi**，涂皂液看冒泡。
- 渗漏分级（30 分钟内收集燃油的表面面积直径）：stain **< 3/4 in**；seep **3/4–1 1/2 in**；heavy seep **1 1/2–4 in**；running leak 会滴落并沿机体流远。
- 仪表量程示例：燃油压力表 **0–30 psi**；differential fuel pressure gauge **0–7 diff. psi**。
- 蒸馏塔馏分温度：C1–C4 气体 20 °C；C5–C9 石脑油 70 °C；C5–C10 汽油 120 °C；C10–C16 煤油 170 °C；其后 270 °C、600 °C，>C70 为渣油；C14–C20 柴油、C20–C50 润滑油、C20–C70 燃料油。

## 5. 结构 / 系统 / 部件

- **油箱**
  - rigid removable：3003 或 5052 铝合金、不锈钢；铆接 + 缝焊防漏；早期薄钢板镀 lead/tin 合金称 terneplate，折边 + 锡焊；机体结构完整性不依赖油箱，故不算 integral。
  - bladder（fuel cell）：增强柔性材料，安装开口可很小，卷起塞入再展开；必须贴结构固定、铺平无皱（底面有皱则杂质无法沉入 sump）。
  - integral（wet wing）：耐油双组分密封胶密封结构，容积最大、重量最轻；用翼肋与 box beam 兼作 baffles，加 baffle check valves 只许油向内侧/低处流，保证 sump 上方 boost pumps 任何姿态都有油。
  - 附件：低处 sump + drain valve、finger screen、baffling、加油口 scupper、access panel（O-ring + 铝垫片用于 electrostatic bonding，clamp ring 压紧）。
- **喷气运输机五大子系统**
  - storage：integral 主箱 + 可选 auxiliary tanks + surge tank（内装单向阀只许流回主箱）。
  - vent：vent tubing 把各箱连到 surge tank 通气空间或排出机外，配 check valves、float valves、多处通气口。
  - distribution：压力加油、放油（defueling）、转输（transfer）、抛油（jettison）。
  - feed：每箱通常 2 个 boost pumps → 每发一个 shutoff valve → manifold + crossfeed valves；有 boost pump bypass，全部增压泵不工作时发动机仍能运行。
  - indicating：油量、流量、压力、温度、阀位与警告灯。
- **油泵**
  - 离心式 boost pump：variable displacement，浸没箱内或箱底外装；外装式配 pump removal valve，可不排空油箱拆泵；出口 check valve 防回流，系统设 bypass valve。
  - ejector pump：把泵出口油经小管引回，venturi 造低压吸油，与 baffle check valve 一起维持泵进口正压头。
  - 脉动式电动泵（plunger）：solenoid + 触点 + calibrated spring 往复，单作用，对出口压力敏感，diaphragm 阻尼脉动。
  - vane-type：constant displacement，偏心转子 + 叶片 + central floating spacer pin；可调 pressure relief 把多余油送回进口；compensated 型用 diaphragm 感受计量装置进气压力自动改泄放压力。
  - wobble pump（双作用叶片）与 hand primer（单作用柱塞）：起动注油用。
- **阀门**
  - 手动：cone/plug、poppet（部分用钢球）、gate。
  - gate valve 作 fire control valve（无需电源断油）、地面 defuel valve、boost pump isolation valve；内置 thermal relief bypass 泄放关闭段的热膨胀压力。
  - 电动：可逆齿轮电机 + 密封 gate/blade，带 manual override lever。
  - 电磁：poppet 型，开线圈通电 + locking stem 锁定开位，关线圈通电解锁后弹簧回座。
- **滤与加温**：finger screen → 主 strainer/gascolator（低点、带排放）→ 发动机驱动泵 → micronic filter（涡轮机 wafer/叠片）→ 计量装置；滤组件内含弹簧加载 bypass valve。加温器为 air-fuel heater（压气机引气）或 oil/fuel heater（FCOC），可手动或 thermostatic 自动。
- **指示**：sight glass / 浮子杆 / crank and pinion / magnetic coupling / 可变电阻 ratiometer / 电容式（探头并联 + reference capacitor + compensator unit + trimmer）/ fuel totalizer / drip stick。

## 6. 检查与维修要点

- **日常**：每日排放 strainer 与 sump，配合定期换滤与目视检查；加油后应等一段时间再检查 sump，让水与沉淀沉到排放点。
- **污染判定**：燃油应为 clean, bright；浑浊偏向箱底是水、偏向箱顶是空气；细颗粒表现为雾状（haze）或在燃油控制滑动面上留下深色虫胶状痕迹；滤中发现明显金属颗粒可能是上游部件失效。
- **外来物**：系统打开时管路立即封盖，加油口周围先清洁；换滤按间隔执行并检查滤中颗粒。
- **泄漏**：先目视找源（接头处最常见；汽油带出染料或留下无尘干净区，喷气燃油靠尘土沉入显现）；漏到蒸气可积聚区域必须飞行前修好；外部无点火危险的泄漏可推迟但须定位并监控。分级按 30 分钟内 3/4 in、1 1/2 in、4 in 的直径界线。
- **接头与油管**：**禁止靠过度拧紧止漏**——按规定扭矩仍漏则卸压、拆开目视检查、必要时换件；软管不得扭曲（用管外印字作 lay line）；油管与电线分开，无法分开时油管走在电线下方；刚性管用 bonded cushion clamp 按外径查表支撑，两固定点之间须有小弯吸收振动与温度胀缩；所有部件 electrical bonding 到结构。
- **垫片/密封件**：重装必须用**新件**，按件号选对，注意包装上的货架寿命；彻底清除旧垫片、清洁配合面，均匀拧紧螺栓防止挤伤。
- **金属箱**：焊接箱修理前必须彻底 purge 油气（steam cleaning、hot water purging、inert gas purging），焊后清除焊剂杂物；检漏加压仅 1/2–3.5 psi 并用准确减压器与压力表，装于机上的箱加压前须同样支撑。轻微渗漏可用批准的 sloshing compound 翻滚覆盖内壁，但须先向厂家确认对该机型是适航修理。铆接箱补片与接缝涂耐燃油化合物；锡焊箱补片须有规定搭接量并清除焊剂。
- **软油箱**：补片按厂家批准材料与方法，须有规定搭接量，**穿透性损伤内外各加一块补片**；有有限使用寿命，渗漏超出可接受限即更换；平时保持充油湿润，干存时涂清洁发动机油防干裂；装回须用正确紧固件牢固固定。
- **整体油箱**：access panel 渗漏常可靠转油、换密封胶与正确螺栓扭矩解决；接缝密封胶失效须转油或放空后进人，用**非金属刮刀**除旧胶、残留用 aluminum wool，清洁后按厂家涂新胶，遵守固化时间与泄漏检查。
- **进箱作业**：按图 14-92 检查单逐项完成并签字——接地、封锁设牌、boost pump 断电拔 CB、电瓶断开与外电挂牌、无线电雷达关闭、只用防爆设备与工具、OSH class 110 以上呼吸器与连体服棉帽脚套护目、受训 attendant 与受限空间记录、aerator 清洁、海绵、带 streamer 的堵头、机械通风（**开箱期间通风必须始终运行**，失效或有头晕刺激异味立即停工撤出）、持证进箱人员与观察员、通知消防部门，并记录氧气百分比、燃油蒸气 ppm、LEL 读数。
- **防火**：燃烧三要素为蒸气、空气、点火源；空油箱残留蒸气风险极高，修理前必须 purge；灭火器用 CO2（对准火焰基部扫射）或适用燃油的干粉，**严禁水型灭火器**。
- **加油/放油**：只在室外；油车停机位置要能迅速驶离；先接静电搭接线再开油箱盖；加油枪不得插到底压凹蒙皮、不得离手留置、不得拖拽掉落；油车移动前排放各 sump 并目视检查，刚加过油或被颠簸的涡轮燃油应静置数小时；放出的污染油单独容器存放，绝不与好油或其它牌号混合，放出的好油按厂家规定决定能否再用。
- **加错油**：未开泵未起动的，放空、用正确燃油冲洗油箱与油管；已起动或试图起动的，全系统放空冲洗、做压缩试验、对燃烧室与活塞做 borescope 检查、放掉滑油并检查所有滤网滤芯，重新组装加正确燃油后放行前须做完整 run-up。

## 7. 高频考点（TECC / 口试风格）

- 问：燃油系统的两类燃油是什么，能否互换？答：AVGAS（往复机汽油）与 jet fuel（涡轮机煤油），**不得混用**，加错油属最严重污染。
- 问：integral tank 与 bladder tank 的本质区别？答：integral 用密封胶把机体结构本身密封成箱、属结构一部分；bladder 是柔性油囊装进结构舱内，结构完整性不靠它。
- 问：为什么整体翼箱要装 baffle check valves？答：允许燃油流向低处/内侧、阻止流向外侧，使位于箱底最低点的 boost pumps 在任何姿态下都有油。
- 问：boost pump 的主要作用？答：给发动机驱动泵正压供油、作为其备份、按设计做箱间转输，并在任何温度高度姿态下防 vapor lock。
- 问：为什么 gate valve 适合做 fire control valve？答：手动闸阀拉应急灭火手柄时**无需电源**即可断油。
- 问：如何确认一个燃油阀的阀位？答：手动阀靠 detents + 指示手柄 + 标牌；电动/电磁阀另有 annunciator lights、FMS/ECAM 图形显示，阀外部多有位置手柄可目视并手动定位。
- 问：strainer 与 filter 的区别？答：strainer 粗网拦大块杂物、**不阻挡水的流动**；filter 细网可拦千分之几英寸细渣并帮助拦水。
- 问：喷气机如何发现滤芯堵塞？答：用 bypass-activated switch 或 pressure differential switch，bypass 打开或进出口压差明显变化即点亮 annunciator；也可监视燃油温度判断结冰堵塞。
- 问：金属油箱检漏用多大压力？答：很低，常用 **1/2–3.5 psi**，涂皂液看冒泡，必须用准确减压器与压力表防超压变形。
- 问：燃油作业为何强调 bonding？答：燃油在管内流动即可产生静电积聚，静电可点燃燃油蒸气；所有油管与部件必须搭接到机体结构导入地。

## 8. 易混点

- **strainer 与 filter**：两者常被混用称呼，但 strainer 是粗金属丝网、只拦大块杂物、不挡水；filter 是细网，能拦细微颗粒并帮助拦水。
- **vapor lock 与 detonation**：vapor lock 是燃油在到达化油器前汽化成气泡导致供油中断（热天、低压、紊流、爬升时箱压下降易发）；detonation 是混合气在气缸内高压高温自燃爆燃、冲击波损伤活塞连杆曲轴。
- **重力供油与泵供油**：高翼机可靠重力供油、无燃油泵，两箱互相通气保证压力相等；低/中翼机不能靠重力，须电泵 + 发动机驱动泵并联，且**不能同时从两个油箱抽油**（会吸空），因此不需要互连通气。
- **boost pump 与 engine-driven pump**：boost pump 多为箱内离心式、电动、variable displacement，负责正压与防气塞；engine-driven pump 多为 vane 式、constant displacement、由附件齿轮箱驱动，是主供油泵并靠可调 relief 控制供油量。
- **integral tank 与 rigid removable tank**：两者都可能是金属结构，但 rigid removable 由绑带固定在机体上、机体结构完整性不依赖它，因而不算 integral；integral 是结构本身被密封成箱。

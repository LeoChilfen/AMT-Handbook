# Ch 13 · Aircraft Landing Gear Systems（飞机起落架系统）

## 1. 一句话

本章讲起落架如何承载全机重量并吸收着陆冲击：从布置形式、减震支柱的油气勤务，到机轮轮胎、各类刹车、收放与安全装置、转向减摆、防滞与日常检查判据。

## 2. 本章要点

- 起落架形式由设计与用途决定，基本布置有三种：tail wheel-type（又称 conventional gear）、tandem、tricycle-type；现代飞机绝大多数用 tricycle，因为重心（CG）在主轮之前，刹车可以更重而不致 nosing over，且能防止 ground-looping。
- 真正"吸能"的起落架靠 shock strut 把冲击动能转成热能：两个 telescoping 圆筒，下腔始终充满液压油、上腔充压缩空气或氮气，油被迫经 orifice 时产生热并由支柱壁散掉。
- 压缩行程的油流速度靠 metering pin 的锥度自动控制；伸张（回弹）行程靠 piston 上的 recoil valve 或 recoil tube 限流，防止行程末端的硬撞击。
- 减震支柱勤务是固定顺序：放尽气压 → 加规定液压油到 service valve port 高度 → 按厂家规定以 psi 或"下支柱伸出某尺寸"充气；充气必须缓慢，人须避开 valve core 的弹出轨迹。
- 现代机轮是两半式铝或镁合金轮，用 wheel tie bolts 连接、接合面 O-ring 密封，多配无内胎轮胎；内侧半轮负责驱动刹车 rotor 并常带 thermal plug 与 overinflation safety plug。
- 刹车的基本作用是把动能转为热能；形式从 single disc、floating/fixed disc、dual disc，到 multiple disc、segmented rotor，再到 carbon brakes。刹车过热、拖滞（dragging）、颤振或尖叫都要查明原因。
- 大型机用 power brakes：brake metering valve 按踏板行程计量系统压力，用两套独立液压系统、内外侧两组独立刹车组件、brake accumulator 与 shuttle valve 实现冗余；debooster 把压力降到刹车组件工作范围，hydraulic fuse 在管路破裂时保住油液。
- 防滞（anti-skid）靠每个机轮的 wheel speed sensor 与减速率判据瞬时卸压，含 touchdown protection 与 locked wheel protection；轮胎的可用性最终由胎压、磨损与损伤判据决定，而不是"看起来还能用"。

| 英文 | 中文 | 一句话解释 |

| auxiliary landing gear | 辅助起落架 | 指 nose gear、tail gear 或 outrigger-type gear |
| main landing gear | 主起落架 | 靠近重心（CG）的两个或更多大起落架 |

| bogie | 台车式轮架 | 一个支柱上挂两个以上机轮的机构，Boeing 777 为 triple bogie |

| packing gland | 密封压盖 | 装在外筒开口端，密封上下筒滑动接合面 |
| wiper ring | 刮尘环 | 装在 gland 槽内，阻止泥沙冰雪被带进密封与筒内 |
| shimmy damper | 减摆器 | 用液压节流或摩擦阻尼抑制前轮高速摆振 |
| squat switch | 压缩开关（地面安全开关） | 随支柱伸缩开闭，防止地面收起落架 |
| proximity sensor | 接近传感器 | 无接触地探测 target 位置并向 gear logic unit 回送电压 |
| ground lock | 地面保险销 | 外部销子或夹块，插入收放机构阻止其运动，须挂红色飘带 |
| uplock / downlock | 上位锁 / 下位锁 | 把起落架保持在收上或放下位置的锁机构 |

| lockout debooster | 锁闭式降压器 | 兼具降压与 hydraulic fuse 功能，下游失油即停止供油 |
| hydraulic fuse | 液压保险（流量保险） | 检测到过大流量即关闭，保住系统内剩余油液 |
| shuttle valve | 梭阀 | 在主油源失压时切换到备用或应急油源 |
| anti-skid | 防滞 | 探测机轮过度减速并瞬时卸压，使机轮不锁死打滑 |
| wheel speed sensor | 轮速传感器 | AC 或 DC 传感器，输出频率或幅值与轮速成正比的信号 |
| thermal plug（fusible plug） | 热熔塞 | 低熔点合金芯，胎压因过热升高到危险前熔化放气 |

| hydroplaning | 滑水 | 水膜使轮胎失去与跑道接触，转向与刹车同时失效 |
| shearography | 剪切散斑干涉检测 | 翻新站用于判断胎体内部完整性的光学无损检测方法 |
| glazing | 盘面釉化 | 刹车盘局部过热形成的表面层，造成尖叫与颤振 |

## 4. 关键数字与公式

- 高压勤务活门：AN6287-1 额定 3,000 psi，但其 valve core 本身只额定 2,000 psi；MS28889-1 无 valve core，额定 5,000 psi。图中标注 5/8-inch hex nut、3/4-inch hex body。
- 接近传感器示例：detector 0.3 V = logic 0，13 V = logic 1，供电 28 V DC。
- 起落架限速标牌示例：EXTEND 270/.8M，RETRACT 235K，EXTENDED 320/.82K。
- 舱门 latch roller 间隙：1/8 ± 3/32 inch。
- 侧撑杆 over-center 量：.22 ± .03 inches；down lock 弹簧张力用 spring scale 检查，本例 40–60 pounds。
- 收放试验判据：把起落架从 down-and-locked 位向内收 6 inches 后释放，必须自由落回锁定放下位。
- 前轮转向 compensator 溢流压力：100 psi（使转向作动筒常压，兼作减摆器）。
- 刹车降压器原理：Pressure = Force/Area；高压作用在小面积活塞上，力传到更大面积活塞，输出压力降低而油液体积增加。
- multiple disc 刹车的 rotors 与 stators 约 1/8-inch 厚，散热较差、易翘曲。
- 碳刹车：比常规刹车约轻 40%；可承受比钢件刹车高 50% 的温度；寿命比钢刹车长 20–50%；非航空应用中可承受钢刹车 2–3 倍的热量。
- 防滞：防滞工作到约 20 mph 后转入手动刹车；locked wheel 逻辑中，同组配对轮一个比另一个慢 25 percent 即卸压。
- 衬片磨损目视参照：number 40 twist drill，直径 0.098 inches（用于 Cleveland 刹车）。
- 刹车密封件货架寿命：通常自 cure date 起三年。
- 轮胎类型标识：Type III 用于着陆速度 160 mph 或以下，如 6.00 – 6（宽 6.00 inches、6 inches 轮辋）；Type VII 如 26 X 6.6；Type VIII 三段命名如 18 X 4.25—10；子午胎把 – 换成 R，如 30 X 8.8 R 15。
- 标识符前缀：B 表示轮辋与断面宽比 60–70 percent、bead taper 15 degrees；H 表示同一比例但 bead taper 仅 5 degrees。
- 帘布角度：bias ply 与转动方向成 30°–60°，radial 成 90°。
- 胎压：带载与不带载读数可差 4 percent；设计充到 160 psi 的轮胎在千斤顶上的读数可差 6.4 psi；温度每变化 5 °F 胎压约变 1 percent。
- 胎压测量时机：着陆后需等 3 小时使轮胎冷却到环境温度；示例中 50 °F 温差导致 10 percent 胎压下降。
- 花纹判据：磨到沟底沿圆周超过 1/8 即拆下；bias 的 reinforcing ply 或 radial 的 protector ply 外露超过圆周 1/8 也拆下。
- 损伤判据：异物造成的圆孔直径 3/8-inch 或以下可接受；chip/chunk 使 reinforcing 或 protector ply 外露超过 1 square inch 即拆下；沟槽裂纹外露超过 1/4-inch 不可接受；翻新时可修复不超过 40 percent 帘布层的损伤；内表面小于 1/8-inch、外表面小于 1/4-inch 的小穿刺可修。
- 轮胎存放：立放，胎架平面支撑面最小 3–4 inches；平放不得超过 6 个月；直径小于 40-inches 最多叠 4 条，大于则 3 条；已装轮充气胎可按工作压力低 25 percent 存放；安全存放温度 32 °F–104 °F。
- 充气：新装胎必须在 inflation safety cage 内充气，调压距离至少 30 feet；充到工作压力后无载放置 12 hours，压力下降 5–10 percent 属正常，再补压后每天损失应小于 5 percent。
- 轮胎挠度：着陆时侧壁挠曲可达汽车轮胎的 2–3 倍。

## 5. 结构 / 系统 / 部件

- 起落架系统的组成：shock absorbing equipment、brakes、retraction mechanisms、controls、warning devices、cowling、fairings，以及把起落架连到机体所需的结构件。
- 按吸能方式分：
  - 非吸能式：rigid（刚性支柱，冲击直接传机体）、skid。
  - 弹性式：leaf-type spring gear（弹簧钢板/复材板）、bungee cord（橡胶索或橡胶缓冲块）。
  - 吸能式：air/oil shock strut（本章重点）。
- Shock strut 主要零件：上 cylinder（固定于机体）、下 cylinder 即 piston（可滑动，多带 axle）、orifice 与 metering pin（或 metering tube）、recoil valve / recoil tube、packing gland 与 wiper ring、torque links、valve fitting assembly（加油与充气）、instruction plate；前起另有 locating cam assembly（对正机轮）与 shimmy damper 安装点。
- 收放系统：
  - 小型机 hydraulic power pack：电动泵正反转、gear-up check valve、pressure switch、thermal relief valve、shuttle valve、restrictor、emergency extend freefall valve、mechanical down locks。
  - 大型机：engine accessory drive 驱动的液压泵（常配辅助电动泵）、selector valve、actuating cylinders、uplocks、downlocks、sequence valves（或 priority valves）、tubing、各类舱门与舱门作动筒。
- 安全与指示：squat switch（或 proximity sensors + gear logic unit）、ground locks、uplock/downlock、gear position indicators（绿灯 down and locked、红灯 unsafe、amber in transit、gear disagree）、gear warning horn、nose wheel centering cams 或外部 roller/guide pin。
- 转向：小型机为脚蹬经 push-pull tubes 与 pedal horns 的机械连杆；大型机为 tiller/wheel 输入 → steering control unit（计量阀）→ 转向作动筒 → 下支柱，配 follow-up mechanism 与 compensator（100 psi 背压）。
- 减摆：piston-type（活塞 bleed hole 节流）、vane-type（叶片与节流孔 + replenishing reservoir）、non-hydraulic（橡胶活塞 surface-effect damping）、steering damper（靠转向作动筒常压）。
- 机轮：内侧半轮（刹车 rotor 驱动 key/keyway、thermal plug、overinflation safety plug、fill valve）、外侧半轮（bearing、anti-skid wheel-spin transducer、hub cap/fairing）、bearing cup 与 tapered roller bearing、wheel tie bolts、balance weights。
- 刹车谱系：single disc → floating disc / fixed disc（Cleveland）→ dual disc → multiple disc（钢 stator + 镀铜/青铜 rotor）→ segmented rotor multiple-disc（标准 air carrier 刹车）→ carbon brakes；老式另有 expander tube brakes。
- 刹车操纵：independent master cylinder（自带或 remote reservoir、compensating port、棘轮 parking brake）→ boosted brakes（spool valve 引系统压力助力的 boosted master cylinder）→ power brakes（brake control/metering valve、feel unit、accumulator、hydraulic fuse、shuttle valve、debooster、anti-skid valve、auto brake valve）。
- 轮胎构造：bead（钢丝束 + apex strip + flippers + chafers）、carcass/casing plies（多为尼龙，两端绕过胎圈成 ply turn-ups）、bias 用 tread reinforcing plies、radial 用 undertread 与 protector ply、tread（rib/diamond/all-weather/smooth/chine 五种）、sidewall、inner liner、vent holes（绿或白点标记）、breakers。
- 防滞组成：wheel speed sensors（每轮一个）、anti-skid control valves（每个刹车一个）、control unit（集中比较电路，含 converter、velocity reference loop、velocity comparator、pressure bias modulator、valve driver、locked wheel comparator 等）。

## 6. 检查与维修要点

- 起落架系统检查前必须把所有表面清洁干净，否则漏检；每次检查或进入轮舱都要确认所有 ground locks 已装好。
- 定期检查项：shock struts、trunnion/brace assemblies 与 bearings、shimmy dampers、wheels、wheel bearings、tires、brakes；位置指示器、灯、警告喇叭功能；应急控制手柄与系统状态；tie bolts 是否松动；anti-skid 线路；轮胎磨损、割伤、老化、油污、slippage marks 与充气；转向钢索磨损、断股、对正与保险；支柱裂纹、腐蚀、断裂与固定。
- 润滑：只用维修手册规定的润滑剂；注油前把 grease fitting 擦净（泥沙混入油脂会变成研磨膏）；注油后擦掉多余油脂；外露的支柱与作动筒活塞杆始终保持清洁。
- 机轮轴承：定期拆下、清洗（推荐溶剂，不得用 gasoline 或 jet fuel；不得蒸汽清洗）、检查（galling、spalling、overheating 变色、brinelling、bruising、cup 在轮内打转、保持架裂纹）、立即润滑防锈；吹干时绝不能让轴承高速旋转。
- 机轮：tie bolts 必须齐全紧固，缺一个即须拆下彻底检查两半轮；axle nut 太松会使 bearing cup 打转、滚柱 scalloping，太紧会使轴承过热失效，必须按厂家程序定扭；bead seat 区裂纹用 eddy current（着色渗透无效）；drive key 区用 dye penetrant；tie bolts 用 magnetic particle；thermal plug 一旦熔化，轮胎退役、机轮按厂家检查、相邻机轮也查。
- 拆胎安全：先放气、冷却（3 小时或更长）再动手；人从前或后方接近、不要正对侧broadside；破胎圈时 tie bolts 必须保持装好并拧紧；不得用螺丝刀撬胎；只得用皂液，绝不用含烃润滑剂。
- 收放试验（swinging the gear）：顶起飞机、清洁润滑后按飞行状态收放，同时目视检查固定与动作；每次都要检查应急/备用放下系统；时机含年度检查、更换或调整影响系统的部件后、硬着陆或超重着陆后，以及排故。
- 调整（rigging）：latch roller 间隙、舱门间隙（hinge 长圆孔/锯齿垫圈/rod end/door stops）、side brace 的 over-center（lock link 端接头、6 inches 回弹试验、spring scale 查锁簧张力）；所有程序在飞机顶起、起落架收上状态完成；舱门过紧伤结构、过松兜风增阻。
- 刹车：机上查 lining wear、系统是否有空气、液量、渗漏、螺栓扭矩；Cleveland 可用 number 40 twist drill（0.098 inches）比对衬片，multiple disc 在施加刹车时测 pressure plate 与 housing 距离；踏板海绵感必须放气。
- 放气方法：master cylinder 系统可 top down 重力或 bottom up 压力（pressure pot）；power brake 系统只能 top down，因为 bottom up 会把空气逼进主液压系统。
- 液压油：矿物基 MIL-H-5606（red oil）绝不能与磷酸酯基 Skydrol® 混用；被污染的系统必须排空全部液体并更换所有密封件后才能放行。
- 渗漏：先卸压再断开检查接头；过度拧紧会损坏接头，MS flareless 接头尤其敏感；修好后重新增压并做功能测试。
- 刹车分解检查：螺栓与螺纹连接（self-locking nut 的锁定特性、非标准硬件不可替代）、盘（裂纹常自 relief slots 起、键槽磨损与变宽、glazing 可重新表面加工）、automatic adjuster pins（须平直、grip 在规定力下走完全行程）、torque tube（磁粉查裂纹）、housing（荧光渗透查裂纹、缸孔尺寸）、piston、密封件全部换新且注意货架寿命、back-up rings 装在 O-ring 远离压力侧。
- 刹车故障：过热（中断起飞后必须拆下分解、换全部密封件、查壳体裂纹/翘曲/硬度、盘不得翘曲、装机前做台架渗漏与压力测试）；拖滞（回位机构、盘翘曲、油路有空气、错误零件）；颤振与尖叫（盘翘曲、叠层不平行、表面材料转移）。
- 轮胎检查：胎压必须按机体维护数据（不是胎侧标注、不是"看起来"），在带载状态测、用校准压力表；欠压会过度挠曲生热、磨肩、在轮辋上打滑、夹伤侧壁，双轮中一条严重欠压须两条同换；过压会降低附着、磨中间、易受割伤与爆裂。
- 轮胎损伤：任何可疑损伤与渗漏处在放气前用粉笔/蜡笔/漆笔标记；沟槽裂纹可导致 undercutting 甚至整条花纹被"甩掉"（thrown tread）；鼓包或胎面与胎体分离立即停用；侧壁帘线外露即更换；圆周方向裂纹或裂口不可接受。
- 翻新与存放：几乎所有轮胎修理须在 certified tire repair facility 完成，翻新站用 shearography 判断胎体；翻新次数无固定限制，取决于胎体结构完整性（主轮可用几次，部分前轮近十几次）；存放要求见第 4 节数值。
- 装胎：轮辋 bead seat 须光滑无缺陷、O-ring 润滑且状态良好；确认胎侧标注 tubeless、件号、尺寸、ply rating、speed rating 与 TSO 号；轮胎序列号装在外侧；两半轮的 light 标记相对，轮的 heavy spot 对准胎上红点（light spot），无 heavy 标记时把红点对准充气活门位置；按厂家顺序与扭矩拧 tie bolts（常见 anti-seize 与 wet torque），只用校准的手扭力扳手，绝不用 impact wrench；装复后做静平衡，必要时加配重。
- 无内胎胎充气：充到工作压力后无载放 12 hours，压力降 5–10 percent 属正常；补压后每日损失小于 5 percent，超过须查明。

## 7. 高频考点 · TECC 完形填空

> 10 道题，全部取材本章（飞机起落架系统）。每题一个空、四个选项，只有一个最合适——干扰项按**形近词、同词族变体、近义词**设置。答案与解析在末尾。

**1.** Because the CG of a tricycle-gear aircraft lies ahead of the main wheels, the brakes can be applied firmly without the aircraft _____.

A) nosing over　　B) nosing in　　C) nosing out　　D) nosing up

**2.** Landing impact is cushioned by forcing hydraulic fluid through a metering orifice, and the _____ of that energy appears as heat.

A) absorbing　　B) absorb　　C) absorption　　D) absorbed

**3.** Before a shock strut is recharged with nitrogen, the oil level must be _____ to the service valve port.

A) adjust　　B) adjusted　　C) adjusting　　D) adjustment

**4.** A seriously underinflated tire will _____ its sidewalls excessively and generate damaging heat.

A) flex　　B) bend　　C) bow　　D) warp

**5.** Small depressions in a wheel bearing race caused by heavy impact loads are called _____.

A) spalling　　B) galling　　C) brinelling　　D) scoring

**6.** Only after the aircraft has been jacked and the ground locks removed _____ the gear be swung.

A) could　　B) should　　C) must　　D) can

**7.** A power brake system must be bled from the top down, so that air is never forced _____ the main hydraulic system.

A) back out　　B) back into　　C) back up　　D) back off

**8.** A proximity sensor must be set with a go–no go gauge, because its _____ distance is critical to the gear logic unit.

A) installing　　B) install　　C) installment　　D) installation

**9.** A tire that is hydroplaning loses contact with the runway, and both steering and braking become _____.

A) effect　　B) effective　　C) ineffective　　D) ineffectively

**10.** If a strut is low on fluid, it will _____ at the end of the compression stroke and pass the impact into the structure.

A) bottom in　　B) bottom out　　C) bottom up　　D) bottom off

### 答案与解析

**1. A** —— `nose over` 是「（飞机刹车过猛）拿大顶、前翻」的固定短语，`without the aircraft nosing over` 中动名词作介词宾语。B `nose in`、C `nose out`、D `nose up` 虽都是 nose + 小品词，但分别表示「机头向内/向外/上仰」，都不是前翻。考点：**同一动词换小品词**。

**2. C** —— 空格前有定冠词 `the`、后有 `of that energy`，必须填名词 `absorption`（吸收）。A `absorbing` 是动名词/分词、B `absorb` 是动词原形、D `absorbed` 是过去分词（且此处不构成被动），都不能直接作 `the ... of` 的中心名词。考点：**同词族名词化**。

**3. B** —— `must be _____` 是被动结构，需过去分词 `adjusted`（油位必须被调整到勤务活门高度）。A 是原形、C 是现在分词、D 是名词，都无法构成被动。考点：**情态动词 + be + 过去分词**。

**4. A** —— 描述轮胎侧壁反复变形用 `flex`（挠曲），这是轮胎术语中的固定动词。B `bend`、C `bow` 指刚性件整体弯曲、D `warp` 指受热后永久翘曲，都不是「侧壁反复挠曲生热」的意思。考点：**近义动词的工程语义差别**。

**5. C** —— `brinelling` 专指滚道受冲击载荷产生的压痕。A `spalling` 是表面剥落、B `galling` 是金属粘着擦伤、D `scoring` 是划伤，四者都是轴承缺陷名但机理不同。考点：**同类术语的近义辨析**。

**6. D** —— `Only after ...` 置于句首时主句要**部分倒装**，情态动词提到主语 `the gear` 之前，故用 `can the gear be swung`。A `could` 时态不符、B、C 与陈述语序的 `the gear be swung` 搭配时不能成立，因为倒装句必须把助动词/情态动词提前。考点：**only + 状语引起的部分倒装**。

**7. B** —— `force air back into the system`（把空气逼回主系统）是本章强调的禁忌，`back into` 表示「反向进入」。A `back out` 退出、C `back up` 支撑/备份、D `back off` 松开，方向或语义都不对。考点：**back + 不同介词的方向义**。

**8. D** —— 空格需要名词修饰 `distance`，`installation distance`（安装距离）成立。A `installing` 是动名词（口语化且不地道）、B `install` 是动词、C `installment` 意为「分期付款/分册」，是同词族但词义跑偏的干扰项。考点：**同词族名词的词义甄别**。

**9. C** —— `become` 是系动词，后接形容词作表语；滑水时转向与刹车都失效，需要否定意义的 `ineffective`（失效的）。A `effect` 是名词、B `effective` 意思相反、D `ineffectively` 是副词不能作表语。考点：**系动词 + 形容词表语**。

**10. B** —— `bottom out` 是「（减震支柱）压到底、触底」的固定短语，正是缺油支柱压缩行程失控的表现。A `bottom in`、C `bottom up`、D `bottom off` 都不是该义项的搭配。考点：**bottom + 小品词的固定搭配**。

## 8. 易混点

- **debooster 与 lockout debooster**：两者都用大小活塞降压；差别是 lockout debooster 在下游失油时像 hydraulic fuse 一样切断油流，保住系统油液，且有复位手柄，不复位就无法刹车。
- **thermal plug 与 overinflation safety plug**：前者芯为低熔点合金，靠"过热"熔化放气；后者靠"过充压力"破裂放气，两者都装在轮上但触发条件不同。
- **dynamic hydroplaning 与 viscous hydroplaning**：前者是轮胎前积水形成水膜、轮胎"跑"在水面上；后者是薄水膜与污染物混合形成极滑条件，光滑跑道也会发生，锁死的机轮可能留下 reverted rubber 或 skid burn。
- **squat switch 与 proximity sensor**：squat switch 是装在支柱上、随支柱伸缩机械开闭的开关；proximity sensor 是无接触的电磁传感器，靠 target 靠近程度改变回送电压，更适合脏湿环境，需用 go–no go gauge 设定安装距离。
- **shimmy damper 与 steering damper**：shimmy damper 是专门抑制前轮摆振的阻尼件（液压节流、叶片或橡胶活塞式）；steering damper 指大型机靠转向作动筒内保持压力提供的阻尼，是转向系统的"附带"功能。
- **Type VII 与 Type VIII 轮胎命名**：Type VII 是两个数字、中间 X（总直径 X 断面宽）；Type VIII 是三段、前两个用 X、后两个用 –（直径 X 断面宽 — 轮辋直径），子午胎把 – 换成 R。
- **premature 换胎的两种胎压偏差**：欠压是"过度挠曲生热、磨胎肩"，过压是"附着下降、磨胎冠中间"，磨痕位置正好相反。

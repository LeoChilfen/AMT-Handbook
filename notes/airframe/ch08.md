# Ch 08 · Aircraft Painting & Finishing（飞机涂装与表面处理）

## 1. 一句话

本章讲飞机涂装的全链条：涂料与底漆的选型、表面预处理（清洗、酸蚀、转化膜）、喷涂设备与安全防护、常见漆膜缺陷的成因与纠正，以及国籍标志的涂刷与放行规定。

## 2. 本章要点

- 涂装不只是外观：面漆（topcoat）保护裸露表面免于腐蚀和劣化，正确涂装的飞机更易清洁维护，因为漆面抗腐蚀、抗污，油也不易附着；但漆层同时计入飞机重量。
- "Paint" 是统称，包含底漆（primer）、磁漆（enamel）、硝基漆（lacquer）及各种多组分涂料。涂料由三种成分构成：树脂（resin，成膜材料）、颜料（pigment，提供颜色）、溶剂（solvent，把混合料稀释到可施工粘度）。
- 底漆是涂层的基础，作用是粘结表面、抑制金属腐蚀、为面漆提供附着锚点（anchor point）。底漆颜料必须对金属呈阳极性（anodic）或在有水分时钝化表面；非金属表面的底漆不需要牺牲性（sacrificial）或钝化颜料。
- 表面处理是整个涂装工程最重要的部分，最费工时。铝表面流程为：碱性航空清洗剂 + Scotch-Brite 擦洗 → 冲净至水膜连续（water break free）→ 酸蚀（acid etch）→ 冲净 → 铝转化膜（Alodine）→ 尽快涂底漆。
- 有机涂层的耐久性排序上，聚氨酯（polyurethane）在耐磨、抗污、耐化学方面居首，并天然耐 UV，是当今公务机与运输机涂装的首选；硝基漆（lacquer）易施工但不耐久，飞机外表面已几乎不再使用。
- 喷涂质量取决于三件事：设备（空压机气量与除水除油过滤、喷枪选择）、粘度（Zahn 杯测流出时间）、手法（垂直 8–10 英寸、约每秒一英尺、搭接 50%、先扳机后移动）。
- 绝大多数漆膜缺陷来自"配比—温度—湿度—手法"四者之一：blushing 是水分被封进漆膜，fisheyes 是硅酮蜡污染，orange peel 是雾化不良或稀释不足，sags/runs 是漆量过多。
- 国籍与登记标志由 14 CFR Part 45 规定：无装饰、与背景色对比、清晰可读；标准类固定翼飞机字高至少 12 英寸。涂装前必须确认漆系相容性（paint system compatibility），否则返工。

| STC | 补充型号合格证 | 蒙布系统（Ceconite®、Poly-Fiber®）的涂料与工艺须按 STC 规定使用 |
| TSO | 技术标准规定 | Grade A 棉/麻蒙布须满足 FAA TSO C-15d/AMS 3806c |
| Alodine® | 阿洛丁（铝转化膜） | 铝表面的化学转化涂层，可使铝呈浅金色或绿色，也有无色产品 |

## 4. 关键数字与公式

- 涂料三组分：树脂（coating material）、颜料（pigment）、溶剂（solvent）。
- 丁醇（butyl alcohol）掺入涂布漆溶剂以延缓干燥、防止 blushing：5%–10%。
- 丁醇与乙醇混合稀释 wash coat primer 用于喷涂：比例 1:1 至 1:3。
- 铝表面处理施工环境温度：68 °F 至 100 °F。
- 酸蚀液（acid etch）在表面保持湿润的接触时间：1–2 分钟。
- 铝转化膜（Alodine®）保持湿润的接触时间：2–5 分钟，不得让其干燥。
- 复合材料环氧打磨底漆可用 320 grit 砂纸配合双作用偏心打磨机（D/A sander）打磨。
- 涂布漆/涂料的机械振荡（paint shaker）要求：使用前 5 天内完成；两份组分涂料推荐机械搅拌。
- 两组分涂料的诱导时间（induction time）：有的为 0，有的需 30 分钟反应时间。
- 常规虹吸式喷枪供气：空压机储气罐能提供至少 90 psi、10 CFM 的连续气量。
- HVLP 喷枪配常规空压机：宜用至少 5 hp 的两级空压机，工作压力 90 psi，供气 20 CFM。HVLP 的关键是气量（volume）而非压力。
- HVLP 涂料转移率：至少 65%，最高可达 80% 以上。
- 无气喷涂（airless）：液压 500–4,500 psi 雾化涂料。
- 远程压力漆罐容量：2 夸脱至 60 加仑以上。
- 常规喷枪喷涂压力（调枪时）：通常 40–50 psi。
- 试喷距离：枪口距表面约 8–10 英寸（约拇指尖到小指尖的手掌张开距离）。
- 走枪速度：约每秒一英尺；相邻行程搭接 50%。
- 垂直面板施工时需先喷一道 tack coat，防止第二道流挂。
- 粘度测量时样品温度须在 73.5 °F ± 3.5 °F（23 °C ± 2 °C）；多数底漆与面漆推荐 #2 或 #3 Zahn 杯。
- 硝基漆喷涂时，喷枪中高达 85% 的 VOC 逸散到大气。
- 聚氨酯漆膜推荐的补漆打磨：损伤至底材时用 320 氧化铝砂纸（D/A 气动打磨机），周边湿磨用 1500 水砂纸；底漆轻磨用 1500 湿/干砂纸。
- 补漆羽化（blending）区域约为实际损伤面积的 3 倍；最后一道面漆用相容稀释剂稀释 1/3 至 1/2 后喷涂，并逐道扩大范围。
- 划痕修补打磨：主区域 320 grit，靠胶带线处用细目 Scotch-Brite。
- 3M® Fine Line 胶带宽度规格 1/8–1 英寸；直线或大半径曲线用 3/4 或 1 英寸，小半径曲线用 1/2 或 1/4 英寸。封边胶带用 3/4 或 1 英寸，遮盖纸用 1 英寸胶带（一半压纸、一半压胶带）。
- 纸基贴花（paper decal）浸泡清水 1–3 分钟；超过 3 分钟背纸会在水中与贴花分离，少于 1 分钟则背纸不脱离。
- 金属贴花（赛璐玢背衬）浸清洁温水 1–3 分钟。
- 无胶金属贴花使用 MIL-A-5092 胶粘剂，涂后待两面发粘再贴。
- 漆系相容性：丙烯酸硝基漆可附着于新喷（干燥不足 6 小时）的环氧涂层。
- 国籍标志尺寸（美国注册、标准类固定翼）：字高至少 12 英寸；滑翔机至少 3 英寸。
- 标志字符：高宽相等；宽为高的 2/3；笔画为实线且线宽为字高的 1/6；字母 M 与 W 可宽高相等；字符间距不小于字宽的 1/4。
- blushing 成因阈值：湿度高于 80%；温度低于 60 °F 或高于 95 °F。
- 二氯甲烷：1990 年被列为有毒空气污染物，并由 EPA 在 1990 年《清洁空气法修正案》中定为 HAP。
- 新鲜空气供气呼吸系统：可供气软管最长 200 英尺。

## 5. 结构 / 系统 / 部件

- 涂层体系（由内到外）
  - 表面处理层：清洗（碱性航空清洗剂）→ 酸蚀 → 转化膜（Alodine®/铝转化涂层）
  - 底漆层（primer）：wash primer / 环氧底漆 / 聚氨酯底漆 / 锌铬黄底漆 / 红氧化铁 / 灰色磁漆中涂
  - 面漆层（topcoat）：聚氨酯、丙烯酸聚氨酯、合成磁漆、硝基漆、涂布漆（蒙布）
  - 装饰与标识层：trim 色带、公司标志与徽标、贴花（decal）、登记标志与勤务说明标记
- 涂料化学（按成膜机理）
  - 溶剂挥发成膜：硝基漆、涂布漆、树脂清漆
  - 化学固化（催化）成膜：环氧、聚氨酯、丁酸/丙烯酸催化漆、催化型硝基漆
- 施工方法：浸涂（dipping，工厂/大修站）、刷涂（brushing，小修补与不便喷涂处）、喷涂（spraying，首选）
- 喷涂设备系统
  - 气源：活塞式空压机（单级/多级）+ 储气罐 + 调压器 + 水分离器（water trap）+ 油滤 + 管路过滤器
  - HVLP 系统：涡轮压缩机（多级风扇/级数），进气兼作电机冷却气，进气先过滤；涡轮不产生油水但出气升温，需加长软管降温
  - 供料：枪上漆杯（1 夸脱，虹吸式在下、重力式在上）、远程压力罐（2 夸脱–60 加仑）
  - 喷枪类型：虹吸式（外混）、重力式（外混）、HVLP 生产型（内混，外混之外唯一的内混类型说明）、无气式（液压雾化，非空气雾化）
  - 喷枪调节：上部旋钮调气量/喷幅（pattern），下部旋钮调漆量（fluid）；空气帽可旋转 90°
  - 辅助工具：遮蔽纸/胶带分配器、干膜测厚仪（电子式与磁式）、湿膜测厚仪、红外测温仪、粘度杯（Zahn cup）
- 涂装场所（paint booth）：小型喷漆间可至容纳最大飞机的机库；须遮风挡雨、照明良好、通风良好、无尘，理想还有温湿度控制。简易喷漆棚可用木框或 PVC 管 + 塑料膜搭成，一端排风扇、另一端进风空调滤网，灯具置于棚外透塑料窗照明。
- 漆膜缺陷谱（本章列举）：poor adhesion、blushing、pinholes、sags and/or runs、orange peel、fisheyes、sanding scratches、wrinkling、spray dust。
- 剥离方法体系：化学剥离（二氯甲烷类、EFS-2500）、塑料介质喷丸（PMB）、新方法（激光剥离、干冰颗粒 + 脉冲闪光灯）。
- 安全防护体系：通风系统（排风、补风）、防火（接地封闭电机、灯具防护罩、灭火器、防火垃圾桶）、个体防护（防毒面具/呼吸器、供气式呼吸系统、Tyvek® 连体服、橡胶手套、护目镜）。

## 6. 检查与维修要点

- 表面预处理（铝）：碱性航空清洗剂 + Scotch-Brite® 擦洗，保持湿润并用清水冲至 water break free（水面无珠、无断裂）；再上新海绵涂酸蚀液，1–2 分钟不干，冲净；干后涂 Alodine® 类转化膜 2–5 分钟不干，彻底冲净化学盐类；干后尽快涂底漆。隐藏区域必须冲净，残留药液是腐蚀源。
- 水膜测试（water break test）：用清水喷/浇/淋要喷漆的表面，若局部结珠则未清洁，水应铺平成连续膜。
- 底漆选择：须与面漆相容；双组分环氧底漆对多数环氧、聚氨酯表面及聚氨酯面漆提供最好的抗腐蚀与附着力。**锌铬黄不得用于聚氨酯漆之下。**
- 面漆必须在规定的施工时间窗内涂在底漆上，超时则需对底漆做打磨拉毛（scuff sand）。
- 复合材料：环氧打磨底漆作基底，可用 320 grit 配合双作用偏心打磨机打磨；与双组分环氧底漆、聚氨酯面漆相容。须打磨并封闭后再喷面漆，否则出现 sanding scratches。
- 涂料管理：只用航空涂料（比汽车漆更柔韧、更耐化学）；同一工程建议全用同品牌相容体系；采购时索取每组分的技术/材料数据表（technical/material data sheet）与安全数据表（SDS）；超期、变稠、胶凝的料不得使用；已开封结皮须彻底去除皮膜后再搅拌。
- 两组分涂料混合：催化剂/活化剂必须加入基料（base/pigmented component）；按规定诱导时间静置。
- 稀释：按厂家推荐与施工方法、设备、气压、大气条件确定稀释比；在独立容器中稀释混合，再经推荐目数的漆筛过滤后倒入漆杯或压力罐。
- 喷枪调枪：喷遮蔽纸试喷，垂直距 8–10 英寸，扳机全开，左右调两个旋钮，直到喷幅上下一片湿（类似 dial 10 的图样）。下部漆量旋钮顺时针减小出漆、逆时针增大；上部喷幅旋钮逆时针加宽喷幅、顺时针收成锥形。
- 走枪手法：起步后再扣扳机、结束前先松扳机（保持气流不断，避免每程末端积漆造成流挂）；直线移动、不得弧线（do not arc stroke）——弧线导致涂层不均。搭接 50%。
- 交叉喷涂（crosscoat）：先横后竖（顺序不限），先喷 light coat；垂直面先喷 tack coat 再喷第二道，防止流挂。两道水平轻喷搭接 50%，待 tack 后再竖喷覆盖。
- 整机喷涂顺序（单发/轻型双发）：先喷各角落与控制面与固定面之间的缝隙 → 各翼面前后缘 → 起落架与轮舱 → 机腹向上至水平分界（如接缝线）→ 水平安定面下表面 → 垂直安定面与方向舵 → 水平安定面上表面 → 机身顶部与侧面下至分界 → 机翼下表面 → 最后机翼上表面。
- 漆膜缺陷速查（成因 → 纠正）
  - poor adhesion（附着力差）：表面清洁/预处理不当、底漆选错、面漆与底漆不相容、稀释不当或用错等级稀释剂、混合不当、喷具或气源污染 → 彻底去除旧漆、查明并纠正原因、整块重新涂装。
  - blushing（发白）：溶剂快速蒸发降温使空气中水分凝结；湿度 >80%，温度 <60 °F 或 >95 °F，用了快干稀释剂，枪口气压过高 → 施工中发现可加慢干稀释剂后重喷；已干则打磨后重涂。
  - pinholes（针孔）：涂料或气路污染、涂层过厚过湿封住水分/溶剂、稀释剂过快或过慢 → 停喷评估设备与手法，干后打磨平滑重涂。
  - sags & runs（流挂）：漆量过多、枪太近、移动太慢、稀释剂过量（太稀）、气漆配比设置不当 → 按推荐稀释与手法施工（尤其垂直面与凸出边缘）；已干须打磨掉再重喷。
  - orange peel（橘皮）：喷枪调整不当（首要）、稀释剂不足或型号不符环境温度、搅拌不均、强制干燥（风扇/加热）过快、层间闪干时间不足、环境或基材温度过高过低 → 轻微可湿磨或用抛光膏抛掉；严重须磨平重喷。
  - fisheyes（鱼眼）：表面残留硅酮蜡等污染 → 立即停喷、擦掉湿漆、用硅酮蜡清除剂彻底清洁；偶发可待首道定型后在后续面漆中加推荐量的 fisheye eliminator；喷前确认空压机放水、调压器清洁、系统滤芯已换。
  - sanding scratches（砂痕）：喷面漆前未正确打磨/封闭（多见于非金属面：复合材料整流罩、木质面、塑料整流罩），或用了过快干的稀释剂 → 用更细砂纸磨掉、上推荐封闭漆（sealer）后重喷。
  - wrinkling（起皱）：厚涂或含溶剂过多的涂层使溶剂被封在下面、干燥不均；快干稀释剂；层间未干就压厚涂；喷涂中环境温度剧变；用不相容的稀释剂 → 必须彻底清除并重新涂装。
  - spray dust（干喷）：雾化颗粒到表面前已干；气压/漆量/喷幅设置不当、枪太远、稀释不当或稀释剂选错 → 打磨后重涂。
- 漆种识别（补漆前必做）
  - 滴一点机油（MIL-PRF-7808 涡轮油或等效品）在待查表面：老硝基漆几分钟内软化；丙烯酸与环氧漆无反应。
  - 若仍无法判定，用 MEK 湿布轻擦（只擦不搓）：MEK 会带下丙烯酸漆的颜料，对环氧漆无影响；重搓连未完全固化的环氧也会掉色。**硝基漆上不得使用 MEK。**
  - 书中另附溶剂测试表（Figure 8-22）：用浸过测试溶剂的棉球接触 3–5 分钟，按 IS（不溶）、ISW（不溶但漆膜起皱）、PS（渗入漆膜轻微软化不起皱）、S（可溶）、SS（微溶）、VS（极易溶）判定漆种。
- 补漆（touchup）工艺
  - 先清洗并用去蜡剂/去油剂擦洗，再打磨。
  - 若整块蒙皮或接缝线以内可整片重做，则省去颜色匹配与羽化；剥离至接缝线，从 wash primer 到面漆整套重做；边缘湿磨并用 320 号砂纸羽化。
  - 点修补：准备约 3 倍损伤面积用于羽化；穿透底漆至基材时，用 320 氧化铝砂纸 + D/A 气动打磨机打磨，再用 1500 水砂纸湿磨损伤区及周边，喷前用 tack cloth 擦净。
  - 裸金属处喷一道交叉环氧底漆（crosscoat），按数据表控制干燥与重涂时间；底漆轻磨 1500，未打磨的边缘区域用研磨膏（cutting compound）处理；用异丙醇类去油溶剂 + tack cloth 清洁。
  - 喷两道轻面漆（第二道略超出第一道，层间留闪干时间），再用相容稀释剂按 1/3–1/2 稀释喷最后一道并继续扩大范围；按数据表干燥后抛光羽化区。
- 漆系相容性八条规则（补漆必查）
  1. 老式锌铬黄底漆可直接用于裸金属点补与内部涂装；状态良好时可用 wash primer 覆盖；丙烯酸硝基漆不附着于它。
  2. 改性锌铬黄底漆对裸金属附着不佳，绝不可涂在已干的丙烯酸硝基漆膜上。
  3. 硝基漆可附着于丙烯酸漆上，反之不可；丙烯酸硝基漆不得涂在老硝基漆上。
  4. 丙烯酸硝基漆对裸金属、硝基漆与环氧漆附着都很差；最佳做法是先喷新鲜连续的 wash primer 与改性锌铬黄，再喷它；它也能附着于新喷（干燥 <6 小时）的环氧涂层。
  5. 环氧面漆能附着于任何状态良好的漆系，可用于一般点补，包括烤漆（baked enamel）缺陷的修补。
  6. 老 wash primer 层可直接被环氧覆盖；若要喷丙烯酸漆，必须补一道新的 wash primer。
  7. 老丙烯酸漆若先用丙烯酸硝基稀释剂软化，可用新丙烯酸漆重做。
  8. 环氧漆的损伤最好用环氧修补，因为两种硝基漆都不附着于环氧表面；个别情况下，把损伤边缘用细砂纸打磨后可用气干磁漆点补。
- 剥离（stripping）
  - 目的：减重，并借机检查与修理被漆层掩盖的腐蚀与缺陷。
  - 剥离前保护：窗材、通气口与静压孔、橡胶密封与轮胎、可能受化学影响的复合材料件，按剥离剂厂家推荐的防护材料遮蔽。
  - 化学剥离：二氯甲烷类曾长期使用（1990 年前被认为环保可接受），1990 年因致癌等被列为有毒空气污染物并被 EPA 定为 HAP；替代品（甲酸、苯甲醇等）对多层漆效果不佳。EFS-2500 靠破坏基材与底漆之间的结合，使底漆与面漆作为一层膜整片掀起，可用刮板或高压水去除；不熔化涂层，无氯化物、非酸性、不燃、无害、可生物降解，通过波音关于夹层腐蚀、浸泡腐蚀与氢脆的测试；可用无气喷涂、刷、滚或槽浸施工，适用于铝、镁、镉镀层、钛、木材、玻璃纤维、陶瓷、混凝土、石膏、石材。
  - PMB 塑料介质喷丸：干式磨料，用软质有棱角塑料颗粒，气压较低，对底层表面影响最小；介质经回收系统可重复使用至多 10 次；最适合金属表面，在复合材料上也已成功使用（视觉损伤小于砂磨）。
  - 新方法：激光剥离（复合材料）、干冰颗粒配合脉冲闪光灯快速加热薄漆层再被冰粒打掉。
- 喷漆间安全
  - 必须装足够通风系统，既排毒气又减少/消除过喷与灰尘落于漆面；排风与风机电机须接地并封闭防爆；照明与灯泡须有罩防破碎。
  - 需为所有参与剥离与涂装的人员配备合格呼吸器与新鲜空气供气系统；调配任何涂料或双组分涂料时须戴护目镜与呼吸器。
  - 喷漆作业期间须备足适用类别与数量的灭火器，并按要求称重与认证；须有防火容器丢弃浸漆/浸溶剂的抹布。
  - 涂料与溶剂存放：远离一切热源与明火，理想存于通风良好的防火金属柜；有保质期的组分应在容器上标注购买日期。
  - 个体防护：口罩式呼吸器（双活性炭滤罐 + 可换粉尘滤棉，与鼻口密合）可防有机蒸气、粉尘、漆雾，但**不能防含异氰酸酯的涂料（聚氨酯漆）**；喷任何聚氨酯或含异氰酸酯涂料必须用强制供气（forced-air）呼吸系统，其他所有喷涂与剥离（化学或喷丸）也推荐使用。若呼吸困难、闻到/尝到污染物、头晕恶心，立即离开并到新鲜空气处求助。穿 Tyvek® 连体服（兼防漆与防尘落于漆面）；使用任何剥离剂、酸蚀液、转化膜与溶剂时必须戴橡胶手套。
  - 清洗喷具溶剂的区域不得有明火或其他热源；不得把溶剂随意喷入大气；不得用溶剂洗手洗臂。多数州有 OSHA 规定，要求雇主保护员工免受蒸气等危害。
- 标志与标记（法规）
  - 依据：14 CFR Part 45《Identification and Registration Marking》。要点：漆于机体或用其他同等永久性方式附着；无装饰；与背景色形成对比；清晰可读。
  - 显示内容：罗马大写字母"N"（表示美国登记）后接登记号；每个后缀字母也须为大写罗马字母。
  - 位置（固定翼）：垂尾面上，或机身两侧；在垂尾上时须水平显示于单垂尾两面或多垂尾外表面；在机身上时须水平显示于机翼后缘与水平安定面前缘之间的机身两侧。直升机须水平显示于座舱、机身、尾梁或尾部两面；飞艇、气球、动力伞、重量转移控制类按 14 CFR Part 45 执行。
  - 尺寸：绝大多数美国注册标准类固定翼飞机字高至少 12 英寸；滑翔机至少 3 英寸。等高等宽比例、笔画与间距规则见第 4 节；两侧标志的高度、宽度、笔画与间距必须一致。标志须喷涂，贴花（decalcomania）则须永久性附着。特殊适航证飞机及进入 ADIZ/DEWIZ 空域的飞机另有例外，须查现行 14 CFR Part 45。
- 贴花（decals）
  - 类型：纸基、金属箔、乙烯基薄膜；可用于外表面与内表面。用于勤务说明、燃油滑油规格、油箱容量、顶升与水平点、走道、电瓶位置等标识；比喷字便宜、易施工。
  - 贴前清洁：用 aliphatic naphtha（脂肪族石脑油）彻底清除油脂、油、蜡与异物；多孔表面须封闭，粗糙表面须打磨后再清洁。
  - 纸基贴花：清水浸 1–3 分钟，一边缘先贴、轻压后抽出背纸，手指微调，软布吸干水分，向最近边缘赶出气泡，待干。
  - 赛璐玢背衬金属贴花：清洁温水浸 1–3 分钟 → 干布擦干 → 揭去背衬（不碰胶）→ 一边先贴，大张箔贴花从中心向边缘赶 → 橡胶辊压实排除气泡并压紧边缘。
  - 纸背衬金属贴花：同法但不必浸水，背纸可直接揭下；必要时按厂家方法活化胶。
  - 无胶金属贴花：两面涂 MIL-A-5092 胶 → 待发粘 → 贴上并刮平排气 → 用蘸 aliphatic naphtha 的布清除多余胶。
  - 乙烯基贴花：揭去背纸，用蘸水净布搓掉残纸，残屑用遮蔽胶带粘除；膜面朝上置于木质或多孔吸水纸上；在胶面用推荐活化剂均匀用力涂布；胶仍发粘时一边先贴定位；用辊交叉压实至无气泡。
  - 去除：纸基贴花用蘸硝基稀释剂（lacquer thinner）的布擦除，若贴于漆面或涂布漆面须少用以免伤漆；金属贴花用 aliphatic naphtha 润湿边缘后揭下，须通风良好；乙烯基贴花用浸 MEK 的布覆在贴花上，用塑料刮板刮除，残胶用蘸干洗溶剂的布擦净。
- 遮蔽（masking）与 trim 施工
  - 3M® Fine Line 胶带耐溶剂、宽 1/8–1 英寸、贴好可得锐利漆线；不可用报纸遮蔽（漆会渗透）；用真正遮蔽纸与优质遮蔽胶带。
  - 直线与大半径用 3/4 或 1 英寸胶带并拉紧；小半径用 1/2 或 1/4 英寸；选能贴平且能走顺曲线的最宽胶带；用壁纸滚轮把胶带边缘压实。
  - 先在一侧（机身、垂尾与方向舵、发动机短舱、机翼）完成 trim 线，检查后再翻到另一侧；可用描图纸转移，或以蒙皮/铆钉线加测量定位；两侧完成后各拍照片比对一致性。
  - Fine Line 外侧可加压 3/4 或 1 英寸封边胶带（压一半宽、越出外缘），再上遮蔽纸（1 英寸胶带一半压纸一半压胶带），其余裸露区全部遮盖防过喷，覆盖边缘须封贴。
  - 喷 trim 前对 trim 区做 scuff sand 去掉基漆光泽（主区 320，胶带线旁用细目 Scotch-Brite），吹净灰尘，用去油剂与 tack cloth 擦净，再压一遍胶带边。
  - 要锐利漆线，可在喷 trim 色前先薄喷一道基色或清漆封住胶带边。
  - 多色 trim：喷完一色干燥后，用遮蔽纸盖住已喷区、露出下一区，注意不要压实到刚干的漆上。
  - 拆除：最后一道 trim 干到手触不粘即尽快去除遮蔽纸；Fine Line 胶带以锐角缓慢回折自身揭起；底漆上的胶带也应尽快去除，避免伤漆。
- 材料保存与调漆补充：paint shaker 用于 5 天内将用的所有涂料；机械搅拌器若用电钻驱动，必须用气动钻——电钻火花可引燃漆蒸气。

## 7. 高频考点 · TECC 完形填空

> 10 道题，全部取材本章（飞机涂装与表面处理）。每题一个空、四个选项，只有一个最合适——干扰项按**形近词、同词族变体、近义词**设置。答案与解析在末尾。

**1.** The primer bonds the surface, inhibits corrosion and _____ an anchor point for the topcoat.

A) provide　　B) provides　　C) providing　　D) provided

**2.** A surface is clean enough for painting when water spreads into a continuous film instead of _____ into droplets.

A) bead　　B) beads　　C) beading　　D) beaded

**3.** Silicone wax left on the surface is the classic cause of _____, small craters that expose the substrate.

A) pinholes　　B) fisheyes　　C) blushing　　D) orange peel

**4.** The topcoat must be applied _____ the recoat window, or the primer has to be scuffed first.

A) within　　B) without　　C) beyond　　D) beside

**5.** Blushing appears as a milky white haze caused by moisture _____ in the film.

A) trapping　　B) trapped　　C) trap　　D) traps

**6.** Zinc chromate primer must not be _____ under a polyurethane topcoat.

A) use　　B) using　　C) used　　D) uses

**7.** Viscosity is recorded as the _____ time of the paint from a Zahn cup.

A) effluent　　B) effusion　　C) effort　　D) efflux

**8.** Rather than one heavy pass, the painter should build _____ several light coats to avoid runs.

A) up　　B) on　　C) out　　D) in

**9.** Orange peel is often caused by _____ atomization or by too little thinner.

A) poorly　　B) poor　　C) poverty　　D) poorer

**10.** A charcoal cartridge respirator does not protect the painter against _____ paints.

A) isocyanide　　B) cyanide　　C) isocyanate　　D) nitrate

### 答案与解析

**1. B** —— 主语 the primer 为第三人称单数，并列谓语 bonds、inhibits 也都是单数，故填 provides。A provide 是原形，C providing 是分词，D provided 是过去式，均破坏主谓一致。

**2. C** —— `instead of` 是介词短语，后面接动名词 beading（结珠）。A bead 是原形，B beads 是第三人称单数，D beaded 是过去式，都不能直接作介词宾语。

**3. B** —— fisheyes（鱼眼）是硅酮蜡污染造成的露底小孔，与后半句 small craters that expose the substrate 完全对应。A pinholes 是漆膜内封闭的小孔，C blushing 是发白，D orange peel 是橘皮，成因与外观都不同。

**4. A** —— `within the recoat window` 是「在重涂时间窗内」的固定搭配。B without 是「没有」，与 must 连用逻辑相反；C beyond 是「超出」，D beside 是「在……旁边」，都不能修饰时间窗。

**5. B** —— moisture 与 trap 是被动关系，需过去分词 trapped 作后置定语（被封在漆膜里的水分）。A trapping 表主动，C trap 是原形，D traps 是第三人称单数，均不能作定语。

**6. C** —— `must not be _____` 是被动语态，需过去分词 used。A use 是原形，B using 是现在分词，D uses 是第三人称单数，都不能与 be 构成被动。

**7. D** —— `efflux time`（流出时间）是 Zahn 杯测粘度的标准术语。A effluent 指废水/流出物，B effusion 指渗出/倾泻，C effort 指努力，三个形近词都不是该术语。

**8. A** —— `build up` 是「逐层堆叠、逐步增加」的短语动词，build up several light coats 即多道薄涂。B build on 是建立在……基础上，C build out 是扩建，D build in 是嵌入，语义都不合。

**9. B** —— atomization 是名词，需形容词 poor 修饰，`poor atomization`（雾化不良）是橘皮的典型成因。A poorly 是副词，不能修饰名词；C poverty 是名词「贫困」；D poorer 是比较级，句中无比较对象。

**10. C** —— isocyanate（异氰酸酯）是聚氨酯漆中的有害成分，普通活性炭滤罐无法防护。A isocyanide 是异腈，B cyanide 是氰化物，D nitrate 是硝酸盐，三者均为形近但化学类别不同。

## 8. 易混点

- **primer 与 topcoat**：底漆是哑光（flat，无光泽）、提供防腐与附着；面漆有光泽、提供耐候与外观。把"底漆喷成亮光"或"面漆当底漆用"都是错的。
- **环氧底漆与聚氨酯底漆**：两者都是双组分催化固化，但环氧不含异氰酸酯、较软、抗石击好，可作裸金属上的免打磨底漆/封闭漆；聚氨酯底漆含异氰酸酯活化剂，须做特殊防护，易打磨、填充好，但厚涂会收缩。
- **polyurethane 与 acrylic urethane**：聚氨酯耐强化学性最好、天然耐 UV；丙烯酸（"acrylic"意为塑料）干后更硬、耐强化学性较差，多数需另加 UV 抑制剂。
- **lacquer 与 enamel**：硝基漆靠溶剂挥发成膜、可再溶（新漆层会软化并融入旧层，故易点修补），但不耐久、会泛黄龟裂；合成磁漆是油性单组分，靠氧化/固化成膜，耐久性好但不能靠再溶融合。
- **blushing 与 wrinkling**：blushing 是水分凝结造成的"发白"，漆膜本身平；wrinkling 是溶剂被封在下层导致表层先干、收缩起皱，常伴随底层被"掀起"，效果类似脱漆剂。
- **sags/runs 与 orange peel**：前者是漆量过多导致漆往下流（垂直面与凸边最明显）；后者是雾化/流平不良导致的表面凹凸，漆并没有流走。
- **二氯甲烷与 EFS-2500**：前者是传统强效剥离剂（1990 年被列为 HAP），靠溶解/熔化涂层；后者靠破坏基材与底漆的结合使漆整片掀起，不熔化涂层，无氯化物、非酸性、不燃。

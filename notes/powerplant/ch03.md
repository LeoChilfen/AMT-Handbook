# Ch 03 · Induction & Exhaust Systems（进气与排气系统）

> 说明：本文件对应 PDF 129–159 页，页眉为 3-1～3-31，正文实为 Chapter 3「Induction & Exhaust Systems」。燃油与燃油计量（AVGAS、Jet A、float-type 汽化器、FCU 等）不在此文件内，而在 `powerplant-ch02.txt`（PDF 83–128 页，页眉 2-1～2-46）那一章。

## 1. 一句话

本章讲活塞发动机进气系统（进气斗、滤、汽化器加热、增压器与涡轮增压器控制）和活塞/涡轮发动机的排气系统（排气管、喷管、推力反向、加力、消音与排放），重点在冰、增压控制与排气部件的失效检查。

## 2. 本章要点

1. 进气系统的任务链是：进气斗（air scoop）→ 导管 → 空气滤 → 燃油计量装置（汽化器或燃油喷射器）→ 进气总管 → 气缸。节气门后的空气压力叫进气总管压力（manifold pressure），用英寸汞柱（"Hg）计量，直接决定功率输出。
2. 汽化器结冰分三类：撞击冰（impact ice）、燃油蒸发冰（fuel evaporation ice）、节气门冰（throttle ice）。除冰靠汽化器加热（carburetor heat），热源取排气总管周围的加温空气；用过量的加热会降低空气密度、减少充气重量、损失功率，高温还可能引起爆震。
3. 部分油门（part throttle）时节气门处形成极低压区，是节气门冰的成因；滑翔时定距桨风车转动使发动机吸气量增大，会加剧这一低压。装可变距桨的发动机用较高的 BMEP、在低转速下开大节气门，可减轻节气门结冰倾向。
4. 往复式发动机进气系统按有无增压分为自然吸气与增压两类；增压又分内部驱动（机械传动、压气机位于汽化器之后）和外部驱动（涡轮增压器，压气机位于燃油计量装置之前）。
5. 只有把进气总管压力增压到 30 "Hg 以上才算真正的增压（ground boosted）；只补偿高度带来压力损失的叫归一化（normalizing），不属地面增压。涡轮增压器由压气机组件、涡轮叶轮组件、全浮式轴轴承组件三大部分组成，用发动机滑油作控制与润滑介质，靠废气门（waste gate）调节涡转转速。
6. 涡轮增压系统靠控制器放油（bleed oil）建立废气门作动筒油压：油流限制越多、作动筒压力越高、废气门越关、增压越大。三个自动调节件是排气旁通活门组件、密度控制器（density controller）、压差控制器（differential pressure controller）；另有绝对压力控制器、斜率控制器（sloped controller）与可变绝对压力控制器（VAPC）。
7. 排气系统是"扫气"系统，首要职责是安全排走高热有毒废气；活塞机分短排气管（short stack）与集合器（collector）两类，涡轮增压机必须用集合器把废气集中去驱动涡轮。
8. 涡轮排气段的关键件是喷管：收敛喷管靠减小出口面积提高流速增推，流速到 Mach 1 即成"堵塞喷管"，多余流量转为压力推力；压比足够高时用收敛-扩张（C-D）喷管。推力反向器分机械阻挡式（蛤壳门）与气动阻挡式（平移罩、阻挡门、叶栅），加力燃烧可把推力提高到原来的两倍。

## 4. 关键数字与公式

- 进气总管压力单位：英寸汞柱（"Hg）；真增压的门槛值是 **30 "Hg**（超过 30 "Hg 才算 supercharged / ground boosted）。
- 地面增压型涡轮增压系统可把进气总管压力从 30 "Hg 提高到约 **40 "Hg**。
- 归一化涡轮增压器常设定在某一高度以上才工作，书中举例 **5,000 ft**；低于该高度不增压即可获得最大功率。
- 临界高度举例：**16,000 ft**——高于此高度无法保持 100% 额定进气总管压力。
- 汽化器进口空气 **100 °F** 时，因燃油在汽化器喷嘴处部分汽化，温度约下降 **50 °F**。
- 涡轮增压器可把进气温度提高到约 **5 倍**；100 °F 的全功率起飞日，压气机出口气温可达 **500 °F**。
- 节气门进口允许的最高气温一般为 **230 °F（低）～300 °F（高）**，超过则更接近爆震。
- 全关的 augmentor vane 使排气管横截面积减小约 **45%**。
- 排气部件内部泄漏试验：堵住开口、充入约 **2 psi** 内压后浸入水中，冒泡即漏。
- 消音器与热交换器失效中约 **一半** 可追溯到用于座舱/汽化器加热的热交换面裂纹或破裂。
- 星形机排气集合环：**14 缸** 发动机的集合环由 **7 段** 焊成，每段收 **2 个** 气缸的排气；截面由内侧最小渐变到外侧（接排气管处）最大。
- 带引射器的星形机：**18 缸** 用 **2 套** 排气总管 + **2 套** 引射器，每套总管收 **9 个** 缸的排气。
- 高涵道比涡扇风扇：**1 级** 动叶 + 静子，直径 **小于 84 in 到大于 112 in**；外涵气流产生 **80%** 的推力。
- 未涵道（分开喷管）发动机：风扇气流产生 **80–85%** 总推力，内涵 **20–15%**。
- 涡桨排气喷管只产生 **10–15%** 的推力，其余能量已传给螺旋桨。
- 加力燃烧可把推力提高到原来的约 **2 倍**，耗油也几乎翻倍（"almost double"）。
- 推力矢量：矢量喷管可上下偏转 **20°**。
- 排气噪声几何（图 3-52）：以喷管直径 **D** 为基准，高频细涡流区约在喷口后 **10 D** 内，低频大涡流区约在 **30 D** 处，扩散锥角 **10°**。
- 音速界限：喷口流速达 **Mach 1** 后不再随压比升高；发动机内气流任何时刻都必须低于 Mach 1。
- 压力推力公式（文字表述）：**压力推力 =（喷管内压力 − 外界大气压力）× 喷口面积**。

## 5. 结构 / 系统 / 部件

- 活塞发动机进气系统
  - 进气斗（装在整流罩上，迎风）→ 空气滤（铝合金框 + 深压波纹滤网；纸质、泡沫等型式）→ 汽化器加温箱/进气导管 → 燃油计量装置（汽化器或燃油喷射器）
  - 上吸式：两根进气总管（runner）+ 平衡管 + 每缸进气支管；平衡管消除两侧压力差
  - 下吸式平衡式：在整个工作范围内给各缸更均匀的空气流量，混合比匹配更好
  - 汽化器加温支路：加温空气门（驾驶舱推拉钢索操纵）+ 备用空气门（弹簧常闭、靠吸气打开）
  - 汽化器空气温度表：感温包在汽化器进口侧测进气温度，在发动机侧测混合气温度
- 进气滤与防尘
  - 备用进气口 + 集尘滤：滤芯、门、电动 actuator；空气经不对正气流的百叶窗进入，靠惯性分离尘土
  - 弹簧加载滤门：滤芯堵塞时自动打开，防止进气中断
  - 防冰网（ice guard）：粗目网，结冰后含水少的空气绕网进入滤芯
- 增压系统
  - 内部驱动增压器：机械传动、位于汽化器之后压缩混合气；分配叶轮直接装在曲轴后端同速转动，只打碎油珠不显著增压；增压叶轮经齿轮组增速驱动
  - 外部驱动（涡轮增压器）：压气机组件（叶轮 impeller + 扩压器 diffuser + 机匣）+ 涡轮叶轮组件 + 全浮式轴轴承组件；转子 = 叶轮 + 涡轮轴；中间有隔热/导冷挡板（baffle）或冷却罩
  - 控制链：滑油 → 控制器（放油量）→ 废气门作动筒活塞 → 连杆 → 废气门蝶阀 → 进涡轮废气量 → 转速 → 增压腔压力
  - 滑油路：滑油冷却器后部 → 供油软管 → 增压器中心机匣与轴承 → 回油软管 → 发动机后部回油泵；供油路单向活门防止停车时滑油漏入增压器；压气机轴上的活塞环式油封防止滑油窜入涡轮/压气机机匣
  - 控制器族：密度控制器（充干氮波纹盒，全油门限压）、压差控制器（节气门前后压差，抑自举）、绝对压力控制器（仅最大输出）、VAPC（凸轮随油门改变给定）、斜率控制器（全油门额定、部分油门降压）
  - 中冷器：位于压气机级与节气门之间
- 涡轮发动机进气段
  - 进气导管（多属机体件）+ IGV；导管作扩压器（渐扩、降速增压）
  - 形式：单进口、分开式（翼根/机身侧斗，可加转向叶片）、可变几何（斜板/楔块、气流旁通、激波）
  - 防护：压气机进口滤网（可收放）、喇叭口进气（试车台/直升机，带总压总温探针）
  - 涡桨/涡轴：ducted 布置最佳；进气道唇口电加热防冰、偏转门挡冰挡脏、锥形整流罩
  - 涡扇：风扇与低压压气机一体；唇口内用热引气防冰；风扇叶尖处有可磨涂层；进气道内贴吸音材料
- 活塞发动机排气系统
  - 短排气管（开式）：每缸短管 + 固定卡箍，拆装只动压紧螺母与卡箍
  - 集合器：每缸下排管（高温锁紧螺母）→ 两侧集合管（环形卡箍）→ 排气引射器（防火墙后下方）；集合管外有座舱加温热交换套
  - 星形机集合环：7 段焊接件，螺栓固定于增压器段支架，靠短管套接支撑；排气管用套筒式膨胀接头连接
  - 引射器（augmentor）：文氏效应抽吸舱内冷却空气；尾管内装电动 actuated 的引射叶片
- 涡轮发动机排气段
  - 喷管：收敛喷管（含排气堵锥形成初始扩张段）、C-D 喷管；涡轴用扩张喷管（不产生推力）
  - 反推：机械阻挡式（倒锥/半球/蛤壳门）与气动阻挡式（平移罩 + 阻挡门 + 叶栅）；作动源为气动或液压，经齿轮箱、软轴、螺旋作动筒、控制活门、气马达/液压马达
  - 加力：火焰稳定器、燃油总管、火焰保持器、点火器、可变面积喷管 + 隔热衬套
  - 消音：波纹周边式/多管式消音器 + 短舱内多孔蒙皮/蜂窝吸音衬里（声能转热）
  - 排放：TAPS 双环预混旋流燃烧室（压气机高压空气经两个高能旋流器预混）

## 6. 检查与维修要点

- 进气系统：每次定期检查都查裂纹与漏气、各件安装牢固性；保持清洁（抹布、纸片进入进气道会限流；松脱螺栓螺母进入发动机会造成严重损伤）。
- 汽化器空气滤：脏污或油膜不足即拆下清洗；干燥后浸入滑油与防锈剂的混合液，装回前让多余液体滴净；纸质滤芯视情更换；滤芯过脏会导致功率损失甚至不能起动。
- 起动防火：起动全过程须有防火员持 CO₂ 灭火器守候，且必须熟悉该机进气系统，以便把 CO₂ 打入进气道；起动中着火应继续摇转把火吹灭，若起动不成功且火继续燃烧则停止起动，由防火员灭火。排气系统也可能因缸内液体燃油被点燃后排出而起火。
- 排气系统（活塞机）：
  - 严禁在排气系统上使用镀锌或镀锌工具，严禁用铅笔在排气件上做记号——铅、锌在高温下被金属吸收，改变组织、使局部软化而开裂。
  - 装好全部排气件与整流罩后先试车到正常工作温度，停车拆罩，检查每个卡箍连接与每个排气口有无漏气；漏气表现为管子上平坦的灰色或烟黑色条痕，多因两件对合不正；松开卡箍重新对位。
  - 按规定扭矩拧紧；若到规定扭矩仍松动，说明螺栓螺母已被拉长，应更换；拧紧后所有螺母打保险。
  - 陶瓷涂层排气管只能用除油清洗，禁止喷砂或碱液清洗；喷砂表面的可按工艺清理。
  - 检查外表面裂纹、凹坑、缺件，覆盖焊缝、卡箍、支架、支架凸耳、撑杆、滑动接头、法兰、垫片、柔性接头；每个弯头与焊缝邻近区域都要查；凹坑与低点查内腐蚀减薄与点蚀，可用冰锥状尖具探试。
  - 视需拆开检查内部挡板与扩压件；不可直视处拆下做 2 psi 水浸漏气试验；日常检查看外露部分的裂纹、起皮、过量泄漏与卡箍松动。
  - 修复原则：排气短管、消音器、尾管等一般以新件或翻修件更换代替修理；必须焊修时保持原轮廓、不得使系统对正变形；内部凸出的焊瘤不可接受（局部热点并限流）；必须用规定的高温黄铜/专用锁紧螺母与卡箍，不得用钢制或低温自锁螺母代替；旧垫片一律不重用。
- 涡轮增压系统：定期除焦（de-coking）；废气门内积碳会使工作不稳，积碳过多可把废气门卡在全关位而造成超增压；涡轮内积碳造成飞行中逐渐掉功率、起飞前 MAP 偏低。
- 引射管：定期检查对正、固定与总体状态；裂纹会让废气进入短舱/机翼/座舱，构成火警与 CO 危害。
- 推力反向器：任何维护时只要人在反推区域，必须机械锁定，禁止其动作；反推展开或收上都不允许影响发动机工作，驾驶舱应有状态指示。
- 排气系统失效后果：任何排气失效都按严重危害对待——一氧化碳中毒、部分或全部功率损失、着火；垫片四周的黑烟灰即垫片失效的标志。

## 7. 高频考点（TECC / 口试风格）

问：进气总管压力是什么、用什么单位？ 答：节气门后进入气缸的空气（混合气）压力，用英寸汞柱 "Hg 表示，是判断发动机功率输出的依据。

问：汽化器结冰有哪三种？ 答：撞击冰 impact ice、燃油蒸发冰 fuel evaporation ice、节气门冰 throttle ice。

问：为什么部分油门容易结节气门冰？ 答：节气门关小使气流通过缝隙的速度极高、局部压力极低、温度随之降到冰点以下，水汽即结冰；滑翔时定距桨风车转动吸气更多，会加重这一现象。

问：汽化器加热为什么不能滥用？ 答：加热使空气膨胀、密度下降，充气重量减少、容积效率下降而掉功率；进气温度过高还会引起爆震甚至发动机失效，起飞与大功率段尤其危险。

问：什么情况下算真正的增压？ 答：进气总管压力被增压到 30 "Hg 以上；只补偿高度压力损失的是归一化（normalizing），不算增压。

问：涡轮增压器三大组件是什么？ 答：压气机组件（叶轮、扩压器、机匣）、涡轮叶轮组件、全浮式轴轴承组件。

问：废气门开度与增压量的关系？ 答：废气门越关，进涡轮的废气越多、转速越高、增压越大；全开时废气几乎全部旁通，几乎不增压。

问：密度控制器与压差控制器分工？ 答：密度控制器只在全油门工作，按进气密度限制临界高度以下的 MAP；压差控制器在除全开外的所有废气门位置工作，感受节气门前后压差放油定位废气门，抑制自举。

问：bootstrapping、overboost、overshoot 有何不同？ 答：自举是废气门全关时功率扰动被放大、MAP 持续漂移，不伤发动机；超增压是 MAP 超过规定限值，会严重损坏发动机；过冲是快速推油门后 MAP 短暂偏离设定，比自举轻，靠慢推油门消除。

问：收敛喷管出口面积为什么不能随意改？ 答：太大浪费推力，太小会把发动机其他部件的气流憋住（choked）；喷管相当于一个孔口，其面积决定燃气的密度与流速，直接影响推力与排气温度。

问：机械阻挡式与气动阻挡式反推的区别？ 答：机械式在排气中放倒锥/半球/蛤壳把燃气直接挡住并偏转，多用于涵道风扇混合排气；气动式只用外涵风扇空气，靠平移罩、阻挡门、叶栅把风扇气流折向前方，多用于未涵道涡扇。

## 8. 易混点

1. **增压器（supercharger）vs 涡轮增压器（turbosupercharger）**：前者是内部机械驱动的压气机，位于汽化器之后压缩混合气；后者是外部排气能量驱动的涡轮带动的压气机，位于燃油计量装置之前只压缩空气。二者都要求 MAP 超过 30 "Hg 才算真正增压。
2. **归一化（normalizing）vs 地面增压（ground boosted）**：归一化只把高度造成的压力损失补回来，MAP 不超过 30 "Hg，且常只在某高度以上工作；地面增压可从海平面起就把 MAP 增到 30 "Hg 以上（约 40 "Hg），临界高度以内保持额定功率。
3. **自举（bootstrapping）vs 超增压（overboost）**：自举是控制环自身造成的 MAP 持续漂移，不损害发动机寿命；超增压是 MAP 超出规定限值，会严重损坏发动机，部分系统用略高于最大增压腔压力设定的卸压活门防止。
4. **收敛喷管 vs 收敛-扩张喷管**：收敛喷管把亚音速燃气加速到喉道处的 Mach 1；C-D 喷管在喉道后再扩张，让燃气在超音速下继续加速，只有在发动机压比高到出口流速会超过 Mach 1 时才有优势。
5. **汽化器加热使混合气变富还是变贫**：原文前面一处写"加热使空气密度下降、混合气变贫（leans）"，后面机理段又写"不结冰时加温且油门不变，混合气会变富（richer）"。按后文机理（空气密度下降而燃油量未减）应为富油，考试按机理答"变富"。

# Ch 06 · Lubrication & Cooling Systems（润滑与冷却系统）

## 1. 一句话

本章讲两件事：滑油如何把摩擦面隔开、带走热量与脏物（油品规格、干槽/湿槽系统、泵、滤、散热器与温控），以及发动机如何把多余热量散掉（气缸散热片与导风板、整流罩鱼鳞板、涡轮二次空气冷却）。

## 2. 本章要点

1. 流体润滑的本质是"把两个面完全隔开"：只要油膜不断，金属间摩擦就被滑油内部的液体摩擦取代，摩擦与磨损降到最低；摩擦分滑动（sliding，滑动轴承）、滚动（rolling，即 antifriction 减摩轴承）、擦抹（wiping，齿轮齿面）三类。
2. 滑油除减摩外还有五个作用：缓冲冲击载荷（曲轴、连杆）、吸热（滑油冷却可占总冷却量的 50%）、密封活塞与缸壁、携脏（靠分散剂 dispersant 把颗粒悬浮住交给滤子）、停机后留油膜防腐蚀——这也是发动机不能长期停放的直接原因。
3. 选油的第一指标是黏度（viscosity，即流动阻力）；商业航空油号（65、80、100、120、140）近似对应赛氏通用黏度计（Saybolt Universal Viscosimeter）测得的秒数，SAE 把油按 130 °F 或 210 °F 的黏度分七档（SAE 10 至 70），SAE 号只表示黏度等级，不表示质量。
4. 活塞机油分三档：直馏矿物油（65/80/100/120，只含极少量倾点抑制剂与抗氧化剂，用于新车或刚翻修机台的磨合期）、无灰分散型油（W80/W100/W120，非金属聚合添加剂，不产生燃烧室灰分沉积）、半合成多级油（SAE W15 W50，兼顾低温起动与高温油膜）。
5. 往复机压力润滑系统分湿槽（wet sump，油存在机匣内）与干槽（dry sump，油存在外部油箱，需回油泵+外部管路+外部油箱）；干槽包含湿槽的全部部件，所以按干槽讲。真正的滑油分配方式只有压力式或压力+泼溅式，泼溅式从不单独使用。
6. 涡轮机因无往复运动、全用减摩轴承，用黏度更低的合成油（MIL-PRF-23699F，210 °F 时约 5–5.5 厘斯，称 type II；MIL-L-7808 为 type I）；合成油的两大优点是高温下不易生成漆膜与焦炭，且挥发损失小，适合高空运行。
7. 滑油温度靠两条路控制：一条是散热器本体的油路切换（温控阀/恒温旁通阀 thermostatic bypass valve，冷油走 bypass jacket，热油走 core），另一条是控制流过散热器的空气量（散热器后百叶窗、排气道风门、浮控恒温器驱动的风门作动筒）；系统另有浪涌保护阀（surge valve）防止冷天回油管憋压炸散热器。
8. 冷却侧：气冷缸靠散热片（fins）加大换热面积、靠气缸导风板（baffle）与折流板（deflector）把空气压到缸壁与缸头、靠整流罩（cowling）形成压力腔；涡轮侧靠压气机早期级引出的二次空气（secondary air / bleed air）冷却涡轮盘、导向叶片、工作叶片与轴承腔，外部再靠风扇空气与分区通风冷却。

## 3. 术语对照（英文 | 中文 | 一句话解释）

| viscosity | 黏度 | 滑油对流动的阻力，冷则稠、热则稀 |
| viscosity index (VI) | 黏度指数 | 表示温度变化对黏度影响大小的数，高 VI 表示黏度随温度变化小 |
| Saybolt Universal Viscosimeter | 赛氏通用黏度计 | 测 60 cm³ 油流经校准孔口所需秒数来标定黏度的仪器 |
| flash point / fire point | 闪点 / 燃点 | 开始放出可燃蒸气闪燃的温度 / 蒸气足以维持燃烧的温度 |
| cloud point / pour point | 浊点 / 倾点 | 蜡开始析出使油发浑的温度 / 油还能流动或倒出的最低温度 |

| straight mineral oil | 直馏矿物油 | 只含极微量倾点抑制剂与抗氧化剂的基础油，用于磨合期 |

| dispersancy | 分散性 | 把颗粒悬浮在油中直到被滤子截住或换油排掉的能力，不是清净分散的"清洗" |
| multigrade oil | 多级油 | 跨黏度等级的油，低温易流动、高温油膜更强 |

| gear-type pump | 齿轮泵 | 两个啮合齿轮在壳内旋转的正排量泵，最常用 |
| gerotor pump | 转子泵（摆线转子泵） | 内星形主动件带外凸齿、外套内凹齿圈偏心啮合的泵 |
| pressure relief valve | 释压阀 | 只在压力超过系统最大限值时开路卸压的真释压阀 |
| pressure regulating valve | 压力调节阀 | 在设定值附近持续调节系统压力，涡轮机多用此型 |
| filter bypass valve | 滤子旁通阀 | 滤芯堵塞或冷油凝结时让未过滤滑油绕过滤芯，宁脏勿断油 |
| check valve | 单向活门 | 只允许单向流动，防止停机后油箱油靠重力渗入机匣 |
| last-chance filter | 末道滤 | 装在喷油嘴前、每个轴承处的细网滤，防止喷嘴被堵 |
| Cuno filter | 库诺滤 | 圆盘+隔片滤芯、靠刮刀清污的滤，现代机少用 |
| spin-on filter | 旋装式滤 | 全流式一次性滤罐，往复机最常用，内含防回流阀与释压阀 |
| surge protection valve | 浪涌保护阀 | 冷天回油管压力过高时把回油直接短路回油箱，保护散热器与软管 |
| thermostatic bypass valve | 温控旁通阀 | 按油温改变流经散热器的油量比例，维持滑油温度 |
| oil cooler bypass jacket | 散热器旁通套 | 内外壳之间的环形通道，冷油不经过芯体直接流回油箱 |
| deaerator / deoiler | 除气器 / 除油器 | 油箱内靠切向进油分离滑油中的空气 / 齿轮箱内靠离心力把油从通气空气中甩出 |
| chip detector | 磁堵 | 装在回油路、油箱、收油池，吸附铁磁性颗粒供检查 |

| FADEC / EICAS | 全权限数字发动机控制 / 发动机指示与机组告警系统 | 滑油压力、温度、滤前后压差等信号经其送驾驶舱显示 |
| cowl flap | 整流罩鱼鳞板 | 改变整流罩后部出口面积，控制流过气缸的空气量 |
| augmentor | 引射器 | 用排气引射抽吸额外冷却空气的管束装置 |
| cylinder baffle / deflector | 气缸导风板 / 折流板 | 挡住并引导冷却空气贴着缸壁与缸头流过 |
| blast tube | 吹风管 | 装在导风板上，把冷却空气射向火花塞弯头与附件 |
| fin area | 散热片面积 | 散热片两侧暴露于空气的总面积，是判废依据 |
| cylinder head temperature (CHT) | 缸头温度 | 用热电偶测最热气缸缸头温度 |
| exhaust gas temperature (EGT) | 排气温度 | 热电偶装在排气口后，用于调混合比 |
| secondary air flow | 二次空气流 | 从压气机前几级引出的冷却空气，冷涡轮盘、叶片与轴承腔 |

## 4. 关键数字与公式

- 滑油冷却可占总发动机冷却量的 **50%**（up to 50 percent）。
- 赛氏黏度计：测 **60 cm³** 油流经校准孔口的秒数；商业航空油号 65、80、100、120、140。
- SAE 把油分 **7 档**（SAE 10 至 70），按 **130 °F 或 210 °F** 的黏度划分；SAE 20W 中的 W 表示冬季用油，与表示无灰分散型的 W 不是一回事。
- 图 6-3 三套编号对照：商业 SAE 号 30、40、50、60、70；商业航空号 65、80、100、120、140；陆海军规格号 1065、1080、1100、1120。
- 比重示例：水约 **8 lb/gal**，比重 **0.9** 的滑油约 **7.2 lb/gal**。
- 起动可占正常发动机磨损的 **80%**（up to 80 percent）；温度低于 **20 °F** 时，无论用哪种油，发动机与滑油箱通常都要预热。
- 封存油应在最初 **25 小时**运行结束时排除。
- 油箱膨胀空间：不小于油箱容量的 **10%** 与 **0.5 加仑**两者中的较大值。
- 滤子止回阀（filter check valve）弹簧预紧：**1–3 psi**（干槽星形机，防止重力供油进入发动机造成液锁）。
- 滑油压力表量程：**0–200 psi** 或 **0–300 psi**。
- 浮控恒温器控制的滑油温度波动不超过约 **5–8 °C**。
- 散热器旁通阀：油温低于 **65 °C（150 °F）** 时打开旁通；约到 **65 °C** 开始关闭；到 **85 °C（185 °F），±2 °C** 完全关闭，全部滑油走芯体。
- 滑油压力释压阀设定范围：约 **35 psi（最低）至 90 psi（最高）**；检查压力时发动机转速约 **1,900–2,300 rpm**。
- 换油间隔：新机/翻修机/换缸后首次 **25 小时**；压力滤网系统的典型换油间隔 **25 小时**（清洗压力滤网+检查收油池滤网）；全流过滤系统典型 **50 小时**（换滤芯+检查吸入滤网）；油系统维护最长间隔 **4 个月**。
- 矿物油转无灰分散油：首次换油前运行不超过 **5 小时**；发现油泥则每 **10 小时**换油，直到滤网干净。
- 涡轮油：**MIL-L-7808** 为 type I；**MIL-PRF-23699F** 为 type II，210 °F 时黏度约 **5–5.5 厘斯（centistokes）**；合成油以 **1 夸脱**密封罐供应。
- 涡轮滤网：不锈钢细网约 **25–35 微米**（1 微米 = 百万分之一米）。
- 涡轮滤子止回阀：需 **4–6 psi** 才打开；滑油单向活门一般需 **2–5 psi** 才允许滑油流向轴承。
- 涡轮油箱通气经可调止回释压阀，设定约 **4 psi** 正压。
- 转子泵排量举例：压力元件 **3.1 gpm**，回油元件 **4.25 gpm**；某型泵共 **4 个元件**（1 供油 + 3 回油），另一些型号 **6 个元件**（1 供油 + 5 回油）。
- 变压力系统：滑油压力可从 **100 psi** 变到 **260 psi 以上**，释压阀约在 **540 psi** 开启。
- 涡轮机调压示例：约在正常额定推力的 **75%** 时，滑油压力应为 **45 psi，±5 psi**。
- 冷却：发动机可浪费燃料能量的 **60–70%**；1 加仑航空汽油的热量足以烧开 **75 加仑**水；约 **1/4** 的热量变成有用功率，其余一半随排气排出、一半被发动机吸收。
- 进入整流罩的冲压空气只占流向短舱总气流的 **15–30%**。
- 气缸散热片判废示例：任一散热片沿根部量完全断掉超过 **12 英寸**，或任一缸头断片总面积超过 **83 平方英寸**，则更换气缸；相邻片断片允许量为两片相邻共 **6 英寸**、三片相邻共 **4 英寸**、四片相邻共 **2 英寸**、五片相邻共 **1 英寸**。
- 涡轮理想油气比 **15:1** 时内部温度会升到 **4,000 °F 以上**；靠大量余气把热段温度压到 **1,500–2,100 °F**。
- 隔热毯各处温度示例：排气气体 **1,000 °F**、排气道 **900 °F**、不锈钢护罩 **350 °F**、冷却空气 **120 °F**。

## 5. 结构 / 系统 / 部件

- 摩擦与润滑原理
  - 滑动摩擦（sliding，滑动轴承）、滚动摩擦（rolling，滚珠/滚柱减摩轴承）、擦抹摩擦（wiping，齿轮齿面，载荷可极大）
  - 油膜作用：隔开金属面、缓冲冲击载荷、吸热、密封、携脏、防腐蚀
- 往复机滑油分类
  - 湿槽（wet sump）：油存机匣内收油池，靠油尺量油，底部有滤网，不适宜倒飞
  - 干槽（dry sump）：滑油箱 + 发动机驱动压力泵 + 回油泵 + 带控制阀的滑油散热器 + 油箱通气管 + 管路 + 压力/温度指示
- 干槽系统主要部件
  - 滑油箱（铝合金；膨胀空间；加油口盖标 OIL；回流管切向排油减少泡沫；底部挡板破涡；集油槽积水垢；立管为变距桨保留熄火后顺桨用油；老星形机有 hopper tank 加速升温）
  - 滑油泵（齿轮式正排量泵；压油侧与回油侧；回油泵容量更大以应对含气泡沫油；转子泵 gerotor：内星形主动件、外套偏心钢板上从动）
  - 滤子（screen 网式多用作吸入滤；Cuno 圆盘式；canister 罐式可换滤芯，波纹钢中心管抗压溃；spin-on 全流旋装式，含防回流阀与释压阀）
  - 压力调节/释压阀（位于泵出口，多余油旁通回泵入口；调压螺钉顺时针升压）
  - 散热器（圆柱或椭圆，芯体为铜管或铝管蜂窝状，铜管锡焊、铝管钎焊或机械连接；内外壳之间为旁通套；芯体内挡板迫使滑油往复流动）
  - 散热器流量控制阀（冷油时波纹盒收缩、阀门抬起，油走旁通套经恒温阀回油箱；热油时波纹盒膨胀关闭旁通出口，油走芯体）
  - 浪涌保护阀（可集成在流量控制阀内，也可为回油管路上的独立件）
  - 空气流量控制（散热器后百叶窗、排气道风门；手动拉杆、电动或浮控恒温器+电动作动筒；双散热器系统还有分流器、Y 形接头、双门作动机构）
  - 通气与指示（油箱通气管接机匣、经机匣呼吸器通大气；压力表、温度表）
- 涡轮机滑油系统
  - 分类：压力调节式（pressure relief，压力基本恒定）、全流式（full flow，压力随转速变）、全损耗式（total loss，靶机/导弹短时使用）
  - 干槽压力调节式：压力子系统 + 回油子系统 + 通气压紧子系统；油箱多装在压气机机匣上
  - 干槽变压力式：无调节阀，泵出口压力与转速成正比，仅设释压阀；另有滑油压力配平节流孔（trim orifice）修低转速压力
  - 湿槽式（涡轮）：附件齿轮箱或机匣底部作油池，含观察窗、通气管、磁性放油塞、温度/压力接头；附件传动齿轮靠泼溅润滑
  - 部件：油箱（万向出口组件+水平挡板+两个翻板单向阀+通气系统）、齿轮/转子泵、主滤与末道滤、压力调节阀或释压阀、滑油喷嘴、磁堵、除气器、除油器、空气-滑油散热器、燃油-滑油散热器（热交换器）
- 冷却系统
  - 往复机：气缸散热片 + 气缸导风板/折流板 + 整流罩与气封 + 吹风管 + 鱼鳞板（cowl flap）/引射器（augmentor）/余热门
  - 液冷柴油机：缸套水腔 + 散热器（radiator）
  - 涡轮机：二次空气冷却燃烧室衬筒、涡轮盘、导向叶片、工作叶片与轴承腔；外部靠风扇空气、分区通风、排气道隔热毯

## 6. 检查与维修要点

- 滑油箱拆装：先放油；地面姿态放不干净时可松开固定带后把油箱后部略微抬起；拆滑油进口管、通气管、集水盘排水软管、搭接线，再拆固定带（拆卡箍前先拆保险丝）；装回按反序，装好后加满油，发动机至少运转 **2 分钟**再查油尺并补油。
- 滑油温度传感器（bulb）：多装在压力滑油滤网壳体上；拆装时先拆保险丝、脱开导线，用专用扳手拆装。
- 压力与回油滤网：按厂家间隔拆下、检查、清洗；接油容器必须干净，否则脏物会造成"发动机有金属"的假象，导致提前拆发动机；重装用新 O 形圈与垫片，按维护手册扭矩拧紧并打保险。
- 油滤/滤网内容物检查：展开滤纸检查夹住的颗粒；压力滤网、收油池吸入滤网查金属屑；旋装式滤罐必须用专用开罐器切开，刀片轻顶滤罐旋转 **360°**，在洁净塑料桶中用 varsol 清洗，先用干净磁铁找黑色金属，再把残液倒过干净滤纸/纸巾，用强光找有色金属；发现异常金属含量需追查来源并做纠正性维修。
- 油滤装配：新橡胶垫涂少量滑油，六角头螺钉配新铜垫；尼龙螺母先手拧；壳体顺时针装回后按规定扭矩拧紧并打保险；旋装式按滤罐上说明，垫圈涂滑油后装、拧紧、打保险。
- 调滑油压力：发动机必须处于正常工作温度且确认用油黏度正确；松锁紧螺母、转调压螺钉（顺时针升压、逆时针降压），在慢车状态下调，每调一次锁紧螺母，再在手册规定转速（约 1,900–2,300 rpm）下读压力；涡轮机调完后换新垫片装回螺帽盖并打保险。
- 换油：先判断污染物（汽油、水分、酸、脏物、炭、金属颗粒）。由直馏矿物油改无灰分散油要按四条预防措施执行：不得把无灰分散油直接加入矿物油（须先放净再加）；首次换油前运行不超过 5 小时；检查所有滤子与滤网有无油泥或堵塞，有油泥则每 10 小时换油直至滤网干净；所有涡轮增压发动机必须用无灰分散油磨合与运行。长期用矿物油且已知很脏的发动机，应翻修后再换油。
- 涡轮机换油滤：准备接油容器；拆滤壳取出滤芯，废弃旧封圈；把滤网/滤芯浸入室温认可的除碳剂数分钟，在脱脂液或清洗溶剂中漂洗，再用压缩空气吹干；装回滤壳，换新封圈并按手册扭矩拧紧，打保险丝。
- 涡轮机维护：定期检查回油与通气系统的渗漏与固定；检查磁堵有无铁磁性颗粒，清洗末道滤后装回并打保险；涡轮机滑油必须在停车后立即检查（hot shutdown check）。
- 磁堵：拆下检查，无金属则清洗、装回、打保险；有金属则追查来源。
- 冷却系统维护：整流罩分块可拆，检查蒙皮划伤、凹坑、撕裂（削弱结构、增大阻力、诱生腐蚀）；检查锁扣铆钉、提手；检查加强筋裂纹与气封损坏；检查鱼鳞板铰链及其搭接（bonding）；气封（橡胶件）必须压在缸头导风系统上才能迫使空气绕缸流过。
- 散热片检查：每次定期检查；小裂纹不必拆缸，可填补或止裂孔（stop-drill）；尖锐棱角可锉平；改形前查厂家服务/翻修手册的允许极限；按前述 12 英寸/83 平方英寸与相邻片断片长度判废。
- 导风板与折流板：定期检查，拆整流罩时必查；查裂纹、凹坑、固定柱松动；刚开始的裂纹可止裂，凹坑可校平，严重者更换。
- 缸温与排温系统：CHT 由指示器、导线、热电偶组成；热电偶两种异金属通常为 constantan 与 iron。卡口式（bayonet）安装：压下滚花螺母顺时针拧到贴合；拆卸时压下逆时针转。垫圈式（gasket）装在火花塞下方代替原垫圈。热电偶引线过长不得剪短，只能盘绕绑扎——长度决定电阻，剪短会导致温度读数错误。热电偶装在做气缸分组试验（block test）确定的最热气缸上。发动机未运转且处于环境温度时，CHT 指示应接近外界自由空气温度，这是判断仪表正常的办法之一。指针摆动时检查所有电气连接。EGT 热电偶装在排气口后的排气流中，用来调混合比从而控制与监视发动机温度。
- 通风系统：附件机匣通气管是带滤网的通口，位于附件机匣前部中央，防止非正常姿态漏油；堵塞会造成机匣憋压，把滑油从轴承油封挤进压气机，严重时引起燃烧与油封/轴承故障。

## 7. 高频考点（TECC / 口试风格）

问：滑油的最主要作用是什么？ 答：降低运动件之间的摩擦——用油膜把两个面完全隔开，把金属摩擦变成滑油内部的液体摩擦。

问：湿槽与干槽最本质的区别？ 答：滑油存在哪里。湿槽存在发动机内部以机匣为油池；干槽用回油泵把油抽到外部油箱，因此多出回油泵、外部管路与外部油箱。

问：为什么回油泵容量比压力泵大？ 答：因为回油是滑油与空气混合的泡沫油，体积已经膨胀，必须更快抽走，否则油会积在轴承收油池里。

问：滤子旁通阀打开意味着什么？ 答：滤芯堵塞或冷天滑油凝结，未过滤的滑油直接进入发动机——过滤作用丧失，但避免了轴承完全断油；涡轮机还有机械指示销弹出来提示处于旁通状态。

问：散热器流量控制阀怎么工作？ 答：靠感受油温的波纹盒。冷油时波纹盒收缩、抬起阀门，油走旁通套直接回油箱并加快升温；油温升高后波纹盒膨胀，关闭旁通出口，迫使全部滑油经芯体冷却。无论走哪条路，滑油都要流过恒温阀的波纹盒。

问：浪涌保护阀保护什么？ 答：保护散热器与软管。冷天滑油凝结时回油泵会在回油管建立很高压力，浪涌阀被顶起、同时把 poppet valve 压回阀座，回油不经散热器直接回油箱；压力降回安全值后弹簧复位。

问：滑油压力表为什么带一个节流孔？ 答：防止油泵的脉动压力冲击波登管，使指针剧烈摆动或损坏仪表。

问：干槽与湿槽的滑油温度传感器各装在哪？ 答：干槽装在供油箱到发动机之间的进油管路上任一点；湿槽装在滑油经过散热器之后。两者都要求测到进入发动机热区之前的油温。

问：磁堵与光谱分析各查什么？ 答：磁堵只能吸附铁磁性颗粒，属现场目视检查；光谱油液分析（SOAP）按 PPM 重量测油中各种金属元素与添加剂，能发现早期磨损趋势并覆盖有色/非铁金属，涡喷与往复机都可用。

问：涡轮机为什么必须设末道滤（last-chance filter）？ 答：滑油喷嘴孔径极小、极易堵，喷嘴只有维修时才能接近清洗，一旦堵塞通常直接导致轴承失效，所以在喷嘴前每个轴承处再设一道细网滤；主滤也要勤查污染。

问：涡轮机排气涡轮轴承为什么是最关键的润滑点？ 答：那里温度最高。除滑油冷却外，有些发动机还用压气机引出的二次空气辅助冷却轴承与涡轮件。

问：涡轮机气缸/热段是怎么被冷却的？ 答：燃烧连续进行，几乎全部冷却空气都要从发动机内部通过。除维持 15:1 理想油气比所需的空气外，要额外送入大量空气，把热段温度压到 1,500–2,100 °F；二次空气还在衬筒内外表面形成薄而快的气膜，并在燃烧室后与燃气掺混降温。

问：为什么发动机不能长期停放？ 答：停机后留在零件表面的油膜会流失，失去防腐蚀保护，零件开始生锈腐蚀。

## 8. 易混点

1. **释压阀（relief valve）与压力调节阀（pressure regulating valve）**：调节阀在设定值附近连续工作，把系统压力维持在范围内；释压阀只在压力超过系统最大限值时才开，正常使用中根本不应打开（大型涡扇变压力系统就是只有释压阀、没有调节阀）。
2. **SAE 号里的 W 与油号前的 W**：SAE 20W 的 W 表示冬季（winter）适用；W80、W100、W120 前面的 W 表示该油是无灰分散型（ashless dispersant）。书中明确提醒两者不要混淆。
3. **分散性（dispersancy）与清净性（detergency）**：无灰分散剂的分散性只是把颗粒悬浮住交给滤子或换油排掉，它不是清净剂，不会把已经形成的沉积物从发动机内部洗下来。
4. **干槽与湿槽的"油在哪" vs 涡轮机的"压力怎么定"**：前者按储油位置分类（wet/dry sump），后者按压力控制方式分类（压力调节式/全流式/全损耗式），两套分类互不替代，一个系统可以同时是"干槽 + 变压力"。
5. **二次空气（secondary air / bleed air）与冲压/风扇冷却空气**：二次空气是从压气机前几级引出的内部空气，冷的是涡轮盘、导向叶片、工作叶片与轴承腔；风扇空气与冲压空气冷的是发动机外部、短舱与附件区（Zone 1/2/3 通风）。
6. **鱼鳞板（cowl flap）与引射器（augmentor）**：都是增加冷却空气流量，但鱼鳞板靠改变整流罩出口面积（会带来阻力），引射器靠排气速度抽吸（不依赖螺旋桨滑流，还能提供座舱加热与防冰用热空气）。

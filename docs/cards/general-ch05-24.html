1. 原文

A single pulley can be used to magnify the force exerted. In Figure 5-11, the pulley is movable, and both ropes extending up from the pulley are sharing in the support of the weight.

This single, movable pulley will act like a second class lever.

The effort arm (EF) being the diameter of this pulley and the resistance arm (FR) being the radius of this pulley. This type of pulley would have a mechanical advantage of two because the diameter of the pulley is double the radius of the pulley. In use, if someone pulled in 4 ft of the effort rope, the weight would only rise off the floor 2 ft. If the weight was 100 lb, the effort concept of work. If it allows you to lift 5 times more weight, you will only move it 1⁄5 as far as you move the effort, because a lever cannot have more work output than input.

4. 语法解析

① 情态被动 can be used + 过去分词作定语

原句：A single pulley can be used to magnify the force exerted.

拆解：主语 A single pulley；谓语 can be used（情态动词 + be + 过去分词）；to magnify the force exerted 为不定式作目的状语，其中 exerted 是过去分词单独后置修饰 the force（= the force which is exerted）。

要点：can be used to do 译「可用来做……」，是手册说明用途的固定句式。the force exerted 与 the applied force 同义，都指「所施加的力」；过去分词单独后置是压缩定语从句的常用手段。不要把 exerted 误当成谓语。

② 与现在事实相反的虚拟条件句

原句：if someone pulled in 4 ft of the effort rope, the weight would only rise off the floor 2 ft.

拆解：条件从句用一般过去时 pulled；主句用 would + 动词原形 rise，构成与现在（或将来）事实相反的虚拟语气；in 4 ft 与 2 ft 都是数量状语，说明位移量。

要点：手册举假设例子时常用虚拟（pulled / would rise），并非过去发生的事，翻译要加「若……（就）……」。rise 是不及物动词，不能用于被动；「提升某物」要用 raise。注意 only 强调「仅」，突出位移被牺牲。

③ 倍数结构与等比结构

原句：If it allows you to lift 5 times more weight, you will only move it 1⁄5 as far as you move the effort, because a lever cannot have more work output than input.

拆解：if 引导真实条件句；5 times more weight 为「倍数 + 比较级」结构；1/5 as far as 为「分数 + as … as」等比结构；because 引导原因状语从句，其中 more … than 构成比较（more work output than input）。

要点：times more 与 as … as 是两套倍数表达，中文都落在「倍」，但基准不同：5 times more 表示是原来的五倍（多四倍），1/5 as far as 表示行程只有施力端的五分之一。because 从句点出本质：省力必费距离，输出功不能大于输入功。可迁移：three times as long as（是……的三倍长）。

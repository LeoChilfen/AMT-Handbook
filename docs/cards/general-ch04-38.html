Outline or Visible Lines

通用 Ch 04 · Outline or Visible Lines · 原文 PDF 第 142 页

1. 原文

The outline or visible line is used for all lines on the drawing representing visible lines on the object. This is a medium-to- wide line that represents edges and surfaces that can be seen when the object is viewed directly.

2. 中文翻译

轮廓线（可见线）用于图纸上所有表示物体可见棱线的线条。它是一种中等宽度到宽的线，用来表示直接观察物体时能够看到的棱边与表面。

3. 专业词汇

英文 词性 中文 本节语境
outline line n. phr. 轮廓线 与 visible line 同义，本节标题即并列二者
visible line n. phr. 可见线 表示物体上直接可见的棱线
medium-to-wide adj. 中等至宽的 说明该线型的线宽介于中粗与粗之间
edge n. 棱边、边缘 两个面的交线，图中以轮廓线表示
surface n. 表面 可直接看到的平面或曲面
viewed directly phr. 直接观察 不加剖切、不借助其他视图地观看物体
represent v. 表示、代表 图上线条与物体实际轮廓的对应关系

4. 语法解析

① representing visible lines on the object（现在分词短语作后置定语）

原句：The outline or visible line is used for all lines on the drawing representing visible lines on the object.

拆解：主语 The outline or visible line（两名词用 or 并列，指同一线型），谓语 is used for（被动 + for 引出用途）；宾语 all lines on the drawing，其后 representing visible lines on the object 是现在分词短语作后置定语，逻辑主语是 all lines。

要点：现在分词短语作定语时与被修饰名词是主动关系（线条「表示」可见棱线），故用 -ing 而非 -ed。on the drawing 与 on the object 两个 on 短语一前一后，分别限定 lines 和 visible lines，读时不要混作一个整体。

② This is a medium-to-wide line that represents edges and surfaces that can be seen …（双层定语从句）

原句：This is a medium-to-wide line that represents edges and surfaces that can be seen when the object is viewed directly.

拆解：主干 This is a medium-to-wide line；第一层定语从句 that represents edges and surfaces 修饰 line；第二层定语从句 that can be seen when the object is viewed directly 修饰 edges and surfaces；when 从句是时间状语，内含被动 is viewed。

要点：英语允许定语从句套定语从句，中文则习惯拆成短句或转成「……的」前置定语。此处译作「它表示直接观察物体时能看到的棱边与表面」，把第二层从句前置处理。medium-to-wide 是「形容词 + to + 形容词」的复合定语，同类还有 small-to-medium、low-to-medium。

③ is used for all lines（be used for + 名词）

原句：The outline or visible line is used for all lines on the drawing representing visible lines on the object.

拆解：is used for 后接名词短语 all lines on the drawing，表示用途或适用范围，而不是 be used to do（后接动词）。

要点：be used for + 名词（用于某类对象）／be used to do（被用来做某事）／be used as + 名词（被用作某物）三者分工明确，考试与实修中都常被混淆。本句 for 后接的是「所有线条」，属对象而非动作，故只能用 for。

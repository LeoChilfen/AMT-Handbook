1. 原文

Algebra is the branch of mathematics that uses letters or symbols to represent variables in formulas and equations.

For example, in the equation d = v × t, where distance = velocity × time, the variables are: d, v, and t.

Equations

Algebraic equations are frequently used in aviation to show the relationship between two or more variables. Equations normally have an equals sign (=) in the expression.

Example: The formula A = π × r^2 shows the relationship between the area of a circle (A) and the length of the radius (r) of the circle. The area of a circle is equal to π (3.1416) times the radius squared. The larger the radius, the larger the area of the circle.

Algebraic Rules

When solving for a variable in an equation, you can add, subtract, multiply, or divide the terms in the equation (you do the same to both sides of the equals sign) to get the variable onto one side of the equals sign.

Examples: Solve the following equations for the value N.

3N = 21

To solve for N, divide both sides by 3.

3N ÷ 3 = 21 ÷ 3

N = 7

N + 17 = 59

To solve for N, subtract 17 from both sides. N + 17 – 17 = 59 – 17

N = 42

N – 22 = 100

To solve for N, add 22 to both sides.

N – 22 + 22 = 100 + 22

N = 122

N/5 = 50

To solve for N, multiply both sides by 5.

N × 5 = 50 × 5

N = 250

Solving for a Variable

Another application of algebra is to solve an equation for a given variable.

Use of Parentheses

In algebraic equations, parentheses are used to group numbers or symbols together. The use of parentheses helps us to identify the order in which we should apply mathematical operations. The operations inside the parentheses are always performed first in algebraic equations.

Example: Solve the algebraic equation X = (4 + 3)^2. First, perform the operation inside the parentheses, which is, 4 + 3 = 7. Then complete the exponent calculation X = (7)^2 = 7 × 7 = 49.

When using more complex equations, which may combine several terms and use multiple operations, grouping the terms together helps organize the equation. Parentheses, ( ), are most commonly used in grouping, but you may also see brackets, [ ]. When a term or expression is inside one of these grouping symbols, it means that any operation indicated to be done on the group is done to the entire term or expression.

Example: Solve the equation N = 2 × [(9 ÷ 3) + (4 + 3)^2]. Start with the operations inside the parentheses ( ), then perform the operations inside the brackets [ ].

N = 2 × [(9 ÷ 3) + (4 + 3)^2]

N = 2 × [3 + (7)^2]

First, complete the operations inside the parentheses ( ).

N = 2 × [3 + 49]

N = 2 × [52]

Second, complete the operations inside the brackets [ ].

N = 104

Order of Operation

In algebra, rules have been set for the order in which operations are evaluated. These same universally accepted rules are also used when programming algebraic equations in calculators. When solving the following equation, the order of operation is given below:

N = (62 – 54)^2 + 6^2 – 4 + 3 × [8 + (10 ÷ 2)] + √25 + (42 × 2) ÷ 4 + 3⁄4

  1. Parentheses. First you must do everything in parentheses, ( ), starting from the innermost parentheses. If the expression has a set of brackets, [ ], treat these exactly like parentheses. If you are working with a fraction, treat the top as if it was in parentheses and the denominator as if it were in parentheses, even if there is none shown. From the equation above, completing the calculation in parentheses gives the following:

N = (8)^2 + 6^2 – 4 + 3 × [8 + (5)] + √25 + (84) ÷ 4 + 3⁄4, then N = (8)^2 + 6^2 – 4 + 3 × [13] + 25 + 84 ÷ 4 + 3⁄4

  1. Exponents. Next, clear any exponents. Treat any roots (square roots, cube roots, and so forth) as exponents. Completing the exponents and roots in the equation gives the following:

N = 64 + 36 – 4 + 3 × 13 + 5 + 84 ÷ 4 + 3⁄4

  1. Multiplication and Division. Evaluate all of the multiplications and divisions from left to right. Multiply and divide from left to right in one step. A common error is to use two steps for this (that is, to clear all of the multiplication signs and then clear all of the division signs), but that is not the correct method. Treat fractions as division. Completing the multiplication and division in the equation gives the following:

N = 64 + 36 – 4 + 39 + 5 + 21 + 3⁄4

  1. Addition and Subtraction. Evaluate the additions and subtractions from left to right. Like above, addition and subtraction are computed left to right in one step. Completing the addition and subtraction in the equation gives the following:

X = 161 3⁄4

A commonly used acronym, PEMDAS, is used for remembering the order of operation in algebra. PEMDAS is an acronym for parentheses, exponents, multiplication, division, addition, and subtraction. To remember it, many use the sentence, “Please Excuse My Dear Aunt Sally.” Always remember, however, to multiply/divide or add/subtract in one sweep from left to right, not separately.

  1. Multiplication
  1. Division
  1. Addition
  1. Subtraction

2. 中文翻译

代数是数学的一个分支，它用字母或符号在公式和等式中表示变量。

例如，在等式 d = v × t 中（其中 distance 表示距离、velocity 表示速度、time 表示时间），变量是 d、v 和 t。

等式

代数等式在航空领域常用于表示两个或多个变量之间的关系。等式通常含有等号（=）。

例：公式 A = π × r2 表示圆的面积（A）与该圆半径长度（r）之间的关系（原文 r 上的平方指数在抽文中丢失，r2 即 r²）。圆的面积等于 π（3.1416） 乘以半径的平方。半径越大，圆的面积越大。

代数法则

要求在等式中解出某个变量时，可以对等式中的各项做加、减、乘、除（即对等号两边做同样的运算），把该变量移到等号的一边。

例：解下列方程，求 N 的值。

3N = 21。

为求 N，两边同除以 3：

3N ÷ 3 = 21 ÷ 3，

N = 7。

N + 17 = 59。

为求 N，两边同减 17：N + 17 – 17 = 59 – 17，

N = 42。

N – 22 = 100。

为求 N，两边同加 22：

N – 22 + 22 = 100 + 22，

N = 122。

N 5 = 50（原文此处为分数 N⁄5，分数线在抽文中丢失）。

为求 N，两边同乘 5：

N × 5 = 50 × 5，

N = 250。

解出某个变量

代数的另一项应用是对给定变量解方程。 例：用给出的公式求串联电路的总电容（CT），该电路含三个电容器：C1 = 0.1 微法，C2 = 0.015 微法，C3 = 0.05 微法。先把已知值代入公式： （原文此处为换算表与公式的排版碎片，原文无完整句子）因此，CT = 1⁄96.66 = 0.01034 微法。微法（10-6 法拉）是电容的计量单位，在第 12 章“电学”中会有更详细的讨论。

括号的用法

在代数等式中，圆括号用于把数字或符号归成一组。使用圆括号有助于确定运算的先后次序。在代数等式中，括号内的运算总是最先进行。

例：解代数等式 X = (4 + 3) 2（原文此处括号外的 2 为上标，即求平方，下同）。先做括号内的运算，即 4 + 3 = 7，然后完成指数运算：X = (7)2 = 7 × 7 = 49。

使用较复杂的等式时（这类等式可能合并若干项并含多种运算），把各项分组有助于理清等式的结构。分组最常用的是圆括号 ( )，但也可能见到方括号 [ ]。当某一项或表达式处在这样的分组符号内时，意思是对该组所示的任何运算都要作用于整个项或整个表达式。

例：解等式 N = 2 × [(9 ÷ 3) + (4 + 3) 2]。

先做圆括号 ( ) 内的运算，再做方括号 [ ] 内的运算：

N = 2 × [(9 ÷ 3) + (4 + 3)2]，N = 2 × [3 + (7)2]。

首先完成圆括号 ( ) 内的运算：

N = 2 × [3 + 49]，

N = 2 × [52]；

其次完成方括号 [ ] 内的运算：

N = 104。

运算顺序

在代数中，运算的先后次序是有规定的。这套公认的规则在把代数等式编入计算器时同样适用。解下面这个等式时，运算顺序如下：

N = (62 – 54)2 + 62 – 4 + 3 × [8 + (10 ÷ 2)] + 25 + (42 × 2) ÷ 4 + 3⁄4。

  1. 括号。首先必须完成圆括号 ( ) 内的所有运算，从最内层的括号做起。若表达式中有方括号 [ ]，把它完全按括号处理。若遇到分数，把分子当作处在括号内、分母也当作处在括号内，即使没有写出括号。对上式完成括号内的计算后得：

N = (8)2 + 62 – 4 + 3 × [8 + (5)] + 25 + (84) ÷ 4 + 3⁄4，然后 N = (8)2 + 62 – 4 + 3 × [13] + 25 + 84 ÷ 4 + 3⁄4。

  1. 指数。接着算出所有的指数。任何根（平方根、立方根等）都按指数处理。完成式中指数与根的计算后得：

N = 64 + 36 – 4 + 3 × 13 + 5 + 84 ÷ 4 + 3⁄4。

  1. 乘法和除法。从左到右依次算出所有的乘法和除法。乘除要在一步中从左到右完成。常见的错误是把这一步分成两步（即先把所有乘号算完，再算所有除号），那不是正确的方法。分数按除法处理。完成式中的乘除后得：

N = 64 + 36 – 4 + 39 + 5 + 21 + 3⁄4。

  1. 加法和减法。从左到右依次算出所有的加法和减法。与上面一样，加减要在一步中从左到右完成。完成式中的加减后得：

X = 161 3⁄4。

PEMDAS 是常用的首字母缩写，用来记住代数中的运算顺序。PEMDAS 分别是括号、指数、乘法、除法、加法、减法六个英文词的首字母。为便于记忆，许多人用“Please Excuse My Dear Aunt Sally”这句话。但始终要记住：乘除或加减都要从左到右一次做完，不能分开做。

4. 语法解析

① 限制性定语从句 + use sth to do

原句：Algebra is the branch of mathematics that uses letters or symbols to represent variables in formulas and equations. 拆解：主句 Algebra is the branch of mathematics；that 引导限制性定语从句修饰 the branch of mathematics，从句主语 that，谓语 uses，宾语 letters or symbols，to represent variables 为目的不定式，in formulas and equations 为范围状语。 要点：定语从句用 that 还是 which 不影响含义，但先行词被 of 短语修饰时要紧贴先行词放置；represent 在此是“表示”，不译作“代表某人”。

② where 引导非限制性定语从句

原句：For example, in the equation d = v × t, where distance = velocity × time, the variables are: d, v, and t. 拆解：For example 为插入性状语；in the equation d = v × t 为地点状语；where 引导非限制性定语从句，先行词是 the equation，where 相当于 in which；主句真正的主谓是 the variables are，冒号后列举三个变量。 要点：先行词是“式子、场合、情况”这类抽象地点时用 where，不用 which；非限制性从句前后都要有逗号，且不能用 that 替换 where。

③ the + 比较级, the + 比较级

原句：The larger the radius, the larger the area of the circle. 拆解：前一分句 The larger the radius 省略了系动词 is，意为“半径越大”；后一分句 the larger the area of the circle 同样省略 is，意为“圆的面积就越大”。 要点：这种“越……越……”结构两个分句都必须以 the + 比较级开头，顺序不能颠倒；省略的 be 动词在书面语中通常不补出，翻译时补“就”。

④ When + 动名词的时间状语 + 括号插入

原句：When solving for a variable in an equation, you can add, subtract, multiply, or divide the terms in the equation (you do the same to both sides of the equals sign) to get the variable onto one side of the equals sign. 拆解：When solving … 是状语从句的省略形式，逻辑主语与主句主语 you 一致，故用现在分词；主句谓语为 can add, subtract, multiply, or divide 四个并列动词；圆括号内是一个完整小句作补充说明；to get the variable onto one side 为目的不定式。 要点：状语从句主语与主句一致且含 be 动词时才可省略成 When doing；solve for 是“解出（某变量）”的固定搭配，不能写成 solve to。

⑤ 不定式作表语 + solve … for …

原句：Another application of algebra is to solve an equation for a given variable. 拆解：主语 Another application of algebra；系动词 is；表语为不定式 to solve an equation for a given variable，其中 for a given variable 表示求解的对象，given 为过去分词作定语修饰 variable。 要点：主语是“用途、目的”类名词时，表语常用不定式；solve an equation for N 意为“解方程求 N”，介词 for 引出待求量，不能省略。

⑥ 状语从句 + that 宾语从句 + 过去分词短语作后置定语

原句：When a term or expression is inside one of these grouping symbols, it means that any operation indicated to be done on the group is done to the entire term or expression. 拆解：When a term or expression is inside one of these grouping symbols 为时间状语从句，交代前提；主句 it means that … 中 it 指代前面刚说的情形，that 引导宾语从句；宾语从句的主语是 any operation，indicated to be done on the group 是过去分词短语作后置定语修饰 any operation（相当于 which is indicated to be done on the group），谓语是 is done（被动语态），to the entire term or expression 为对象状语。 要点：单个分词作定语要前置（a given formula），带补足成分的过去分词短语必须后置（any operation indicated to be done）；后置定语相当于省略了“which is/are”的定语从句，因此不能再补 which；这里 indicated 与 is done 都是被动，翻译要按“被指示/被施行”处理，不能改成主动；that 宾语从句里主语和谓语之间可以隔一个长定语，但 is done 的位置不能提前。

Uniform Motion

通用 Ch 05 · Uniform Motion · 原文 PDF 第 164 页

1. 原文

Motion may be defined as a continuing change of position or place, or as the process in which a body undergoes displacement. When an object is at different points in space at different times, that object is said to be in motion, and if the distance the object moves remains the same for a given period of time, the motion may be described as uniform. Thus, an object in uniform motion always has a constant speed.

2. 中文翻译

运动可定义为位置或地点的持续变化，也可定义为物体发生位移的过程。当物体在不同时刻处于空间中的不同位置时，就说该物体处于运动状态；如果物体移动的距离在给定的时间段内保持不变，这种运动就可描述为匀速运动。因此，做匀速运动的物体总是具有恒定的速率。

4. 语法解析

① may be defined as … or as the process in which …（情态被动 + define as 并列）

原句：Motion may be defined as a continuing change of position or place, or as the process in which a body undergoes displacement.

拆解：主语 Motion；谓语 may be defined as（情态动词 + be + 过去分词）；后接两个并列的 as 短语，第二个 as 前省略了 may be defined；the process 后带 in which 定语从句。

要点：define A as B 意为「把 A 定义为 B」。or 后的并列成分要按前文补全谓语。in which = in the process，介词不能丢，也不能换成 that。

② that object is said to be in motion（be said to be + 省略关系代词）

原句：When an object is at different points in space at different times, that object is said to be in motion, and if the distance the object moves remains the same for a given period of time, the motion may be described as uniform.

拆解：When 引导时间状语从句；主句 that object is said to be in motion；and 连接并列分句，if 条件从句中 the distance (that) the object moves 省略了关系代词，remains the same 为系表结构；主句 the motion may be described as uniform。

要点：be said to be in motion 意为「被称为处于运动状态」。the distance the object moves 中省略了 that，因为 that 在从句中作 moves 的宾语。remain 是系动词，后接 the same；describe A as B 用 as。

③ Thus, an object in uniform motion always has a constant speed（连接副词 + 介词短语作定语）

原句：Thus, an object in uniform motion always has a constant speed.

拆解：Thus 为连接副词作状语；主语 an object，in uniform motion 为介词短语作后置定语；谓语 has；宾语 a constant speed。

要点：in motion / in uniform motion 是固定介词短语，不能用 on。thus 引出结论，后面常用一般现在时陈述规律。constant 与 uniform 在此互相呼应：匀速就是速率不变。

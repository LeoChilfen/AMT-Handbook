Expressing a Decimal Number as a Percentage

通用 Ch 03 · Expressing a Decimal Number as a Percentage · 原文 PDF 第 106 页

1. 原文

To express a decimal number in percent, move the decimal point two places to the right (adding zeroes if necessary) and then affix the percent symbol.

Example: Express the following decimal numbers as a percent:

0.90 = 90% 0.5 = 50% 1.25 = 125% 0.335 = 33.5%

2. 中文翻译

要把小数表示为百分数，把小数点向右移两位（必要时补零），然后加上百分号。

例：把下列小数表示为百分数：

0.90 = 90% 0.5 = 50% 1.25 = 125% 0.335 = 33.5%

4. 语法解析

① 目的不定式 + 两个并列祈使谓语

原句：To express a decimal number in percent, move the decimal point two places to the right (adding zeroes if necessary) and then affix the percent symbol.

拆解：To express a decimal number in percent 是目的状语置于句首；主句为祈使句，两个并列谓语 move … 与 affix …，由 and then 连接表示先后；two places to the right 是「数量 + 方向」状语，说明移动幅度；括号内 adding zeroes if necessary 是分词短语作补充说明。

要点：手册的操作步骤一律用祈使句，读者自然理解为「你应当」。express A in percent（或 as a percent）是固定搭配，介词不能用 to。移位方向落成 two places to the right，中文说「向右移两位」，语序相反，翻译时按中文习惯调整，「数量 + to the + 方向」的结构要整体理解。

② express A as B：把……表示为……

原句：Example: Express the following decimal numbers as a percent:

拆解：Example: 是提示语，冒号后接祈使句；Express 是谓语动词，宾语 the following decimal numbers，as a percent 是介词短语作宾语补足语，说明结果形式；句末冒号引出下面的算式列表。

要点：express/state/give/write + 宾语 + as + 名词，表示「以……形式表示」，as 不能换成 to 或 in（in percent 可以，但 as a percent 更强调结果形态）。the following + 复数名词 是手册引出示例的固定说法，后面必须跟冒号与具体数据，冒号前不用句号。

③ 分词短语 + if necessary 的省略

原句：adding zeroes if necessary

拆解：adding zeroes 是现在分词短语，逻辑主语与主句祈使句的隐含主语 you 一致，作补充说明（相当于 by adding zeroes 或 you may add zeroes）；if necessary 是 if it is necessary 的省略形式，省略了主语与 be 动词。

要点：if necessary / when necessary / if possible 是技术文本的三件套省略结构，一律省掉 it is，不能写成 if it necessary。分词短语放在括号里，等于给出「可选做法」，翻译时常用「必要时……」带过，不必译成完整分句。注意 adding 用 -ing 而非 added，因为补零是主动动作。

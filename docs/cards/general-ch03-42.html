Fractional Powers

通用 Ch 03 · Fractional Powers · 原文 PDF 第 109 页

1. 原文

Another way to write a root is to use a fraction as the power (or exponent) instead of the radical sign. The square root of a number is written with a 1⁄2 as the exponent instead of a radical sign. The cube root of a number is written with an exponent of 1⁄3 and the fourth root with an exponent of 1⁄4 and so on.

Example: 31 = 31 1⁄2 3 125 = 1251⁄3 4 16 = 161⁄4

2. 中文翻译

书写根式的另一种方式，是用分数作幂（或称指数）来代替根号。一个数的平方根写作以 1⁄2 为指数，而不用根号。一个数的立方根写作指数 1⁄3，四次方根写作指数 1⁄4，依此类推。

例：31 = 31 1⁄2　3 125 = 1251⁄3　4 16 = 161⁄4（算式照原文转写保留；原文中的根号与分数指数在转写时有缺失。）

4. 语法解析

① 不定式作定语 + 不定式作表语

原句：Another way to write a root is to use a fraction as the power (or exponent) instead of the radical sign.

拆解：主语 Another way，to write a root 是不定式作后置定语；系动词 is；表语同样是不定式 to use a fraction as the power；instead of the radical sign 是介词短语作状语，表替代。

要点：主语含不定式定语时，表语常用不定式与之对称；instead of 是介词，后接名词或动名词，写成 instead of to use 即错。as the power 中的 as 表「作为」，use A as B 是固定搭配。

② 并列分句中的谓语省略

原句：The cube root of a number is written with an exponent of 1⁄3 and the fourth root with an exponent of 1⁄4 and so on.

拆解：and 并列两个分句；第二个分句 the fourth root with an exponent of 1⁄4 承前省略了 is written；末尾 and so on 表示按同一规律继续。

要点：技术文本常用「名词 + 介词短语」的形式省略重复的被动谓语，读时要把 is written 补回来，否则容易误以为 the fourth root 是前面名词的并列宾语。and so on 意为「依此类推」，强调按同一模式继续，比 etc. 更口语。

③ be written with（被动 + with 表手段）

原句：The square root of a number is written with a 1⁄2 as the exponent instead of a radical sign.

拆解：主语 The square root of a number；is written 为被动谓语；with a 1⁄2 as the exponent 是 with 短语，表所用的写法；instead of a radical sign 表替代。

要点：with 在此表「用……（方式）」，与 by（凭动作执行者或手段）不同：be written with an exponent 指写法本身。主语是单数 the square root，故用 is，不要受后面 a number 影响。

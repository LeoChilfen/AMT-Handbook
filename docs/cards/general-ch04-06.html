Detail Drawing

通用 Ch 04 · Detail Drawing · 原文 PDF 第 126 页

1. 原文

A detail drawing is a description of a single part, describing bylines, notes, and symbols the specifications for size, shape, material, and methods of manufacture to be used in making the part. Detail drawings are usually rather simple. When single parts are small, several detail drawings may be shown on the same sheet or print. [Figure 4-3]

2. 中文翻译

零件图是对单个零件的描述，它通过线条、注释和符号，说明制作该零件时在尺寸、形状、材料和制造方法方面的技术要求。零件图通常相当简单。当单个零件较小时，同一张图幅或图纸副本上可以画出若干张零件图。[图 4-3]

4. 语法解析

① describing by lines, notes, and symbols the specifications …（分词状语 + 宾语后置）

原句：A detail drawing is a description of a single part, describing bylines, notes, and symbols the specifications for size, shape, material, and methods of manufacture to be used in making the part.

拆解：主句是 A detail drawing is a description of a single part；describing … 是现在分词短语作补充说明，表示方式；因宾语 the specifications for … 很长，故后置到 bylines, notes, and symbols 之后，形成「动词 + 方式状语 + 长宾语」的语序。

要点：原文此处印作 bylines，实为 by lines（借助线条），不要当作一个词，更不要译成「署名行」。英语允许把短状语插在动词与长宾语之间以避免头重脚轻；译成汉语时按习惯还原为「通过……说明……」。

② to be used in making the part（不定式被动作定语 + in + 动名词）

原句：the specifications for size, shape, material, and methods of manufacture to be used in making the part

拆解：to be used 是不定式被动，作后置定语修饰 methods of manufacture；in making the part 是介词 in + 动名词，表示「在制作……的过程中」。

要点：不定式被动 to be done 作定语含「将要、应当被」之意，与过去分词 done 作定语（已完成的被动）不同。in + 动名词表「在……方面或过程中」，比 when making 更书面。

③ When single parts are small, … may be shown …（时间状语从句 + 情态被动）

原句：When single parts are small, several detail drawings may be shown on the same sheet or print.

拆解：When 引导时间状语从句，用一般现在时表一般情况；主句 several detail drawings may be shown 是「情态动词 + 被动」，on the same sheet or print 是地点状语。

要点：主句用情态动词、从句用一般现在时，是手册陈述一般规则的常见搭配。may be shown 在此不是推测「可能被展示」，而是「可以（允许）画在」的许可用法。several 后须接可数名词复数 detail drawings。

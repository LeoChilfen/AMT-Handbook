Use of Parentheses

通用 Ch 03 · Use of Parentheses · 原文 PDF 第 113 页

1. 原文

In algebraic equations, parentheses are used to group numbers or symbols together. The use of parentheses helps us to identify the order in which we should apply mathematical operations. The operations inside the parentheses are always performed first in algebraic equations.

Example: Solve the algebraic equation X = (4 + 3) 2.

First, perform the operation inside the parentheses, which is, 4 + 3 = 7. Then complete the exponent calculation X = (7)2 = 7 × 7 = 49.

When using more complex equations, which may combine several terms and use multiple operations, grouping the terms together helps organize the equation. Parentheses, ( ), are most commonly used in grouping, but you may also see brackets, [ ]. When a term or expression is inside one of these grouping symbols, it means that any operation indicated to be done on the group is done to the entire term or expression.

Solve the equation N = 2 × [(9 ÷ 3) + (4 + 3) 2]. Start with the operations inside the parentheses ( ), then perform the operations inside the brackets [ ].

N = 2 × [(9 ÷ 3) + (4 + 3)2]

First, complete the operations inside the parentheses ( ).

Second, complete the operations inside the brackets [ ].

2. 中文翻译

在代数等式中，括号用来把数字或符号归并成组。使用括号有助于我们确定应当按什么顺序进行数学运算。在代数等式中，括号内的运算总是最先进行。

例：解代数等式 X = (4 + 3)2。

首先进行括号内的运算，即 4 + 3 = 7。然后完成乘方计算：X = (7)2 = 7 × 7 = 49。

遇到更复杂的等式时——它们可能合并若干项并使用多种运算——把各项归并成组有助于理清等式的结构。分组最常用的是圆括号 ( )，但也可能见到方括号 [ ]。当某一项或某个表达式位于这类分组符号之内时，意思是：对该组所标示的任何运算，都要作用于整个项或整个表达式。

解等式 N = 2 × [(9 ÷ 3) + (4 + 3)2]。先做圆括号 ( ) 内的运算，再做方括号 [ ] 内的运算。

N = 2 × [(9 ÷ 3) + (4 + 3)2]

第一步，完成圆括号 ( ) 内的运算。

第二步，完成方括号 [ ] 内的运算。

4. 语法解析

① 一般现在时被动 + always 的位置

原句：The operations inside the parentheses are always performed first in algebraic equations.

拆解：主语 The operations，inside the parentheses 为后置定语；谓语 are always performed（be + 频度副词 + 过去分词）；first 作状语；in algebraic equations 为范围状语。

要点：频度副词 always 放在 be 动词之后、实义动词之前，因此是 are always performed，不能写成 always are performed。用被动是因为这里陈述的是「运算被执行的顺序」，执行者无关紧要。

② 「介词 + which」引导的定语从句

原句：The use of parentheses helps us to identify the order in which we should apply mathematical operations.

拆解：主句主语 The use of parentheses，谓语 helps，宾语 us，宾语补足语 to identify the order；in which ... 为「介词 + which」引导的定语从句修饰 the order，in which 相当于 in this order。

要点：先行词 order 与介词 in 是固定搭配（in the order），所以从句用 in which，不能只用 which 或 that；口语中也可说 the order we should apply ... in，但介词不宜留在句首之外的怪位置。help sb. (to) do sth. 中的 to 可以省略。

③ When + 分词状语与 which 非限制性定语从句

原句：When using more complex equations, which may combine several terms and use multiple operations, grouping the terms together helps organize the equation.

拆解：When using more complex equations 是「连词 + 现在分词」构成的状语，逻辑主语为主句主语；which may combine ... 为非限制性定语从句，先行词是 equations；主句主语是动名词短语 grouping the terms together，谓语 helps，宾语 organize the equation。

要点：When + 分词可理解为 When you are using ...，手册中省略主语使句子更紧凑。非限制性定语从句用逗号隔开、只能用 which 不能用 that。动名词短语作主语时谓语用第三人称单数（helps，不是 help）。

Sketching Techniques

1. 原文

To make a sketch, first determine what views are necessary to portray the object. Then block in the views using light construction lines. Next, complete the details, darken the object outline, and sketch extension and dimension lines.

Complete the drawing by adding notes, dimensions, title, date, and when necessary, the sketcher’s name. The steps in making a sketch of an object are illustrated in Figure 4-31.

2. 中文翻译

画草图时，先确定需要哪些视图才能表现该物体；然后用浅细的辅助线把各视图的大致轮廓框出来；接着补全细节，加深物体轮廓线，并画出尺寸界线和尺寸线。

再加上说明、尺寸、标题、日期，必要时再加上绘图者的姓名，图即告完成。绘制物体草图的各个步骤见图 4-31。

4. 语法解析

① To make a sketch, first determine …（不定式作目的状语 + 祈使句）

原句：To make a sketch, first determine what views are necessary to portray the object.

拆解：句首 To make a sketch 是不定式短语作目的状语，意为「要画草图」；主句为祈使句，省略主语 you，谓语 determine 后接 what 引导的宾语从句；从句中 are necessary 是系表结构，to portray the object 又是修饰 necessary 的不定式。

要点：操作步骤类文本几乎都用祈使句，动作执行者默认是读者。first / then / next 等顺序词放在句首，构成流程叙述。注意 what views 中 what 作定语，意为「哪些视图」，不要误读成「什么视图是必要的」这样的名词性从句。

② Then block in the views using light construction lines（现在分词短语作方式状语）

原句：Then block in the views using light construction lines.

拆解：祈使句以 Then 承接上一步；block in 是「动词 + 副词」构成的短语动词，宾语 the views 插在中间；using light construction lines 为现在分词短语，说明用什么手段去 block in。

要点：现在分词短语作状语时，其逻辑主语应与主句主语一致——这里是隐含的 you。短语动词的宾语是名词时放在副词前（block the views in），是代词时必须放中间（block them in）。light 在此指线条「浅、细」，不是「轻」。

③ Complete the drawing by adding …（by + 动名词表手段 + 并列宾语）

原句：Complete the drawing by adding notes, dimensions, title, date, and when necessary, the sketcher’s name.

拆解：主句为祈使句 Complete the drawing；by adding … 是「介词 by + 动名词」作方式状语；adding 后并列五个宾语 notes、dimensions、title、date、the sketcher’s name；when necessary 是插入的省略状语从句（when it is necessary）。

要点：by + -ing 回答「靠什么完成」，与上句 using … 同义但更正式。when necessary 这类「连词 + 形容词」的省略结构（when needed、if possible、where applicable）在手册中极常见，中间不加主语和 be 动词。

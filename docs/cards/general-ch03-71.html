4. 语法解析

① 祈使句 + that 宾语从句：notice that each angle is labeled…

原句：In Figure 3-31 , notice that each angle is labeled with a capital letter.

拆解：In Figure 3-31 是前置的地点状语；notice 是祈使句谓语；that each angle is labeled with a capital letter 是 that 引导的宾语从句，从句内部为被动语态（is labeled with）。

要点：技术图注常用「祈使动词 + that 从句」引导读者看图，同类还有 note that / observe that / see that。labeled with 中的 with 引出标注所用的符号；中文说「用大写字母标注」，不必译成「被标注」。原文 Figure 3-31 与逗号之间多一个空格，是 PDF 提取留下的排版噪声。

② because 引导的原因状语从句

原句：This triangle is a right triangle because angle C is a 90° angle.

拆解：主句 This triangle is a right triangle（主 + 系 + 表）；because 引导原因状语从句 angle C is a 90° angle，从句自身主谓齐全。

要点：because 后必须接完整从句，不能像 because of 那样只接名词短语——写成 because of angle C is a 90° angle 是常见错误。表角度用 a 90° angle，读作 a ninety-degree angle；度数符号 ° 直接跟在数字后，不加空格。

③ be referred to as：定义术语的被动句式

原句：Side “c” is always across from the right angle and is referred to as the “hypotenuse.”

拆解：并列谓语 is … and is referred to as …；across from 是复合介词「在……对面」；be referred to as 中 as 引出主语补足语，说明称谓。

要点：refer to A as B（把 A 称为 B）的被动式 A is referred to as B 是定义术语的固定句式，同义还有 is called / is known as / is termed，as 后接名词且不加 to。across from 不能说成 across of；always 放在 is 与过去分词之间，符合频率副词的常规位置。

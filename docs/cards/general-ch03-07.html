1. 原文

In order to add fractions, the denominators must be the same number. This is referred to as having “common denominators.” Example: Add 1⁄7 to 3⁄7 1 + 3 = 1 + 3 = 4 7 7 7 7 If the fractions do not have the same denominator, then one or all the denominators must be changed so that every fraction has a common denominator.

Example: Find the total thickness of a panel made from 3⁄32-inch thick aluminum, that has a 1⁄64-inch thick paint coating. To add these fractions, determine a common denominator. The LCD for this example is 1, so only the first fraction must be changed since the denominator of the second fraction is already in 64ths.

( 3 + 1 )=( 3 × 2 + 1 )=( 6 + 1 )=(6 + 1)= 7 32 64 32 × 2 64 64 64 64 64 Therefore, 7⁄64 is the total thickness.

2. 中文翻译

为了做分数的加法，各分母必须是同一个数。这称为具有「公分母」。例：把 1⁄7 与 3⁄7 相加　1⁄7 + 3⁄7 = (1 + 3)⁄7 = 4⁄7　如果各分数的分母不相同，则必须改变一个或全部分母，使每个分数都有公分母。

例：求一块板件的总厚度，该板件由 3⁄32 英寸厚的铝板制成，表面有一层 1⁄64 英寸厚的漆层。要做这些分数的加法，先确定一个公分母。本例题的最小公分母是 64，因此只需改变第一个分数，因为第二个分数的分母已经是 64 分之几。

(3⁄32 + 1⁄64) = (3 × 2 ⁄ 32 × 2 + 1⁄64) = (6⁄64 + 1⁄64) = (6 + 1)⁄64 = 7⁄64　因此，总厚度为 7⁄64 英寸。

4. 语法解析

① if … then … 条件句 + so that 目的状语从句

原句：If the fractions do not have the same denominator, then one or all the denominators must be changed so that every fraction has a common denominator.

拆解：If 引导条件状语从句；then 引出主句 one or all the denominators must be changed（情态被动）；so that 引导目的状语从句 every fraction has a common denominator，从句用一般现在时。

要点：then 在 if 条件句里可以省略，但技术文本保留它使条件与结果的界限更清楚。one or all the denominators 是「一个或全部」的部分与整体搭配，谓语仍按复数 denominators。so that 表目的，译作「以便、使」；表结果时通常前面有逗号。

② 情态被动 + since 引导的原因状语从句

原句：only the first fraction must be changed since the denominator of the second fraction is already in 64ths.

拆解：主语 only the first fraction（only 限定主语，谓语仍与该主语一致）；谓语 must be changed 是情态动词被动；since 引导原因状语从句 the denominator of the second fraction is already in 64ths。此句截自原文 so only the first fraction … 之后的部分。

要点：since 在此是「因为」，不是「自从」，判断依据是从句用一般现在时而非完成时。already in 64ths 是「已经是 64 分之几」，in + 序数词复数表示「以……为分母」，同理 in tenths（以十分之一为单位）。另需说明：原文该句前半句的版面数字残缺（作「is 1」），按上下文「分母已是 64 分之几」及本节算式 (3⁄32 + 1⁄64 = 6⁄64 + 1⁄64)，LCD 应为 64，译文按 64 处理。

③ 过去分词短语作后置定语：a panel made from …

原句：Example: Find the total thickness of a panel made from 3⁄32-inch thick aluminum, that has a 1⁄64-inch thick paint coating.

拆解：祈使句 Find the total thickness of a panel；made from 3⁄32-inch thick aluminum 是过去分词短语作后置定语修饰 a panel；that has a 1⁄64-inch thick paint coating 是定语从句，同样修饰 a panel。

要点：be made from 指「由……制成（原料已看不出原形）」，be made of 指看得出材料，钣金件用 made from / made of 都有，但不可用 made by（那是「由某人制造」）。3⁄32-inch thick 是「数词 + 连字符 + 形容词」构成的复合定语，thick 不加 -er。

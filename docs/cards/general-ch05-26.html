1. 原文

There are occasions when it is desirable to speed up the movement of the resistance even though a large amount of effort must be used. Levers that help accomplish this are third

Resistance “R” Effort “E” Fulcrum “F” “l” “L” Weight R EF Effort “E” is an increase in force, and ultimately torque.

Bevel gears are used to change the plane of rotation, so that a shaft turning horizontally can make a vertical shaft rotate.

The size of the gears and their number of teeth determine the mechanical advantage, and whether force is being increased or rpm is being increased. If each gear has the same number of teeth, there would be no change in force or rpm. [Figure 5-14]

The worm gear has an extremely high mechanical advantage.

The input force goes into the spiral worm gear, which drives the spur gear. One complete revolution of the worm gear only makes the spur gear move an amount equal to one tooth.

The mechanical advantage is equal to the number of teeth on the spur gear, which in this case there are 25. This is a force gaining machine, to the tune of 25 times more output force. [Figure 5-15]

The planetary sun gear system is typical of what would be found in a propeller reduction gearbox. The power output shaft of the engine would drive the sun gear in the middle, applied would only need to be 50 lb. With this type of pulley, the effort will always be one-half of the weight being lifted.

4. 语法解析

① There be + when 定语从句 + it 形式主语

原句：There are occasions when it is desirable to speed up the movement of the resistance even though a large amount of effort must be used.

拆解：There are occasions 为存在句；when… 引导定语从句修饰 occasions；从句中 it 是形式主语，真正的主语是 to speed up the movement of the resistance；even though 引导让步状语从句，用被动 must be used。

要点：There are occasions when… 是手册提出例外情况的惯用开场，译「有时／在某些场合」。it is desirable to do 中 it 不可换成 this；desirable 在此意为「希望、值得」，不是「令人满意的」。让步从句放在最后，汉语宜提前：「即便必须使出很大的力，有时也希望……」

② so that 从句 + make 复合宾语

原句：Bevel gears are used to change the plane of rotation, so that a shaft turning horizontally can make a vertical shaft rotate.

拆解：主句为被动 are used to change…（不定式作目的状语）；so that 引导结果（或目的）状语从句；a shaft turning horizontally 中 turning horizontally 是现在分词后置定语；make a vertical shaft rotate 为 make + 宾语 + 省略 to 的不定式。

要点：so that 从句常与 can / could / may 连用。make / have / let 后接不带 to 的不定式，而 force / cause / require 后必须带 to。译「使一根水平转动的轴能带动一根垂直轴旋转」，中文用「带动」二字即可把 make … rotate 说清。

③ 非限制性定语从句中套 there be

原句：The mechanical advantage is equal to the number of teeth on the spur gear, which in this case there are 25.

拆解：主句 is equal to the number of teeth on the spur gear；which 引导非限制性定语从句，指代 the number of teeth；从句内部用的是存在句 there are 25，属原文的口语化写法。

要点：规范写法应为 of which there are 25 或 which in this case is 25；见到「which + there be」要意识到 which 在从句中充当状语性成分，而非主语。阅读时按「本例中为 25 个齿」理解即可，但自己写作不要照搬这种结构。

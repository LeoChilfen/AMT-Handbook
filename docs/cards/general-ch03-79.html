Converting Binary Numbers to Decimal Numbers

通用 Ch 03 · Converting Binary Numbers to Decimal Numbers · 原文 PDF 第 123 页

1. 原文

To convert a binary number to a decimal number, add up the place values that have a 1 (place values that have a zero do not contribute to the decimal number conversion).

Example: Convert the binary number 10110011 to a decimal number. Using the place value chart in Figure 3-35, add up the place values of the ‘1s’ in the binary number (ignore the place values with a zero in the binary number).

The binary number 10110011 = 128 + 0 + 32 + 16 + 0 + 0 + 2 + 1 = 179 in the decimal number system

2. 中文翻译

要把二进制数换算成十进制数，可把带 1 的各数位值相加（带 0 的数位值对十进制换算没有贡献）。

例：把二进制数 10110011 换算为十进制数。利用图 3-35 的数位值表，把该二进制数中「1」所在数位的值相加（忽略二进制数中为 0 的数位）。

二进制数 10110011 = 128 + 0 + 32 + 16 + 0 + 0 + 2 + 1 = 十进制数制中的 179。

4. 语法解析

① To do X, do Y + that 定语从句

原句：To convert a binary number to a decimal number, add up the place values that have a 1 (place values that have a zero do not contribute to the decimal number conversion).

拆解：To convert … 是不定式短语作目的状语；主句是祈使句 add up the place values；that have a 1 是定语从句修饰 place values；括号内是插入的补充说明句，自身也含 that 定语从句。

要点：说明书常用「To do X, do Y」结构，祈使句表示操作指令，隐含主语为 you。add up 是「把……加起来」的动词短语，代词作宾语时要放中间（add them up）。contribute to 中的 to 是介词，后接名词或动名词。

② 分词短语作方式状语 + 括号补充指令

原句：Using the place value chart in Figure 3-35, add up the place values of the ‘1s’ in the binary number (ignore the place values with a zero in the binary number).

拆解：Using … 是现在分词短语作方式状语；主句是祈使句 add up the place values；括号内 ignore … 是另一条并列的操作指令；of the ‘1s’ 表示「那些 1 所在数位的」。

要点：分词状语与祈使句搭配时，逻辑主语是隐含的 you，动作执行者一致才成立。‘1s’ 这种「数字 + s」表示「若干个 1」，读作 ones，同理 ‘0s’。with a zero 是介词短语作后置定语，修饰 place values，不是伴随状语。

③ 等式链作谓语

原句：The binary number 10110011 = 128 + 0 + 32 + 16 + 0 + 0 + 2 + 1 = 179 in the decimal number system

拆解：等式链 A = B = C 表示逐步等价；in the decimal number system 是范围状语，说明 179 属于十进制。

要点：数学式在句子里可直接充当谓语（= 读作 equals / is equal to），不必另加动词，也不必写成 is equal to 179。这种连等式在技术文本中很常见，翻译时保留算式、只在末尾补「即……」。注意原文此句无句号，是 PDF 截断所致。

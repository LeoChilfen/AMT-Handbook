# AMT-Handbook

FAA《Aviation Maintenance Technician Handbook》（航空维修技师手册）相关的个人学习笔记与整理。

## 目录结构

```
.
├── README.md     项目说明
└── .gitignore    哪些文件不进版本库
```

## 常用命令

```powershell
git status              # 看现在有哪些改动
git add .               # 把改动加入暂存区
git commit -m "说明"     # 提交
git push                # 推到 GitHub
git pull                # 拉回最新
git log --oneline       # 看提交历史
```

## 说明

- 分支：`main`
- 远程：`origin` → https://github.com/LeoChilfen/AMT-Handbook
- 提交信息：一行写清楚“改了什么”，中文英文都行
